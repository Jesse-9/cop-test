# 06 · 整理清单与清理建议

> 目标：在不丢证据、不破坏运行的前提下，把 424 MB 的目录收拾到 160 MB 左右。
> **本篇只是清单和建议，我没有执行任何删除。** 需要我动手时说一声，我按你勾选的项执行。

## 1. 现在到底占了多少

```text
cop-test-main/                     424.3 MB / 2758 个文件
├── docs/                          246.6 MB / 262 个文件   ← 其中 runs/ 占 236.1 MB
├── .venv/                         120.7 MB / 2162 个文件  ← Python 虚拟环境
├── var/                            38.9 MB / 1 个文件     ← catalog.db
├── src/                             4.2 MB / 214 个文件   （其中 __pycache__ 2.45 MB）
├── tests/                           0.5 MB / 65 个文件
├── frontend/                        0.3 MB / 35 个文件    （没有 node_modules）
└── tools/                           0.1 MB / 8 个文件
```

一句话：**424 MB 里只有 5 MB 是"代码"，231 MB 是运行输出，121 MB 是环境，39 MB 是数据库。**

## 2. 四类判定

| 类别 | 判定 | 处置 |
|---|---|---|
| 🟢 必须保留 | 代码、测试、文档、场景工件、正式证据、数据库 | 一个字节都别动 |
| 🟡 可再生成 | `__pycache__`、`*.egg-info`、`.venv`、`frontend/node_modules` | 想清就清，需要时重装 |
| 🟠 临时输出 | `docs/implementation/runs/`、`*.log` | **可以清**，但先归档有代表性的几份 |
| 🔴 真正的垃圾 | 无（这个项目没有明显垃圾文件） | — |

## 3. 逐项清单

### 3.1 🟢 绝对不能删

| 路径 | 大小 | 为什么 |
|---|---|---|
| `docs/scene_artifacts/v1/` | 7.9 MB | 受保护工件 + `current.json`，删了就得重建场景 |
| `docs/scene_artifacts/stage3|stage4/` | 含在上面 | v1 工件的迁移来源，manifest 的 `parent_artifact` 指向它们 |
| `docs/implementation/evidence/` | 1.3 MB / 16 个 | **正式验收证据**，报告引用它 |
| `docs/implementation/reports|plans|governance|reference/` | 0.9 MB | 方案与事实记录 |
| `docs/wiki/` | 0.9 MB / 120 篇 | 知识库 |
| `src/` `tests/` `frontend/src/` `tools/` | 5 MB | 代码 |
| `var/catalog/catalog.db` | 38.9 MB | 目录发布 + 知识图谱 + 运行记录，删了知识图谱要重新导 |
| `pyproject.toml` `uv.lock` `alembic.ini` `spec.py` | 小 | 环境与版本锁 |

⚠️ 特别注意：`docs/scene_artifacts/v1/.runtime/` 是每次运行重新生成的**运行态**（`session.json` + `lifecycle.jsonl`），可以清，`run` 会重建。但**不要动 `v001_.../` 目录里的四个文件**。

### 3.2 🟡 可再生成（合计约 123 MB）

| 路径 | 大小 | 怎么恢复 | 建议 |
|---|---|---|---|
| `.venv/` | 120.7 MB | `uv sync`（需要网络，1～3 分钟） | **保留**。删了下次跑要重装，得不偿失 |
| `src/**/__pycache__/`（11 个目录） | 2.45 MB | 自动生成 | **可删**，纯收益 |
| `src/flexible_factory.egg-info/` | 小 | `uv sync` 或 `pip install -e .` | 可删 |
| `frontend/node_modules/` | 0（当前不存在） | `npm ci` | 不用管 |

### 3.3 🟠 临时输出（合计 236 MB，清理主战场）

| 路径 | 内容 | 大小 | 建议 |
|---|---|---|---|
| `docs/implementation/runs/v1_run_full_flow_*.json` | 14 份全流程报告，单份 12～17 MB | **225.3 MB** | 留最近 2～3 份（含 1 份成功 + 1 份失败/边界），其余压缩归档或删 |
| `docs/implementation/runs/v1_scene_snapshot_*.json` | 25 份场景快照，每份 375 KB | 9.1 MB | 留最新 1 份 |
| `docs/implementation/runs/scene_validation_*.json` | 28 份校验报告，每份 58 KB | 1.6 MB | 留最新 2 份 |
| `flexible_factory.log` | 每次运行追加 | 12.7 MB | 删或截断（`Clear-Content`） |
| `docs/implementation/runs/*.html`（如生成过仪表盘） | 一次性产物 | 视情况 | 需要时重新生成 |

**为什么这些能删**：项目自己的约定写得很清楚——`runs/` 是"被 Git 忽略的临时运行输出，不作为正式归档证据"（`docs/implementation/README.md`）。正式证据在 `evidence/`，而且被报告引用。

**删之前建议归档 3 份**：
1. 最新一份 `full_flow` 成功报告；
2. 一份带故障/边界的报告（比如 `detour_heavy` 背压超时那次的证据，如果还在）；
3. 一份 `staggered_batch` 或 `no_pair` 的对比报告。

### 3.4 其它小整理项

| 现象 | 说明 | 建议 |
|---|---|---|
| 没有 `.git/` | 这个目录是**从压缩包解出来的**（名字带 `-main`），没有版本控制 | ⚠️ **清理前强烈建议 `git init` + 首次提交**，否则删错了没法回滚 |
| `.gitignore` 中文注释乱码 | 文件可能不是 UTF-8 保存的；规则本身都是 ASCII，**不影响功能** | 用编辑器另存为 UTF-8 即可 |
| `.claude/settings.json` | 159 字节的本地工具配置 | 保留 |
| 根目录 `~$dragon.docx` 之类 | 不在此项目内 | 与本项目无关 |

## 4. 推荐操作顺序（PowerShell）

> 全部带 `-WhatIf`，先看会删什么，确认后去掉 `-WhatIf` 再跑。

```powershell
$root = "C:\Users\Mr.chen\Desktop\cop-test-main"
Set-Location $root

# 步骤 0：先有后悔药（二选一）
git init; git add -A; git commit -m "baseline before cleanup"
# 或者：
Compress-Archive -Path ".\src", ".\tests", ".\docs" -DestinationPath ".\backup_src_docs.zip"

# 步骤 1：Python 缓存（安全，纯收益）
Get-ChildItem -Recurse -Directory -Filter __pycache__ | Remove-Item -Recurse -Force -WhatIf

# 步骤 2：日志
Remove-Item ".\flexible_factory.log" -WhatIf
# 想保留但清空内容：
# Clear-Content ".\flexible_factory.log"

# 步骤 3：只留最近 3 份全流程报告（其余先归档）
$reports = Get-ChildItem ".\docs\implementation\runs\v1_run_full_flow_*.json" |
           Sort-Object LastWriteTime -Descending
$reports | Select-Object -Skip 3 | Compress-Archive -DestinationPath ".\docs\implementation\runs_archive.zip"
$reports | Select-Object -Skip 3 | Remove-Item -WhatIf

# 步骤 4：快照留 1 份，校验报告留 2 份
Get-ChildItem ".\docs\implementation\runs\v1_scene_snapshot_*.json" |
  Sort-Object LastWriteTime -Descending | Select-Object -Skip 1 | Remove-Item -WhatIf
Get-ChildItem ".\docs\implementation\runs\scene_validation_*.json" |
  Sort-Object LastWriteTime -Descending | Select-Object -Skip 2 | Remove-Item -WhatIf
```

跑完 `-WhatIf` 版本后，确认输出里没有 `scene_artifacts`、`evidence`、`src`、`tests`，再去掉 `-WhatIf` 执行。

**预期效果**：424 MB → 约 165 MB（`.venv` 120 + 数据库 39 + 代码文档 6）。
