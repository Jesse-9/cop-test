## 三句话版本

1. **它是什么**：一个用 Python 通过 ZeroMQ 远程控制 CoppeliaSim 4.10 的"柔性工业车间"仿真工程——五台 UR5 机械臂 + 一台 AGV + 四条传送带，把两种原料加工、运输、配对成一个成品。
2. **它的难点在哪**：不是"让机械臂动起来"，而是**调度**——谁先动、谁等谁、资源怎么不打架、失败了怎么不把现场搞乱。所以代码里最厚的是 `application/coordinator.py`（2625 行）。
3. **它现在处于什么状态**：v1 产品已收敛（2026-11-03），之后做了混线批次、设备执行适配、工序 DAG、能力调度、订单编排（6 个阶段）、数据平台（目录库/知识图谱/运行记录）。**已实机验收的部分和"仅纯逻辑测试"的部分必须分开看**，[00 篇第 6 节](00-项目全景与三分钟上手.md#6-项目现在能做什么不能做什么) 有清单。
