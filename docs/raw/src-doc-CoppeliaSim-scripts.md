| [![](images/homeImg.png)](../index.html)  CoppeliaSim is a highly customizable simulator: almost every step of a [simulation](simulation.htm) is user-defined. Additionally, the simulator itself can also be customized to a large extent. This flexibility is allowed through an integrated script interpreter ([Lua](http://www.lua.org)) and an external script interpreter ([Python](https://www.python.org)). Both operate in almost the same fashion, [except for small differences](luaPythonDifferences.htm). For more information on Lua, refer to the [Lua crash course](luaCrashCourse.htm) section and the [online documentation](http://www.lua.org).  ![](images/luaAndPythonLogo.jpg)  \[Lua and Python logo\]      CoppeliaSim extends Lua's and Python's API functions and adds CoppeliaSim specific commands that can be recognized by their *sim* -prefixes (e.g. [sim.getObjectPosition](regularApi/simGetObjectPosition.htm)). For a list of all CoppeliaSim specific API functions, refer to the [regular API](apiFunctions.htm). New, customized API functions can also be registered from a [plugin](plugins.htm). Refer to the [related API-functions](apiFunctions.htm#customizingLuaFunctions) for more information.    Several types of scripts are supported in CoppeliaSim: [the sandbox](sandboxScript.htm), [add-ons](addOns.htm), and [embedded scripts](embeddedScripts.htm) (themselves composed of a [main script](mainScript.htm), [simulation scripts](simulationScripts.htm) and [customization scripts](customizationScripts.htm)). An embedded script is a script that is embedded in a [scene](scenes.htm) (or [model](models.htm)), i.e. a script that is part of the scene and that will be saved and loaded together with the rest of the scene (or model). On the other hand, the sandbox and add-ons are not associated with any specific scene, model or object, and will run across all scenes in a similar way.  ![](images/allScripts.jpg)  \[Script types\]      Scripts are invoked via [callback functions](callbackFunctions.htm) by CoppeliaSim, and follow a [specific execution order](scriptExecution.htm). They can [run threaded or non-threaded](threadedAndNonThreadedCode.htm).  CoppeliaSim scripts may be published under any license. |
