# 本地数据库仪表盘 UI 蓝图

本文把[本地数据库仪表盘优化方案](db-dashboard-frontend-optimization.md)落实为页面分区和交互模板。目标是检查由 `tools/db_dashboard.py` 生成的 SQLite 快照；页面始终离线、只读、自包含。不得把筛选/切换设计成会访问数据库或仿真服务的实时功能。

## 页面全局骨架

```text
┌───────────────────────────────────────────────────────────────────────────┐
│ 工厂数据库快照   [总览] [知识图谱] [生产运行] [工艺目录] [来源]   [主题]   │
│ DB: …/catalog.db    revision 0006…   生成于 …    离线 · 只读快照          │
├───────────────────────────────────────────────────────────────────────────┤
│ 当前分区标题 / 说明                                      搜索/分区操作     │
│                                                                           │
│ 当前任务内容                                                               │
└───────────────────────────────────────────────────────────────────────────┘
```

头部在宽屏可 sticky；窄屏将数据库信息压成一行摘要，点击后展开完整路径/revision/时间。路径提供复制动作。主题选择写入 localStorage，失败时退回系统主题，不影响内容查看。快照没有实时刷新按钮；“生成新快照”说明提示使用 CLI 并显示当前配置对应的命令范例。

## 总览分区

```text
数据库快照                         知识实体 2,341  关系 4,892  运行 12
迁移版本 0006…  · 已发布目录 catalog-v1 · 最新运行 PARTIAL_FAILED
┌────────────────────────────┬────────────────────────────┐
│ 数据域                      │ 最近运行                   │
│ 知识图谱   有数据 → 打开    │ run-…  PARTIAL_FAILED       │
│ 工艺目录   已发布 → 打开    │ 场景 / 时间 / 结果摘要     │
│ 来源抽取   3 次 → 打开      │ 失败数 · 完成数 · 输出 UID │
└────────────────────────────┴────────────────────────────┘
```

- 指标用紧凑行，不设置单一超大数字 hero。
- 每个数据域用“已发布/可用/无数据/schema 不存在/读取错误”之一说明状态，并有跳转入口。
- 最新运行概览来自 `data.runs[0]`，没有运行时说明尚无运行记录；payload 错误要显示“数据读取失败”，不能填成 0 后当作真实计数。

## 知识图谱分区

```text
知识图谱 · 2,341 个实体 / 4,892 条关系
类型 [全部 ▾] 状态 [全部 ▾] 搜索名称或 ID…   已匹配 64   [清除]
┌────────────────────────────────────┬──────────────────────────────┐
│ 图谱概览                            │ 当前实体                      │
│ Canvas：关系邻域 / 类型图例         │ 标签 / ID / 类型 / 状态       │
│                                    │ 相邻关系摘要                  │
├────────────────────────────────────┴──────────────────────────────┤
│ 节点表 [64]   关系表 […]   统计视图                                │
└───────────────────────────────────────────────────────────────────┘
```

交互表：

| 用户动作 | 页面反馈 |
|---|---|
| 改变类型/状态/搜索 | 更新当前匹配数、图谱高亮和节点表；保留筛选值 |
| 选择节点 | 高亮其相邻边，在节点表定位该行，并展示右侧详情 |
| 点击关系表中的端点 | 选择对应节点并更新图谱/详情 |
| 清除选择 | 取消高亮，恢复筛选后的全图 |
| 图谱过大 | 先停用动态布局/降低绘制密度，保留完整可筛选表；不截断底层数据表 |

全量实体/关系计数与过滤后结果必须分开标注。表格是 Canvas 的完整文本替代，包含 caption、列头语义和水平滚动容器；选择行可用键盘完成。搜索未命中显示“没有匹配实体”及清除筛选操作。

## 生产运行分区

```text
生产运行   [run-… · PARTIAL_FAILED ▾]
订单/场景 …   开始 …   结束 …   终态 …
[摘要] [工序] [资源等待] [物料谱系] [故障]
┌───────────────────────────────────┬───────────────────────────────┐
│ 当前子视图                         │ 选中工序/资源/UID 详情        │
│ DAG、表格或谱系                    │ 状态、时间、设备、原因        │
└───────────────────────────────────┴───────────────────────────────┘
```

| 子视图 | 显示重点 | 空/错误处理 |
|---|---|---|
| 摘要 | run ID、scenario、status、开始/结束、结果和计数 | 不存在结果时说明尚未记录；payload `error` 独立警示 |
| 工序 | 时间线/DAG、工序状态、阶段、设备、duration、等待、失败原因 | 无工序时区分运行确无实例与 timeline 查询错误 |
| 资源等待 | resource 和 wait 列表、等待时长、运行总数 | 无等待事件与读取失败分别呈现 |
| 物料谱系 | 输入/输出 UID、父子谱系、最终 UID | 缺失 genealogy 时解释 payload 没有最终 UID或无谱系记录 |
| 故障 | 失败项、failure code/reason、节点关联 | 空列表表示没有已记录故障；query error 不得渲染成空列表 |

切换 run 时保留主分区位置并重置只属于该 run 的选中工序。点击时间线/DAG 节点同步选择工序表行。图形状态与表格文字一致；状态值保留原 enum，同时可显示人类可读中文标签。

## 工艺目录分区

```text
工艺目录 · catalog-v1 · 已发布
目录搜索…       [总览] [配方/路线] [工序 DAG] [设备/能力] [物料/资源/区域] [绑定]
┌──────────────────────────────────────────────────────────────────────┐
│ 当前视图：DAG 图或表格；左/上方显示筛选结果数                        │
├───────────────────────────────────────┬──────────────────────────────┤
│ 工序、路线或目录表                    │ 选中条目的字段详情           │
└───────────────────────────────────────┴──────────────────────────────┘
```

- 目录总览显示发布版本、recipe/operation/device/resource/zone 等现有 payload 计数。
- 配方/路线按 route 展示 operation 顺序和入口/出口区域；工序 DAG 可切换图形与依赖表格。
- 设备/能力显示候选 capability、物理/逻辑类型、资源绑定；物料/资源/区域显示容量、颜色或角色等现有字段。
- 绑定区展示场景 ID、contract version、device role/alias；版本与 ID 使用等宽字和复制操作。
- 搜索覆盖当前目录分组中可见 ID、语义和描述；不新增跨数据库查询或未有字段的过滤器。

未发布目录、发布记录为空、目录表缺失三种情况使用不同说明；不把“无已发布 release”渲染成有数据的空 DAG。

## 来源与抽取分区

```text
来源与抽取
抽取运行: extraction ID · source · extractor/version · 状态 · 完成时间
计数摘要: entities … / relations … / unmapped …
来源文件表: source ID | 路径 | SHA-256 | media type | version
```

优先展示抽取状态和 unmapped 诊断；来源路径/摘要详情保持可复制。知识表不可用、无抽取任务、来源表为空、读取异常要明确区分。长表使用 sticky header 与水平滚动。

## 状态与筛选规则

| 状态 | 视觉/文本 | 动作 |
|---|---|---|
| 快照生成时间 | 头部固定展示 | 可复制路径，不能标记为实时 |
| 数据域可用 | 中性/成功标记和状态词 | 跳转分区 |
| `RUNNING` | 运行中标记 | 静态快照不自动轮询；说明运行数据截至生成时间 |
| `DONE` / `PUBLISHED` | 已完成/已发布 | 查看相应详情 |
| `FAILED` / `PARTIAL_FAILED` | 失败/部分失败文本及原因入口 | 跳转故障或运行摘要 |
| `ABORTED` | 已中止文本和最后状态 | 查看运行详情 |
| 无数据 | 中性说明 | 给出该数据域能做的下一步，例如生成运行记录或导入知识 |
| 查询/字段读取错误 | 错误说明和可用部分 | 提示检查数据库 revision/相关表；不可显示为成功空态 |

分区导航保留 URL hash；图谱过滤与 run 选择保存在页面 state，可选保存轻量 URL query 仅在编码长度合适时实施。主题偏好存 localStorage，过滤条件不持久化数据库。

## 响应式与键盘模板

- 宽屏：固定快照头部 + 水平主导航；图谱/运行/目录采用主内容和详情两栏。
- 中屏：详情面板下移为可折叠区；指标行自动换列。
- 窄屏：导航横向滚动或 select；图形与详情上下堆叠；表格自身横向滚动；筛选控件纵向排列。
- 320px 宽度和 200% 缩放下，标题/ID换行，不遮挡控件；不把整页缩放成不可读宽表。
- Tab 顺序符合视觉顺序；所有选择、清除、展开和主题动作可键盘触发；图谱节点不能只通过 pointer hover 获得详情。
- `prefers-reduced-motion` 关闭力导向动画和非必要过渡。

## 验收样例和精简检查

使用两份 fixture：空/部分 schema 数据库；含知识节点与关系、已发布目录、DONE 与局部失败运行、来源抽取的完整样例。

最小验收只检查：

1. 在两类 fixture 下，导航和总览能区分无数据、schema 缺失及读取错误。
2. 一条图谱过滤/选择路径能联动表格与详情；一条运行选择路径能联动运行子视图。
3. 生成 HTML 可以离线打开，payload 字符串仍经 `textContent` 渲染并保留 `</script>` 转义；交互不产生网络写入。
4. 桌面和 320px 窄屏各检查一次焦点、表格滚动和内容重叠；主题检查只验证 token 切换，不对每个组件做截图矩阵。

设计交付后沿用优化方案中现有测试边界，不为每个分区建立独立 E2E。
