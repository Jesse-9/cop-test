# 数字孪生概述与实现架构

## 简介

**数字孪生（Digital Twin）** 是物理系统的虚拟镜像，通过实时数据同步实现虚拟与物理世界的双向映射。CoppeliaSim 作为机器人仿真平台，在数字孪生领域有广泛应用，特别是在**工业场景**中。

## 数字孪生层次

```
L0: 数字模型 (Digital Model)
  └─ 单向离线，手工数据同步
L1: 数字影子 (Digital Shadow)
  └─ 单向自动，物理 → 虚拟
L2: 数字孪生 (Digital Twin)
  └─ 双向自动，物理 ←→ 虚拟
L3: 自适应孪生 (Adaptive Twin)
  └─ 双向 + AI 优化决策
```

CoppeliaSim 常用于实现 L1 和 L2 级别的数字孪生。

## 架构设计

```
┌─────────────────────┐     实时数据流     ┌─────────────────────┐
│   物理世界           │ ◄═══════════════► │   虚拟世界           │

│  ┌───────────────┐  │  传感器数据 →     │  ┌───────────────┐  │
│  │ 物理机器人     │──┼─────────────────→│  │ 虚拟机器人     │  │
│  │ PLC / 控制器  │  │                  │  │ 仿真脚本       │  │
│  │ 传感器        │  │                  │  │ 碰撞检测       │  │
│  │ 编码器        │  │                  │  │ 物理引擎       │  │
│  └───────────────┘  │                  │  └───────────────┘  │
│                     │  控制指令 ←      │                     │
│  ┌───────────────┐  │←─────────────────┼──┐  ┌───────────┐  │
│  │ 执行器        │──┼───────────────────┘  │  │ 规划器     │  │

```

## 通信方案对比

| 方案 | 延迟 | 适用场景 | 配置难度 |

## CoppeliaSim 数字孪生实现模式

### 模式 1：物理 → 虚拟（数据同步）

```python
# Python 端：读取物理设备数据并更新仿真
from coppeliasim_zmqremoteapi_client import RemoteAPIClient
import serial

# 连接仿真
client = RemoteAPIClient()
sim = client.getObject('sim')

# 连接物理设备（示例：串口读取编码器）
ser = serial.Serial('COM3', 115200)

while sim.getSimulationState() ~= sim.simulation_stopped:
    # 读取物理编码器
    data = ser.readline().decode().strip()
    joint_pos = float(data.split(',')[0])
    
    # 更新仿真中的关节位置
    sim.setJointPosition(joint_handle, joint_pos)
    
    # 可选：读取其他传感器数据
    # sim.setFloatSignal('temperature', temp_value)
```

### 模式 2：虚拟 → 物理（控制下发）

```python
# Python 端：仿真规划路径，下发到物理机器人
import numpy as np
from coppeliasim_zmqremoteapi_client import RemoteAPIClient

client = RemoteAPIClient()
sim = client.getObject('sim')
simIK = client.getObject('simIK')

# 在仿真中规划路径
def plan_and_execute(target_pose):
    # 1. 仿真中 IK 求解
    sim.setObjectPosition(target_dummy, target_pose)
    ik_result = simIK.handleGroup(ik_env, ik_group, {'syncWorlds': True})
    
    # 2. 读取仿真关节角度
    joint_angles = [sim.getJointPosition(j) for j in joint_handles]
    
    # 3. 下发到物理机器人（通过 PLC 接口）
    send_to_plc(joint_angles)
    
    # 4. 等待物理执行完成并反馈
```

### 模式 3：完全双向（全数字孪生）

```python
import threading
from coppeliasim_zmqremoteapi_client import RemoteAPIClient

class DigitalTwin:
    def __init__(self):
        self.client = RemoteAPIClient()
        self.sim = self.client.getObject('sim')
        self.running = True
        
    def sync_physical_to_virtual(self):
        """线程 1：物理 → 虚拟（数据采集线程）"""
        while self.running:
            # 读取物理传感器
            physical_data = read_physical_sensors()
            
            # 更新仿真模型
            self.sim.setFloatSignal('joint_pos_1', physical_data['j1'])
            self.sim.setFloatSignal('joint_pos_2', physical_data['j2'])
            
            threading.Event().wait(0.01)  # 10ms 同步间隔
            
    def sync_virtual_to_physical(self):
        """线程 2：虚拟 → 物理（控制下发线程）"""
        while self.running:
            # 读取仿真中的控制指令
            cmd_vel = self.sim.getFloatSignal('cmd_vel')
            cmd_pos = self.sim.getFloatSignal('cmd_pos')
            
            # 下发到物理执行器
            send_to_actuators(cmd_vel, cmd_pos)
            
            threading.Event().wait(0.02)  # 20ms 控制间隔
            
    def start(self):
        """启动数字孪生"""
        t1 = threading.Thread(target=self.sync_physical_to_virtual)
        t2 = threading.Thread(target=self.sync_virtual_to_physical)
        t1.start()
        t2.start()
        
    def stop(self):
        self.running = False

twin = DigitalTwin()
twin.start()
```

## 关键实现要点

### 时间同步
```lua
-- 仿真端：使用仿真时间而非真实时间
sim.setFloatSignal('sim_time', sim.getSimulationTime())

-- 客户端读取并计算延迟
local_time = time.time()
sim_time = client.sim.getFloatSignal('sim_time')
latency = local_time - sim_time
```

### 数据一致性
- 使用**信号（Signal）**机制进行轻量级数据交换
- 对关键数据使用**时间戳**标记
- 实现**心跳检测**监控连接状态

### 误差补偿
- 物理与虚拟模型间的参数偏差需要校准
- 定期使用物理传感器数据进行**模型更新**
- 建立**误差模型**进行预测补偿
