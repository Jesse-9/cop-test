# ROS2 集成指南

## 概述

CoppeliaSim 通过 `simROS2` 插件实现对 **ROS2** 的全功能集成，包括话题（Topic）发布/订阅、服务（Service）通信和动作（Action）接口。ROS2 集成是构建**数字孪生系统**和**协同仿真**的关键能力。

> 详细文档见 [[raw/src-doc-CoppeliaSim-ROS2-tutorial.html]] 和 [[raw/src-doc-CoppeliaSim-ROS2-interface.html]]

## 系统要求

- **CoppeliaSim 4.10**（4.0+ 支持 ROS2）
- **ROS2 发行版**：Humble（Ubuntu 22.04）、Jazzy（Ubuntu 24.04）或 Rolling
- **操作系统**：Ubuntu 20.04/22.04/24.04（推荐）

## 安装设置

### 步骤 1：安装 ROS2

```bash
# Ubuntu 22.04 + ROS2 Humble
sudo apt update
sudo apt install ros-humble-desktop
source /opt/ros/humble/setup.bash
```

### 步骤 2：加载 simROS2 插件

```bash
cd ~/CoppeliaSim_Edu_V4_10_Ubuntu22_04
cp compiledROSPlugins/libsimROS2.so .
```

### 步骤 3：编译 ROS2 包

```bash
export COPPELIASIM_ROOT_DIR=~/CoppeliaSim_Edu_V4_10_Ubuntu22_04
mkdir -p ~/coppelia_ros2_ws/src
cd ~/coppelia_ros2_ws

# 复制官方 ROS2 包
cp -r $COPPELIASIM_ROOT_DIR/programming/ros2_packages/* src/

colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release
source install/setup.bash
```

### 步骤 4：启动

```bash
# 终端 1：启动 CoppeliaSim（必须先 source ROS2）
source /opt/ros/humble/setup.bash
source ~/coppelia_ros2_ws/install/setup.bash
./coppeliaSim.sh

# 终端 2：ROS2 节点
source /opt/ros/humble/setup.bash
ros2 run <your_package> <your_node>
```

## Lua 脚本端用法

### 1. 加载插件

```lua
simROS2 = require('simROS2')
```

### 2. 发布者 (Publisher)

```lua
function sysCall_init()
    simROS2 = require('simROS2')
    
    -- 创建发布者
    pub = simROS2.createPublisher(
        '/simulationTime',          -- 话题名
        'std_msgs/msg/Float32'      -- 消息类型
    )
end

function sysCall_sensing()
    -- 发布仿真时间
    local time = sim.getSimulationTime()
    simROS2.publish(pub, {data = time})
end

function sysCall_cleanup()
    simROS2.shutdownPublisher(pub)
end
```

### 3. 订阅者 (Subscriber)

```lua
function sysCall_init()
    simROS2 = require('simROS2')
    
    -- 回调函数
    function velocityCallback(msg)
        targetVel = msg.data  -- Twist 消息的线速度
    end
    
    -- 创建订阅者
    sub = simROS2.createSubscription(
        '/cmd_vel',                 -- 话题名
        'geometry_msgs/msg/Twist',  -- 消息类型
        'velocityCallback'          -- 回调函数名
    )
end

function sysCall_cleanup()
    simROS2.shutdownSubscription(sub)
end
```

### 4. 服务端 (Service)

```lua
function sysCall_init()
    simROS2 = require('simROS2')
    
    function getPosService(req, res)
        -- req: 请求消息
        -- res: 响应消息（需填充并返回）
        local pos = sim.getObjectPosition(robotHandle, -1)
        res.x = pos[1]
        res.y = pos[2]
        res.z = pos[3]
        return res
    end
    
    srv = simROS2.createService(
        '/get_robot_position',          -- 服务名
        'custom_srvs/srv/GetPosition',  -- 服务类型
        'getPosService'                 -- 回调函数
    )
end

function sysCall_cleanup()
    simROS2.shutdownService(srv)
end
```

### 5. TF 发布

```lua
function sysCall_init()
    simROS2 = require('simROS2')
    
    -- 发布场景对象的 TF
    simROS2.publishTransform(objectHandle, parentName, frameName)
    
    -- 或者自动发布场景中所有对象的 TF
    -- 在场景中添加 "ros2Interface helper tool" 模型
end
```

## Python ROS2 节点 + CoppeliaSim

```python
#!/usr/bin/env python3
import rclpy
from rclpy.node import Node
from std_msgs.msg import Float32
from geometry_msgs.msg import Twist
import math
from coppeliasim_zmqremoteapi_client import RemoteAPIClient

class CoppeliaSimROS2Bridge(Node):
    def __init__(self):
        super().__init__('coppelia_bridge')
        
        # 连接 CoppeliaSim
        self.client = RemoteAPIClient()
        self.sim = self.client.getObject('sim')
        
        # ROS2 发布者
        self.pub = self.create_publisher(Float32, '/sim_time', 10)
        
        # ROS2 订阅者
        self.sub = self.create_subscription(
            Twist, '/cmd_vel', self.vel_callback, 10)
        
        # 定时器
        self.timer = self.create_timer(0.1, self.timer_callback)
        
    def vel_callback(self, msg):
        """接收 ROS2 速度指令并发送到仿真"""
        self.get_logger().info(f'收到速度指令: {msg.linear.x}')
        # 在这里将 Twist 指令转换为仿真中的关节控制
        
    def timer_callback(self):
        """定时发布仿真状态"""
        try:
            sim_time = self.sim.getSimulationTime()
            msg = Float32()
            msg.data = sim_time
            self.pub.publish(msg)
        except Exception as e:
            self.get_logger().warn(f'仿真连接错误: {e}')

def main(args=None):
    rclpy.init(args=args)
    node = CoppeliaSimROS2Bridge()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

## simROS2 完整 API

```lua
-- 发布/订阅
simROS2.createPublisher(topic, msgType)
simROS2.shutdownPublisher(pub)
simROS2.createSubscription(topic, msgType, callbackName)
simROS2.shutdownSubscription(sub)
simROS2.publish(pub, msg)

-- 服务
simROS2.createService(serviceName, srvType, callbackName)
simROS2.shutdownService(srv)

-- 客户端
simROS2.createClient(serviceName, srvType)
simROS2.shutdownClient(client)
simROS2.waitForService(client, timeout)
simROS2.callService(client, req)

-- TF
simROS2.publishTransform(objectHandle, parentFrame, childFrame)
simROS2.sendTransform(transformStamped)

-- 时钟
simROS2.createClockPublisher()
simROS2.shutdownClockPublisher()

-- 仿真控制（使用 Helper Tool）
-- 通过话题控制仿真启停
-- /coppeliaSim/start  (std_srvs/srv/Trigger)
-- /coppeliaSim/stop   (std_srvs/srv/Trigger)
-- /coppeliaSim/pause  (std_srvs/srv/Trigger)
```

## ROS1 vs ROS2

| 特性 | ROS1 (simROS) | ROS2 (simROS2) |
|------|---------------|----------------|
| 中间件 | TCPROS/UDPROS | DDS |
| 实时支持 | 有限 | 原生支持 |
| 多机通信 | 需配置 ROS_MASTER | 自动发现 |
| 安全性 | 无 | DDS 安全 |
| 插件文件 | `libsimROS.so` | `libsimROS2.so` |
| 生命周期 | 停止维护 | 持续更新 |

## 常见问题

1. **插件加载失败** — 确认启动前已 `source` ROS2 环境
2. **包编译失败** — 检查 `COPPELIASIM_ROOT_DIR` 环境变量
3. **消息类型不支持** — 使用 ROS2 内置类型或自定义消息（需编译）
