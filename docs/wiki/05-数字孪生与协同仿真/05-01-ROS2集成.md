# ROS2 集成

## 概述

CoppeliaSim 通过 **ROS2 Interface 插件**（`libsimROS2.*`）实现对 ROS2 的全功能集成。该插件以较高保真度复刻了 C++ 的 ROS2 API，是利用 ROS2 进行灵活分布式通信的推荐方式。CoppeliaSim 由此可作为 **ROS2 节点**接入 ROS2 网络，其他节点可经 **topic / service / action** 与之交互。

ROS2 本身是一个分布式伪操作系统，便于在联网的多台计算机间管理与通信。插件 API 函数统一以 `simROS2` 为前缀（参见 `index/simROS2.json`）。

> 权威来源：`ros2Interface.htm`（概念）、`ros2Tutorial.htm`（教程）、`simROS2.htm`（API 参考）。

## 插件加载

ROS2 Interface 以插件形式提供，脚本侧通过 `require` 加载（Python 与 Lua 写法一致）：

```python
simROS2 = require('simROS2')
```
```lua
simROS2 = require('simROS2')
```

加载后请留意 CoppeliaSim 终端/控制台窗口关于插件加载的输出。成功加载后，节点列表可见：

```bash
$ ros2 node list
/sim_ros2_interface
```

## 环境与编译

- **前提**：已按官方 ROS2 教程安装 ROS2，并 source 了 ROS2 环境（启动 CoppeliaSim 前）。
- **插件文件**：Linux 发行版的 `CoppeliaSim/compiledROSPlugins/` 已附带预编译的 `libsimROS2.so`，需复制到 `CoppeliaSim/` 根目录才会被加载。
- **自编译**：若预编译版本无法加载，可在 `simROS2/meta/` 编辑所需消息/服务后重新编译。源码包含两个包：
  - `simROS2`：编译为 `.so`，被 CoppeliaSim 加载的 ROS2 Interface。
  - `ros2_bubble_rob`：极简机器人控制器节点，配合 `controlTypeExamples/controlledViaRos2.ttt` 演示外部节点经 ROS2 控制 CoppeliaSim 中的机器人。
- **构建**（将上述包复制到 `ros2_ws/src` 后）：

```bash
export COPPELIASIM_ROOT_DIR=~/path/to/coppeliaSim
ulimit -s unlimited          # 否则编译可能卡死/崩溃
colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release
```

编译产物会自动复制到 CoppeliaSim 安装目录。启动前务必先 source ROS2 与工作区环境。

## Topic 发布与订阅

### Lua 示例（节选自官方教程）

脚本附加到场景对象（非线程仿真脚本），同时发布并订阅 `/simulationTime`，并发布该对象的 TF：

```lua
function subscriber_callback(msg)
    sim.addLog(sim.verbosity_scriptinfos, 'subscriber received Float32: '..msg.data)
end

function getTransformStamped(objHandle, name, relTo, relToName)
    local t = simROS2.getSystemTime()
    local p = sim.getObjectPosition(objHandle, relTo)
    local o = sim.getObjectQuaternion(objHandle, relTo)
    return {
        header = { stamp = t, frame_id = relToName },
        child_frame_id = name,
        transform = {
            translation = {x = p[1], y = p[2], z = p[3]},
            rotation    = {x = o[1], y = o[2], z = o[3], w = o[4]}
        }
    }
end

function sysCall_init()
    sim = require('sim')
    simROS2 = require('simROS2')
    objectHandle = sim.getObject('..')
    objectAlias  = sim.getObjectAlias(objectHandle, 3)
    publisher   = simROS2.createPublisher('/simulationTime', 'std_msgs/msg/Float32')
    subscriber  = simROS2.createSubscription('/simulationTime', 'std_msgs/msg/Float32', 'subscriber_callback')
end

function sysCall_actuation()
    simROS2.publish(publisher, {data = sim.getSimulationTime()})
    simROS2.sendTransform(getTransformStamped(objectHandle, objectAlias, -1, 'world'))
    -- 多个 TF 一次性发布用 simROS2.sendTransforms(tableOfTransforms)
end

function sysCall_cleanup()
    -- 仿真脚本中非必需（仿真结束自动关闭）：
    simROS2.shutdownPublisher(publisher)
    simROS2.shutdownSubscription(subscriber)
end
```

命令行验证：

```bash
$ ros2 topic list
$ ros2 topic echo /simulationTime
```

### Python 脚本示例（等价写法）

CoppeliaSim 4.10 仿真脚本同样支持 Python，官方教程给出等价实现：

```python
def subscriber_callback(msg):
    sim.addLog(sim.verbosity_scriptinfos, f'subscriber received Float32: {msg["data"]}')

def getTransformStamped(objHandle, name, relTo, relToName):
    t = simROS2.getSystemTime()
    p = sim.getObjectPosition(objHandle, relTo)
    o = sim.getObjectQuaternion(objHandle, relTo)
    return {
        'header': {'stamp': t, 'frame_id': relToName},
        'child_frame_id': name,
        'transform': {
            'translation': {'x': p[0], 'y': p[1], 'z': p[2]},
            'rotation': {'x': o[0], 'y': o[1], 'z': o[2], 'w': o[3]}
        }
    }

def sysCall_init():
    global sim, simROS2, objectHandle, objectAlias, publisher, subscriber
    sim = require('sim')
    simROS2 = require('simROS2')
    objectHandle = sim.getObject('..')
    objectAlias  = sim.getObjectAlias(objectHandle, 3)
    publisher  = simROS2.createPublisher('/simulationTime', 'std_msgs/msg/Float32')
    subscriber = simROS2.createSubscription('/simulationTime', 'std_msgs/msg/Float32', subscriber_callback)

def sysCall_actuation():
    simROS2.publish(publisher, {'data': sim.getSimulationTime()})
    simROS2.sendTransform(getTransformStamped(objectHandle, objectAlias, -1, 'world'))

def sysCall_cleanup():
    simROS2.shutdownPublisher(publisher)
    simROS2.shutdownSubscription(subscriber)
```

## Service 与 Action

ROS2 Interface 同样支持 service 与 action。关键 API（以 `index/simROS2.json` 实际命名为准）：

```lua
-- Service 服务端
local srv = simROS2.createService('/trigger', 'std_srvs/srv/Trigger', 'service_callback')
-- 回调：单参数 table（请求负载），须返回 table（响应）
function service_callback(req)
    -- 处理 req，返回响应
    return {success = true, message = 'done'}
end
simROS2.shutdownService(srv)

-- Service 客户端
local cli = simROS2.createClient('/trigger', 'std_srvs/srv/Trigger')
if simROS2.waitForService(cli, 2.0) then
    local resp = simROS2.call(cli, {request = true})
end
simROS2.shutdownClient(cli)

-- Action
local ac = simROS2.createActionClient('/fibonacci', 'example_interfaces/action/Fibonacci',
    'goalRespCb', 'feedbackCb', 'resultCb')
simROS2.sendGoal(ac, {order = 5})
-- 取消最近一次 goal：
simROS2.cancelLastGoal(ac)
simROS2.shutdownActionClient(ac)

local as = simROS2.createActionServer('/fibonacci', 'example_interfaces/action/Fibonacci',
    'handleGoalCb', 'handleCancelCb', 'handleAcceptedCb')
simROS2.actionServerActionExecute(as, goalUUID)
simROS2.actionServerPublishFeedback(as, goalUUID, {partial_sequence = {1, 1, 2}})
simROS2.actionServerActionSucceed(as, goalUUID, {sequence = {1, 1, 2, 3, 5}})
simROS2.shutdownActionServer(as)
```

回调中可使用枚举：`simROS2.goal_response`（`reject` / `accept_and_execute` / `accept_and_defer`）、`simROS2.cancel_response`（`reject` / `accept`）、`simROS2.action_result_code`（`succeeded` / `aborted` / `canceled` / `unknown`）。

## Stepping 模式与 ROS2 同步

**ros2Interface helper tool** 是一个由单个 customization script 构成的模型（`Models/tools/ros2Interface helper tool.ttm`），提供如下 topic：

| Topic | 消息类型 | 说明 |
|-------|---------|------|
| `/startSimulation` | `std_msgs/msg/Bool` | 发布启动仿真 |
| `/pauseSimulation` | `std_msgs/msg/Bool` | 暂停仿真 |
| `/stopSimulation`  | `std_msgs/msg/Bool` | 停止仿真 |
| `/enableSyncMode`  | `std_msgs/msg/Bool` | 启用/关闭 stepping 模式 |
| `/triggerNextStep` | `std_msgs/msg/Bool` | 在 stepping 模式下触发下一仿真步 |
| `/simulationStepDone` | `std_msgs/msg/Bool` | 每个仿真步结束时发布 |
| `/simulationState` | `std_msgs/msg/Int32` | 0=停止、1=运行、2=暂停 |
| `/simulationTime`  | `std_msgs/msg/Float32` | 当前仿真时间 |

命令行触发示例：

```bash
$ ros2 topic pub /enableSyncMode   std_msgs/msg/Bool '{data: true}' --once
$ ros2 topic pub /startSimulation  std_msgs/msg/Bool '{data: true}' --once
$ ros2 topic pub /triggerNextStep  std_msgs/msg/Bool '{data: true}' --once
$ ros2 topic pub /triggerNextStep  std_msgs/msg/Bool '{data: true}' --once
$ ros2 topic pub /stopSimulation   std_msgs/msg/Bool '{data: true}' --once
```

stepping 模式让外部 ROS2 节点成为"节拍主导者"：每次外部发布一个 `/triggerNextStep`，CoppeliaSim 推进一步，并在步末经 `/simulationStepDone` 回告完成。这与本仓库 Python 端 `sim.setStepping(True)` + `sim.step()` 的时钟主控思路同源，适合精确工业节拍时序。customization script 内容可自由裁剪以适配不同需求。

## 常用 API 速查

下表为 ROS2 Interface 最常用 API（完整列表见 `index/simROS2.json` 与 `simROS2.htm`）：

| 函数 | 说明 |
|------|------|
| `simROS2.createPublisher(topic, type, unused=0, unused2=false, qos=nil)` | 创建发布者，返回 handle |
| `simROS2.createSubscription(topic, type, callback, unused=0, qos=nil)` | 创建订阅者，回调单参为消息 table |
| `simROS2.publish(pub, msg)` | 发布消息 |
| `simROS2.shutdownPublisher(pub)` / `shutdownSubscription(sub)` | 关闭发布/订阅 |
| `simROS2.createService(name, type, callback)` | 创建服务端，回调返回响应 table |
| `simROS2.createClient(name, type)` | 创建服务客户端 |
| `simROS2.waitForService(client, timeout)` | 等待服务可用，超时返回 false |
| `simROS2.call(client, request)` | 调用服务，返回响应 table |
| `simROS2.createActionClient(...)` / `createActionServer(...)` | Action 客户端/服务端 |
| `simROS2.sendGoal(client, goal)` / `cancelLastGoal(client)` | 发送/取消目标 |
| `simROS2.actionServerActionExecute/Succeed/Abort/Canceled(...)` | 服务端 goal 状态迁移 |
| `simROS2.actionServerPublishFeedback(server, uuid, feedback)` | 发布 feedback |
| `simROS2.sendTransform(tf)` / `sendTransforms(tfs)` | 发布 TF（`geometry_msgs/TransformStamped`） |
| `simROS2.createInterface(type)` | 构造默认值消息对象 |
| `simROS2.supportedInterfaces()` | 返回支持的接口列表 |
| `simROS2.getInterfaceConstants(type)` | 获取接口中定义的常量 |
| `simROS2.importInterface(name)` | 导入接口（如 `geometry_msgs/msg/Vector3`） |
| `simROS2.spinSome()` | 调用 `spin_some(node)`，驱动回调 |
| `simROS2.getSystemTime()` / `getSimulationTime()` / `getTime()` | 时间相关 |
| `simROS2.getParam*/setParam*/hasParam/deleteParam` | ROS 参数服务读写 |
| `*TreatUInt8ArrayAsString(handle)` | 将 uint8 数组按字符串处理（Lua 中更快） |

QoS 与时间等结构/枚举（`simros2_qos`、`simros2_time`、`clock_type`、`qos_*_policy` 等）定义见 `simROS2.htm` 末尾 Constants 段。消息回调签名见 `scriptfun:subscriptionCallback` 等。

## 与 ZMQ Remote API 的取舍

官方教程结尾明确指出：**Remote API** 支持多语言、跨平台、轻量、易于远程函数执行与快速双向数据流，在许多场景下是 ROS 的有趣替代。

| 维度 | ROS2 Interface | ZMQ Remote API |
|------|----------------|-----------------|
| 定位 | 接入 ROS2 生态（topic/service/action、TF、DDS 自动发现、QoS） | 轻量远程函数调用 + 数据流 |
| 依赖 | 需 ROS2 环境/DDS、编译插件 | 仅一个 ZMQ add-on，跨平台开箱即用 |
| 语言 | 脚本内 `require('simROS2')`（Python/Lua） | 7 种语言客户端（含 Python `coppeliasim_zmqremoteapi_client`） |
| 生态 | rviz2、ros2 bag、nav2、MoveIt2 等 ROS2 工具链直接可用 | 无 ROS 生态绑定，适合独立控制程序 |
| 时钟同步 | stepping + helper tool 可让外部节点主控节拍 | Python 端 `sim.setStepping` + `sim.step()` 直接主控 |
| 适用 | 需要与 ROS2 节点/工具链集成、多机分布式、数字孪生接入 ROS 拓扑 | 控制程序自包含、追求轻量、本仓库工厂仿真编排 |

本仓库工厂仿真（[[wiki/05-数字孪生与协同仿真/05-03-Python客户端集成]]）即采用 ZMQ Remote API 作为时钟主控方案，详见 [[wiki/01-API参考/01-02-Remote-API-ZMQ]]。

## 常见问题

1. **插件加载失败** — 启动 CoppeliaSim 前未 source ROS2 环境，或 `.so` 未复制到安装根目录；检查终端输出。
2. **编译卡死/崩溃** — 未执行 `ulimit -s unlimited`。
3. **消息/服务类型缺失** — 在 `simROS2/meta/` 中补齐后重新编译插件。
4. **回调不触发** — 非线程脚本需让出执行以驱动 `spin_some`；stepping 模式下用 `/triggerNextStep` 推进。
