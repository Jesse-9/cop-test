# 接近传感器 Proximity Sensor

> CoppeliaSim 中的接近传感器以**几何精确**方式检测位于其**检测体积**内的 **detectable 对象**（可探测实体），计算传感点与被测对象之间的最小距离，并能模拟超声、红外、激光、电感、电容等各类接近传感器。

## 工作原理

接近传感器执行的是**精确距离计算**，而非多数仿真软件所做的检测体积边缘的简单碰撞检测：

```
最小距离 = dist( sensing point ↔ (detectable entity ∩ detection volume) )
```

- **Sensing point**（传感点）是一个小球，计算时始终视为一个点（显示大小不影响计算）。
- 仅当某 detectable 对象与检测体积相交时，才参与距离计算。
- 命中后触发 trigger，并调用 trigger callback function。

底层检测例程以独立形式开放于 **Coppelia geometric routines**（见 [[wiki/03-运动规划与控制/03-04-几何计算-simGeom]]），可供脚本直接调用做几何查询。

## 六种检测体积类型

接近传感器有 6 种检测体积类型，可高度定制：

| 类型 | 适用场景 | 精度/性能 |
|------|---------|----------|
| **Ray-type**（射线型） | 最简单的接近传感器、激光测距仪 | 最快 |
| **Randomized ray-type**（随机射线型） | 类似锥型外观，随机扫描锥体积 | 快 |
| **Pyramid-type**（金字塔型） | 矩形检测体积 | 快 |
| **Cylinder-type**（圆柱型） | 回转检测体积 | 快 |
| **Disk-type**（圆盘型） | 回转扫描检测体积，精度高 | 精度高，计算较重 |
| **Cone-type**（圆锥型） | 最精确建模多数接近传感器 | 精度最高，计算较重 |

体积参数（见 proximity sensor volume dialog）：

- **Face count / Face count far / Subdivisions / Subdivisions far**：控制检测体积描述精度，精度越高计算时间越长。
- **Inside gap**（仅 disc / cone 型，取值 0–1）：按比例移除部分体积，可组合多个传感器构造复杂检测体积。

## 检测参数

Detection parameter dialog 提供以下过滤项：

- **Front / back face detection**：决定传感器能看到三角面的哪一侧（前向面蓝色、背向面红色，对应 triangle edit mode）。
- **Fast detection (approximate)**：近似快速检测，检测到的点可能不是最近点。
- **Limited angle detection**：限制检测射线与被测面法线之间的最大夹角。超声传感器常需此特性（无法探测不够"正对"的表面）；角度很小时计算量显著上升。
- **Don't allow detections if distance smaller than**（mask distance）：最小检测距离。当有物体进入该盲区时，传感器直接禁用检测（模拟真实超声等传感器的近场盲区，远端物体也不会被"看穿"）。

## Detectable 对象

可被接近传感器检测的对象类型（见 detectableObjects.htm）：

- **Dummies**（虚拟点）
- **Shapes**（形状）
- **OC trees**（八叉树）
- **Point clouds**（点云）
- **Collections**（集合，因可包含上述对象）

注意：Dummies 与 point clouds 是点状的，**不能**被 ray-type 或 randomized ray-type 检测。

### Detectable 属性

- 每个对象可单独启用/禁用针对**全部**或**特定子类**接近传感器的 detectable 属性（非基本形状默认启用）。
- 可在 general scene object properties dialog 设置，或通过 `sim.setObjectSpecialProperty`（已弃用，4.10 推荐用 [[wiki/02-仿真建模/02-10-集合-Collections|properties]] 机制）/ `sim.setObjectProperty` API 设置。
- 子类按物理原理分类：Ultrasonic / Infrared / Laser / Inductive / Capacitive。
- 若对象属于某 model，其 detectable 属性可被 model 属性覆盖（见 model dialog）。

## 与视觉传感器的区别

| 维度 | 掁近传感器 Proximity Sensor | 视觉传感器 Vision Sensor |
|------|---------------------------|------------------------|
| 检测方式 | 几何精确距离计算（连续体积内求最小距离） | 渲染图像后做图像处理 |
| 输出 | 距离、检测点、被测对象句柄、法线 | 图像/深度图、浮点缓冲 |
| 计算开销 | 较低（几何运算） | 较高（完整渲染管线） |
| 适用场景 | 测距、避障、触发检测 | 视觉识别、图像处理、场景感知 |

两者是不同的场景对象类型，不可互换。详见 [[wiki/04-感知与视觉/04-02-视觉传感器]]。

## 显式处理（Explicit Handling）

在 proximity sensor dialog 中可勾选 **Explicit handling**：

- 勾选后，`sim.handleProximitySensor(sim.handle_all_except_explicit)` 不会处理该传感器；
- 仅 `sim.handleProximitySensor(sim.handle_all)` 或直接传句柄时才处理。

用于在 simulation script 中自行控制处理时机，避免主脚本和仿真脚本各处理一次导致重复。

## 相关 API

| 函数 | 作用 |
|------|------|
| `sim.handleProximitySensor(sensorHandle)` | 执行检测（处理一次），返回检测结果 |
| `sim.readProximitySensor(sensorHandle)` | 仅读取上次 `handle` 的结果，不执行检测 |
| `sim.checkProximitySensor(sensorHandle, entityHandle)` | 静默检测指定实体（无视觉反馈），覆盖 detectable 标志 |
| `sim.checkProximitySensorEx` / `sim.checkProximitySensorEx2` | 扩展静默检测 |
| `sim.resetProximitySensor(sensorHandle)` | 清除检测状态、检测颜色、检测线段等 |
| `sim.createProximitySensor(...)` | 运行时创建接近传感器 |

`handle` 与 `read` 的区别：`handle` 执行实际探测并产生视觉反馈（检测射线/颜色），`read` 只读取上次 `handle` 缓存的状态。`check` 系列静默探测，适合脚本内的几何查询，不影响视觉显示。

## Python 示例

通过 ZMQ Remote API 读取接近传感器检测结果（4.10）：

```python
from coppeliasim_zmqremoteapi_client import RemoteAPIClient

client = RemoteAPIClient()
sim = client.require('sim')

# 通过路径获取接近传感器句柄
sensor = sim.getObject('/sensor')

# 执行一次检测（处理该传感器）
res, dist, point, obj, n = sim.handleProximitySensor(sensor)
if res == 1:
    print(f"检测到对象 handle={obj}, 距离={dist:.4f} m")
    print(f"检测点(传感器系)={point}, 法线={n}")
else:
    print("未检测到对象")

# 静默检测指定实体（不产生视觉反馈，覆盖 detectable 标志）
target = sim.getObject('/target')
res, dist, point, obj, n = sim.checkProximitySensor(sensor, target)

# 静默检测所有 detectable 对象
res, dist, point, obj, n = sim.checkProximitySensor(sensor, sim.handle_all)

# 清除检测状态
sim.resetProximitySensor(sensor)
```

> 单位说明：Regular API 中距离单位为米（见 apiFunctions.htm 声明）。检测点 `point` 与法线 `n` 均相对于传感器参考系。

## 添加方式

通过菜单 **Add > Proximity sensor** 将接近传感器添加到场景。检测体积、检测参数、显式处理等均在选中传感器后通过 **Tools > Scene object properties** 打开的 proximity sensor dialog 配置。
