# 形状与几何体（Shape）

> Shape 是由三角面构成的刚性网格对象，可导入/导出和编辑。它是 CoppeliaSim 中最基础的可见几何实体，也是碰撞检测、距离计算与近邻感知的基本参与者。

## 七种子类型

Shape 按内部几何表达分为七种子类型，各自对动力学碰撞响应的适用性差异显著：

| 子类型 | 网格形态 | 颜色/视觉属性 | 动力学碰撞响应 |
|--------|----------|---------------|----------------|
| **Simple shape**（简单形状） | 任意网格 | 单一颜色 | 慢且不稳定，不推荐 |
| **Compound shape**（复合形状） | 任意网格（多组） | 多组颜色 | 慢且不稳定，不推荐 |
| **Convex shape**（凸形状） | 凸网格 | 单一颜色 | 已优化，但仍推荐 primitive |
| **Compound convex shape**（复合凸形状） | 多个凸网格 | 多组颜色 | 已优化，但仍推荐 primitive compound |
| **Primitive shape**（原始形状） | 长方体/圆柱/球（随物理引擎有额外变体） | 单一颜色 | **最快且最稳定，首选** |
| **Primitive compound shape**（复合原始形状） | 多个 primitive 组 | 多组颜色 | **最快且最稳定，首选** |
| **Heightfield shape**（高程场形状） | 规则网格、仅高度变化 | —— | 已优化，视为 primitive |

**关键原则**：导入的形状默认均为 simple shape。primitive shape（或 primitive compound shape）最适合动力学碰撞响应计算——速度快、稳定性高。primitive 形状常被隐藏在不可见层（如 layer 9），仅由物理引擎使用，视觉上由更精细的网格代替展示。详见动力学设计章节。

### 组合规则

- **group/ungroup**（[Edit > Shape grouping/merging > group/ungroup]）：作用于两个及以上的 shape 或 compound shape，生成 compound shape。primitive 组合后的 compound 只有当所有分量都是 primitive 时才保持 primitive 性质。
- **merge/divide**（[Edit > Shape grouping/merging > merge/divide]）：仅作用于 simple shape。**合并 primitive 会得到非 primitive 的 simple shape**——primitive 性质丢失。
- compound shape 不能直接编辑，需先 ungroup，或在其编辑模式下调整各分量视觉属性。

## Primitive Shape 创建与参数

除从外部文件导入网格外，可在场景中直接创建 primitive：[Add > Primitive shape]。参数在 primitive shape 对话框调整：

- **X-/Y-/Z-size**：沿世界坐标系三轴尺寸。
- **X-/Y-/Z-Subdivisions**：三轴方向的单元细分数。细分本身不直接可见、也无直接物理效果，但影响光照反射的细致程度。
- **Smooth shaded**：Gouraud 平滑着色，否则棱角分明。
- **Open ends**：圆柱端面是否开放。
- **Sides**：圆柱/圆盘/球的边数。
- **Face/Disc subdivisions**：圆柱面/圆盘细分。
- **Dynamic and respondable**：生成即启用动力学并响应碰撞（事后可改）。
- **Material density**：材料密度。

颜色与其他视觉属性在 shape 对话框（[Tools > Scene object properties] 或双击层次树图标）中调整，网格可在编辑模式或几何对话框中修改。

## 编辑模式（共四种）

当外部 CAD 不可用或仅需简单定制时，可创建 primitive 后在编辑模式修改。**primitive 在进入编辑模式前会先转换为普通形状**。

| 编辑模式 | 可见/可操作元素 | 典型操作 |
|----------|-----------------|----------|
| **Triangle edit mode**（三角面） | 单个三角面 | 选取、抽取、删除三角面 |
| **Vertex edit mode**（顶点） | 顶点（红色显示，选中黄色，末选白色） | 精确移动、复制/粘贴/删除；插入三角面/三角扇 |
| **Edge edit mode**（边） | 边（同色规则） | 删除边；Automatic Edge Following 沿环提取全局边 |
| **Edit mode for compound shapes**（复合形状编辑） | compound 各分量 | 调整颜色/纹理/着色角/背面剔除等视觉属性（不触及几何） |

进入编辑模式需先选中一个 shape；编辑期间无法选中其他对象、无法启动仿真。点击工具栏 shape edit mode 按钮退出。CoppeliaSim 会自动维护网格一致性——移除未用顶点、合并相近顶点，具体行为在 user settings 的 Vertices/triangles verification 设置中调整。

**模式切换技巧**：可在三种简单编辑模式间无缝切换且保留选区。例如要删除圆柱上表面所有三角面，不必在 triangle 模式逐个选——在 vertex 模式 shift 框选上表面顶点，切到 triangle 模式，按 delete 即可。

### 顶点编辑要点

- 选中顶点后可用 ctrl-c/ctrl-x/ctrl-v/delete 快捷键。
- shift 框选默认包含隐藏顶点；按住 ctrl+shift 仅选可见顶点。
- 顶点列表显示在原本层次树的位置，可像对象一样点选。
- 顶点可经 coordinate and transformation dialog 精确定位，或用对象平移工具栏按钮在视图垂面内拖动。
- Insert Triangles / Insert Triangle Fan：在选中顶点间插入三角面，**选择顺序很重要**；三角扇以最后选中顶点为中心。

### 边编辑要点

- 边可删除但不能复制/剪切/粘贴。
- **Automatic Edge Following**：选中一条边后自动沿同一方向延伸选取，直至成环、方向突变（Max. dir. change angle）或边消失（Max. edge angle）。用于抽取"全局边"而非单个三角形的一条边。仅在单一方向跟随。

### 复合形状编辑模式

仅在选中 compound shape 时激活（若选的是 simple shape 则进入 triangle 模式）。可调：颜色、纹理、shading angle（面区分的临界角，小则锐利多棱、大则平滑少棱）、Show edges（黑色显示边）、Backface culling（剔除内面，利于封闭体和透明体）。

## 凸包与凸分解

凸包与凸分解用于把复杂/非凸网格转化为适合动力学计算的碰撞体。

### 凸包（Convex hull）

凸包是包围一组网格的最小凸包络。CoppeliaSim 可对**可测量对象（measurable）**计算凸包：选中对象后 [Modules > Geometry / Mesh > Convex hull...]。

用途：
- 距离计算、近邻传感器仿真可大幅加速。
- 用复杂形状的凸包近似替代，碰撞检测更快。
- 典型做法：抽取整个模型（如机器人）的凸包，将其设为不可见，所有计算（碰撞/距离）都走不可见的凸包而非复杂本体。

参见 simConvex API 与凸分解。

### 凸分解（Convex decomposition）

凸形状在动力学碰撞响应中比任意网格更快更稳定（但仍不及 primitive）。凸分解把一个非凸形状拆成一组凸形状：

[Modules > Geometry / Mesh > Convex decomposition]

用途：为动力学准备碰撞体——非凸模型无法直接作凸形状，分解后得到的复合凸形状可被物理引擎高效处理。参见 simOpenMesh API 与凸包。

## Shape 参考系与包围盒

每个 shape 都有参考系和包围盒，且**参考系可重定位、包围盒可修改，而不影响其他属性**。

参考系移动（[Edit > Shape reference frame]）：
- **relocate to world origin**：移到世界原点。
- **relocate to mesh center**：移到包围盒中心。

包围盒修改（[Edit > Shape bounding box]）：
- **align with world**：包围盒对齐世界参考系。
- **align with mesh**：选择使包围盒体积最小的朝向。

> 惯性属性不受参考系移动影响，但惯性矩阵和质心会相对于新参考系重新表达。包围盒朝向不必与参考系朝向一致。

相关 API：sim.relocateShapeFrame、sim.alignShapeBB、sim.setShapeBB、sim.scaleObject。

## Shape 属性对话框

在场景对象属性对话框（[Tools > Scene object properties] 或双击层次树图标）中点 Shape 按钮打开。常用项：

- **Color**：编辑颜色。
- **Shading angle**：面区分临界角（仅视觉效果）。小则锐利多棱，大则平滑少棱。
- **Show edges**：黑色显示边。
- **Backface culling**：剔除内面（封闭体/透明体有用）。
- **Invert faces**：翻转所有三角面（内外面互换）；凸形状将变非凸，primitive 例外。
- **Texture**：打开纹理对话框；Quick textures 给所有选中 shape 施加立方映射纹理（适合作"污渍"无缝纹理以增真实感）；Clear textures 清除纹理。
- **Geometry**：打开几何对话框，调整网格各种参数。
- **Dynamic properties dialog**：切换 shape 动力学属性对话框。

> 部分参数仅 simple shape 可用。compound shape 需在复合形状编辑模式下编辑各分量视觉属性，或先 ungroup 再单独编辑。

## 可碰撞/可测量/可检测

Shape 是 **collidable、measurable、detectable** 对象：

- **collidable**：可参与与其他可碰撞对象的碰撞检测。
- **measurable**：可参与与其他可测量对象的最小距离计算。
- **detectable**：可被近邻传感器检测到。

这三项属性在 general scene object properties 对话框修改；若 shape 属于某 model，可被 model 的覆盖设置 override。相关几何计算（碰撞、距离、近邻）亦作为独立例程经 Coppelia geometric routines 提供。

## 代码示例（Python ZMQ Remote API）

### 创建 primitive shape

```python
from coppeliasim_zmqremoteapi_client import RemoteAPIClient

client = RemoteAPIClient()
sim = client.require('sim')

# 创建一个 0.5 x 0.5 x 0.5 立方米的长方体 primitive
# primitiveType 见 sim.primitive_shape_cuboid 等常量
cuboid = sim.createPrimitiveShape(
    sim.primitive_shape_cuboid,
    [0.5, 0.5, 0.5],
    0  # options: bit0 背面剔除, bit1 锐利边, bit2 圆柱开放端, bit3 不作 primitive 注册
)
sim.setObjectAlias(cuboid, '/myCuboid')
```

### 读取 shape 网格

```python
# 取回某 shape 的顶点/索引/法线
vertices, indices, normals = sim.getShapeMesh(cuboid)
print(f'vertices: {len(vertices) // 3} 个顶点')
print(f'indices : {len(indices) // 3} 个三角面')
```

### 重定位参考系与对齐包围盒

```python
# 将参考系移到包围盒中心，包围盒对齐网格使体积最小
sim.relocateShapeFrame(cuboid, [*sim.getShapeBB(cuboid)[:3]])  # 示例：API 用法见 sim.relocateShapeFrame 文档
sim.alignShapeBB(cuboid, sim.alignstr)  # 具体常量见 API 文档
```
