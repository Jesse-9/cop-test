# 关节与关节模式

> 关节（Joint）是连接父子对象、允许二者相对运动的对象。父对象-关节-子对象的层级建立后，子对象附连到关节的**第二参考系**，关节线/角位置的变化会直接反映到其所有子对象上。

## 4 种关节类型

通过菜单 `Add > Joints` 添加。所有关节的相对运动均沿/绕其参考系的 **z 轴**进行。

| 类型 | 自由度 (DoF) | 运动 | 说明 |
|------|------|------|------|
| **Revolute**（旋转） | 1 | 绕 z 轴旋转 | 描述对象间相对转动。可设为 cyclic（位置在 ±180° 间循环） |
| **Prismatic**（平移） | 1 | 沿 z 轴平移 | 描述对象间相对平动 |
| **Screw**（螺旋） | 1 | 沿 z 轴螺旋 | 可视为旋转+平移的联动组合；**lead** 参数定义每转一圈的平移量。仅当 revolute/screw 型、非 cyclic 且 kinematic 模式下可设 lead |
| **Spherical**（球关节） | 3 | 三维旋转 | 描述三维旋转。内部特殊处理以避免奇异性 |

### 球关节 vs 3 串联 revolute

球关节在几何上可类比为 3 个正交串联的 revolute 关节，但二者**仅在所有 revolute 方位互不重合时等价**：一旦两个 revolute 轴接近重合，机构进入奇异位形并丢失 1 个 DoF。球关节内部按整体处理，**不会出现这种奇异性**，因此在需要三轴自由旋转的场合应优先使用球关节而非 3 串联 revolute。

## 3 种关节模式（Joint Mode）

关节模式决定其位置如何被求解，由 Joint 对话框的 `Mode` 字段或 `sim.setJointMode` 设置。

| 模式 | 行为 | 由动力学模块处理 | 典型用途 |
|------|------|------|------|
| **Kinematic**（运动学） | 位置可瞬时改变 | 否 | 纯运动学机构、视觉层动画、IK 目标驱动 |
| **Dependent**（依赖） | 位置由另一关节经线性方程确定 | 否 | 联动机构（如平行四连杆的耦合关节） |
| **Dynamic**（动力学） | 由动力学模块求解 | 是（需构成有效动力学配置） | 物理仿真、力/力矩控制、碰撞响应 |

- **Kinematic 模式**：通过 `sim.setJointPosition` 瞬时设位，或通过 `sim.setJointTargetPosition`/`sim.setJointTargetVelocity` 显示运动轮廓，或由 joint callback function 自定义控制。调节时间步等于仿真时间步（默认 50 ms）。
- **Dependent 模式**：通过 Joint 对话框的 **Dependency equation** 指定与另一关节的线性关系（`offset` + `coeff` × 参考关节位置，单位为米或弧度）。
- **Dynamic 模式**：必须与连接对象构成有效配置（dynamically enabled），才由动力学模块处理；否则行为类似 kinematic。调节时间步由动力学模块定义（默认 5 ms，比 kinematic 精细得多）。

## 高层控制 vs 低层控制

关节控制分两层：

### 高层控制（High-level）

通过专用 API 函数下达目标值，由 CoppeliaSim 内部求解：

| 函数 | 作用 | 适用 |
|------|------|------|
| `sim.setJointPosition` | 瞬时设定关节位置 | kinematic 模式（不能用于 spherical） |
| `sim.setJointTargetPosition` | 设定目标位置（按运动轮廓或位置控制器逼近） | kinematic（运动轮廓）/ dynamic position 控制 |
| `sim.setJointTargetVelocity` | 设定目标速度 | kinematic（速度轮廓）/ dynamic velocity 控制 |
| `sim.setJointTargetForce` | 设定目标力/力矩上限 | dynamic force/velocity/position 控制 |

不同模式与控制模式下并非所有函数都有意义：对 kinematic 关节调 `setJointTargetForce`、对 velocity 控制下的 dynamic 关节调 `setJointTargetPosition` 均无效。

### 低层控制（Low-level）

最佳实现方式是 **joint callback function**（关节回调函数），要求关节处于 kinematic 模式或 dynamic 模式。CoppeliaSim 每个调节步调用一次回调，由用户在其中决定施加的力/力矩与目标速度，粒度细到每个调节步都不跳过。

> **deprecated 提示**：旧式 **joint control callback scripts** 已废弃，应改用 joint callback function。已存在的旧脚本仍可运行，但编辑被禁用；如需临时启用编辑，将 `system/usrset.txt` 中的 `enableOldJointCallbackScriptEdition` 设为 `true`。

### 外部应用低层控制

外部应用（如 Python ZMQ Remote API 客户端）**无法使用 joint callback function**，要实现低层控制须满足两点：

1. **stepping 模式**：`sim.setStepping(True)`，由外部应用显式触发每个仿真步（`sim.step()`），保证同步。
2. **dt = 动力学步长**：将仿真时间步设为与动力学模块时间步相同（如 5 ms），以获得精细控制粒度。

这正是本仓库 `cop-test` 的做法——Python 端作为 clock master，`setStepping(True)` 后每次 `sim.step()` 推进一个 `SIM_STEP`（默认 0.05s），控制逻辑与物理引擎严格同步。

## Dynamic 模式下的控制模式（Control Mode）

dynamic 关节在 Joint dynamics dialog 中可设 6 种控制模式：

| 控制模式 | 行为 | 可调制 API |
|------|------|------|
| **Free**（自由） | 非电机驱动，自由运动 | — |
| **Force/torque**（力/力矩控制） | 施加恒定力/力矩 | `sim.setJointTargetForce` |
| **Velocity**（速度控制） | 施加指定力/力矩直到达到目标速度；可选运动轮廓 | `sim.setJointTargetVelocity`、`sim.setJointTargetForce` |
| **Position**（位置控制） | 施加力/力矩并调制速度以到达目标位置 | `sim.setJointTargetPosition`、`sim.setJointTargetForce` |
| **Spring-damper**（弹簧-阻尼控制） | 通过简单 KC 控制器调制力/力矩，趋向零位移位置 | `sim.setJointTargetPosition`、`sim.setJointTargetForce` |
| **Custom**（自定义控制） | 调用 joint callback function，由用户灵活决定力/力矩与目标速度 | 回调函数 |

此外每种物理引擎还提供各自的 Engine properties，详见对应引擎文档以获得最佳参数。

## Joint 对话框关键属性

- **Position is cyclic**：角位置是否循环（±180° 无限旋转）。仅 revolute 可设。
- **Screw lead**：每转一圈的 z 轴位移。仅 revolute/screw 型、非 cyclic、kinematic 模式下可用。
- **Position minimum / Position range**：非 cyclic revolute、screw、prismatic 的位置下限与变化范围；实际位置被限制在 `[minimum, minimum+range]`。
- **Mode**：kinematic / dependent / dynamic。
- **Dependency equation**：dependent 模式下与另一关节的线性关系（米或弧度）。
- **Length / Diameter / Color**：纯视觉属性，无功能含义。
- **Dynamic properties**：打开 Joint dynamics dialog，设置上述控制模式与动力学参数。

## 示例

### 1. kinematic 关节瞬时设位（Python ZMQ Remote API）

```python
from coppeliasim_zmqremoteapi_client import RemoteAPIClient

client = RemoteAPIClient()
sim = client.require('sim')

sim.startSimulation()
# 关节须处于 kinematic 模式；setJointPosition 瞬时生效，不经过运动轮廓
joint = sim.getObject('/robot/joint1')
sim.setJointPosition(joint, 1.57)  # 直接跳到 ~90° (弧度)
sim.stopSimulation()
```

### 2. 单步 stepping 模式驱动目标位置（外部低层控制基础）

```python
from coppeliasim_zmqremoteapi_client import RemoteAPIClient

client = RemoteAPIClient()
sim = client.require('sim')

# 关节处于 kinematic 模式：setJointTargetPosition 按运动轮廓逼近
# 关节处于 dynamic + position 控制：由位置控制器逼近目标
joint = sim.getObject('/robot/joint1')

sim.setStepping(True)           # 外部应用作为 clock master
sim.startSimulation()

target = 1.57                   # 目标角度 ~90°
for _ in range(200):
    sim.setJointTargetPosition(joint, target)
    sim.step()                  # 显式推进一个仿真步

sim.stopSimulation()
```
