# 图与数据可视化 Graphs & Data Streams

> Graph 是一种场景对象，用于在仿真中记录与可视化数据。数据按 **data stream**（数据流，带时间戳的顺序数值列表）存储，可直接绘制为时间曲线（time plot），也可组合 2~3 条流构成 x/y 曲线或 3D 曲线。Graph 的数据流与曲线由用户脚本负责定义并喂数据。

## 数据流与曲线

- **Data stream**：一条带时间戳的数值序列，由 `sim.addGraphStream` 创建，由 `sim.setGraphStreamValue` 在每个仿真步喂数值，由 `sim.handleGraph` 触发记录。
- **Curve**：把 2 条或 3 条 stream 组合成 x/y 或 x/y/z 曲线，用 `sim.addGraphCurve` 创建。stream 也可以单独作为时间曲线直接显示。
- **Static stream/curve**：用 `sim.duplicateGraphCurveToStatic` 把活动流/曲线"冻结"成静态副本，不再可修改，便于回放对比。

## Graph 属性对话框

通过 [Tools > Scene object properties] 打开场景对象属性，选中 Graph 后点击 Graph 按钮进入。关键参数：

| 参数 | 说明 |
|------|------|
| Buffer is cyclic | 勾选后缓冲区满时覆盖最早数据继续记录；否则缓冲满即停止 |
| Buffer size | 每条数据流可记录的元素数 |
| Remove all streams/curves | 清除所有数据流与曲线 |
| Remove all static streams/curves | 仅清除静态流/曲线 |
| Background / Grid color | 时间图 / x/y 图的背景与网格颜色 |

Graph 对象本身由一个 customization script 驱动，可按需修改；其行为也可通过该脚本旁的 user parameter 图标调整。

## 核心 API（以 apiFunctions.htm 为准）

| 函数 | 作用 |
|------|------|
| `sim.addGraphStream` | 创建/更新一条数据流，返回 streamId |
| `sim.setGraphStreamValue` | 为某条流设置当前步数值 |
| `sim.handleGraph` | 触发记录：按各流当前值写入一个数据点 |
| `sim.addGraphCurve` | 由 2~3 条流组合成曲线 |
| `sim.destroyGraphCurve` | 销毁流或曲线（-1 清除全部） |
| `sim.duplicateGraphCurveToStatic` | 把流/曲线冻结为静态副本 |
| `sim.setGraphStreamTransformation` | 对流施加变换（缩放/偏移/滑动平均） |
| `sim.resetGraph` | 清空图的所有数据流 |

## 示例：记录两个关节速度（时间曲线）

```python
# python (simulation script, sysCall 回调)
import math

def sysCall_init():
    sim = require('sim')
    self.joint1Handle = sim.getObject('/joint1')
    self.joint2Handle = sim.getObject('/joint2')
    self.graph = sim.getObject('/Graph')
    # 创建两条数据流，单位 deg/s，分别用红/绿配色
    self.joint1Vel = sim.addGraphStream(self.graph, 'joint 1 velocity', 'deg/s', 0, [1, 0, 0])
    self.joint2Vel = sim.addGraphStream(self.graph, 'joint 2 velocity', 'deg/s', 0, [0, 1, 0])

def sysCall_sensing():
    # 每个仿真步喂数值（rad → deg）
    sim.setGraphStreamValue(self.graph, self.joint1Vel, 180 * sim.getJointVelocity(self.joint1Handle) / math.pi)
    sim.setGraphStreamValue(self.graph, self.joint2Vel, 180 * sim.getJointVelocity(self.joint2Handle) / math.pi)
```

> Graph 的 customization script 会在内部每步调用 `sim.handleGraph`，因此脚本中通常只需 `setGraphStreamValue` 喂数据；若自行管理记录时机，则需显式调用 `sim.handleGraph(graph, sim.getSimulationTime())`。

## 示例：记录物体 x/y 轨迹（x/y 曲线）

```python
# python
def sysCall_init():
    sim = require('sim')
    self.objectHandle = sim.getObject('/object')
    self.graph = sim.getObject('/Graph')
    # 两条隐藏的时间流（仅作为曲线数据源）
    self.objectPosX = sim.addGraphStream(self.graph, 'object pos x', 'm', 1)
    self.objectPosY = sim.addGraphStream(self.graph, 'object pos y', 'm', 1)
    # 组合成二维 x/y 曲线
    sim.addGraphCurve(self.graph, 'object pos x/y', 2,
                      [self.objectPosX, self.objectPosY], [0, 0], 'm by m')

def sysCall_sensing():
    pos = sim.getObjectPosition(self.objectHandle)
    sim.setGraphStreamValue(self.graph, self.objectPosX, pos[0])
    sim.setGraphStreamValue(self.graph, self.objectPosY, pos[1])
```

## 数据流变换

`sim.setGraphStreamTransformation` 可在不修改喂数据逻辑的前提下对显示值做变换：

```python
# python
# 对流做缩放 ×2、偏移 +1、滑动平均周期 10
sim.setGraphStreamTransformation(graph, streamId, 0, 2.0, 1.0, 10)
```

参数：`trType`（变换类型，0=线性）、`mult`（乘子）、`off`（偏移）、`movingAvgPeriod`（滑动平均周期，1=不做平均）。对循环量（如角度）可在 `addGraphStream` 时设 `cyclicRange` 以便正确插值。

## 更广义的数据可视化与输出

除 Graph 外，CoppeliaSim 还支持多种数据可视化/输出方式（见 dataVisualizationAndOutput.htm）：

- **自定义 UI**：用 simUI（基于 XML 的界面）实时显示数值。
- **场景叠加图元**：`sim.addDrawingObject` / `sim.addDrawingObjectItem` 绘制点、线、球、三角形等临时可视化。
- **状态栏/终端日志**：`sim.addLog` 或简单 print。
- **文件日志**：在 `sysCall_init` 打开文件、`sysCall_sensing` 写入、`sysCall_cleanup` 关闭。

## 缓冲区与数据打包

- **Buffer（V4.7+）**：为区分二进制数据与 Lua 字符串，引入 buffer 类型（`tobuffer`/`isbuffer`），主要影响 Lua 与 Python 之间的二进制数据传递。
- **`sim.transformBuffer`**：在 uint8 / base64 / base16 等格式间转换二进制缓冲。
- **`sim.packTable` / `sim.unpackTable`**：按 CoppeliaSim 格式打包/解包任意（嵌套）表，常用于跨语言数据序列化。
- Python 端通常直接用 numpy / struct / cbor2 处理，无需上述 Lua 专用工具。
