# 碰撞检测与距离计算 Collision & Distance

> CoppeliaSim 提供两个几何模块：**碰撞检测（collision detection）**测试两个可碰撞实体是否干涉，**距离计算（distance calculation）**求两个可测量实体之间的最小距离。两者均为精确几何计算，通过 collection 配对在仿真脚本中逐帧调用。

## 两个模块

| 模块 | 计算内容 | 入口 API | 适用实体 |
|------|---------|---------|---------|
| 碰撞检测 | 两实体是否相交（精确干涉判定） | `sim.checkCollision` | 可碰撞（collidable）实体 |
| 距离计算 | 两实体之间的最小距离 | `sim.checkDistance` | 可测量（measurable）实体 |

两个模块只做**检测/测量**，不做物理响应。碰撞响应（反弹、接触力）由动力学模块（dynamics）负责，与本文无关。

## 可碰撞 / 可测量对象

**可碰撞对象（collidable object）**指能与其他可碰撞对象做碰撞测试、登记碰撞状态的对象，包括：

- Dummy（虚拟点）
- Shape（形状）
- OC 树
- 点云

Dummy 与点云是**点式**对象，只能与**体式**对象（OC 树）碰撞。

**可测量对象（measurable object）**指可用于最小距离计算的对象，集合与上述四类相同（Dummy、Shape、OC 树、点云）。

两类属性默认对**非基本体形状、OC 树、点云**开启，可在场景对象属性对话框中或通过 `sim.setObjectSpecialProperty` 逐个开关；若对象属于某个模型，还可能被模型属性覆盖。

> 注意"可碰撞（collidable）"与"可响应（respondable）"是两件事：可碰撞只登记碰撞状态，可响应才参与动力学接触响应。

## collection 配对

collection 是用户定义的对象集合，本身也是可碰撞/可测量/可检测实体。碰撞检测与距离计算的典型用法是把一台机器人的所有构件打包成一个 collection，再与对方 collection 或 `sim.handle_all` 配对：

- 两机器人配对：`(collectionRobot1, collectionRobot2)`——算法检查集合 A 中任一对象是否与集合 B 中任一对象干涉/接近；
- 机器人对环境：`(robotCollection, sim.handle_all)`——对机器人 collection 与场景中所有其他可碰撞/可测量对象测试；
- 自检：当两个实参是**同一个 collection 句柄**时，同一对象不会与自身比较。

检测时只取集合中真正具备对应属性的对象子集参与：碰撞检测只测集合中的可碰撞对象，距离计算只测集合中的可测量对象。集合还可以用 `createCollection(options)` 的 bit 0 覆盖其对象的这些属性，详见 [[wiki/02-仿真建模/02-10-集合-Collections]]。

## API

### sim.checkCollision

```python
int result, list collidingObjectHandles = sim.checkCollision(int entity1Handle, int entity2Handle)
```

- `entity1Handle` / `entity2Handle`：实体句柄（对象句柄或 collection 句柄）；`entity2Handle` 可为 `sim.handle_all`，对 entity1 与所有其他可碰撞对象测试。
- 若两实参都是对象句柄，则**覆盖**其可碰撞标志强制测试。
- 返回 `result`（0/1）与 `collidingObjectHandles`（碰撞对两个句柄）。

### sim.checkDistance

```python
int result, list distanceData, list objectHandlePair = sim.checkDistance(
    int entity1Handle, int entity2Handle, float threshold = 0)
```

- 参数同 `checkCollision`，另加 `threshold`：距离大于阈值时不计算、`result` 返回 0；`threshold<=0` 表示不用阈值。
- `distanceData` 为 7 元数组 `[x1,y1,z1, x2,y2,z2, dist]`，前 3 个为对象 1 上最近点坐标，中间 3 个为对象 2 上最近点坐标，末位为最小距离。
- `objectHandlePair` 为持有最小距离段的两个对象句柄。

## handle 模式 vs 直接 check 模式

旧版采用"注册 + 句柄 + handle/read/reset"的工作流：

| 旧式 handle 系列 | 作用 | 状态 |
|-----------------|------|------|
| `sim.getCollisionHandle` / `sim.getDistanceHandle` | 取已注册 collision/distance 对象的句柄 | 已弃用 |
| `sim.handleCollision` / `sim.handleDistance` | 处理（计算）某个 collision/distance 对象 | 已弃用 |
| `sim.readCollision` / `sim.readDistance` | 读取上次 handle 的结果 | 已弃用 |
| `sim.resetCollision` / `sim.resetDistance` | 复位状态 | 已弃用 |

手册在 `sim.handleCollision` / `sim.handleDistance` 页明确标注 **Deprecated. See `sim.checkCollision` / `sim.checkDistance` instead.** 4.10 推荐直接用 `sim.checkCollision` / `sim.checkDistance`，一次调用完成检测并返回结果，无需注册句柄或显式 handle。本仓库仿真脚本一律用直接 check 模式。

## 示例

### 碰撞检测：机器人 collection vs 全场景

```python
from coppeliasim_zmqremoteapi_client import RemoteAPIClient

client = RemoteAPIClient()
sim = client.require('sim')

# 把 /robotModelAlias 子树打包成 collection
robot_base = sim.getObject('/robotModelAlias')
robot_collection = sim.createCollection(0)
sim.addItemToCollection(robot_collection, sim.handle_tree, robot_base, 0)

# 与场景中所有其他可碰撞对象测试
result, pair = sim.checkCollision(robot_collection, sim.handle_all)
if result > 0:
    print(f'Robot is colliding. Colliding pair: {pair}')
```

### 距离计算：最小距离与最近点段

```python
from coppeliasim_zmqremoteapi_client import RemoteAPIClient

client = RemoteAPIClient()
sim = client.require('sim')

robot_base = sim.getObject('/robotModelAlias')
robot_collection = sim.createCollection(0)
sim.addItemToCollection(robot_collection, sim.handle_tree, robot_base, 0)

# threshold=0.5：仅当存在小于 0.5m 的接近时才计算
result, dist_data, obj_pair = sim.checkDistance(
    robot_collection, sim.handle_all, 0.5)
if result > 0:
    # dist_data = [x1,y1,z1, x2,y2,z2, dist]
    print(f'Clearance = {dist_data[6]:.4f} m, pair = {obj_pair}')
    print(f'Closest segment: {dist_data[:3]} -> {dist_data[3:6]}')
```

### 可视化最小距离段（场景内画线）

```python
# 在 sysCall_init 中创建线段绘制对象
distance_segment = sim.addDrawingObject(
    sim.drawing_lines, 4, 0, -1, 1, [0, 1, 0])  # 绿色线段

# 在 sysCall_sensing 中每帧刷新
result, dist_data, _ = sim.checkDistance(robot_collection, sim.handle_all)
if result > 0:
    sim.addDrawingObjectItem(distance_segment, None)       # 清空上一帧
    sim.addDrawingObjectItem(distance_segment, dist_data)  # 画最近点段
```

> `dist_data` 的 7 元数组恰好可作 `addDrawingObjectItem` 的线条顶点数据（前 3 + 后 3 两个端点）。

## 与 simGeom 独立例程的关系

CoppeliaSim 的碰撞检测与距离计算功能同时作为**独立几何例程**提供（Coppelia geometric routines / simGeom），可在仿真之外的纯几何上下文中调用，不依赖场景或脚本。手册中 `collisionDetection.htm` / `distanceCalculation.htm` 结尾均明确指出这一点。详见 [[wiki/03-运动规划与控制/03-04-几何计算-simGeom]]。

此外，Modules > Geometry / Mesh > Collision check 菜单提供交互式插件，可快速检查自碰撞、与环境碰撞或两实体间碰撞，便于建模期排查，无需写脚本。
