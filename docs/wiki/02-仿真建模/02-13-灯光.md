# 灯光 Lights

> Light（灯光）是用于照亮场景的对象。场景中无任何灯光时，对象只显示环境光下的无阴影色（环境光在 environment 属性中设置）。场景中最多可有 **8 个**激活灯光。

## 三种灯光类型

| 类型 | 说明 |
|------|------|
| **Omnidirectional light**（全向光） | 从一个点光源向各方向均匀照亮场景 |
| **Spotlight**（聚光灯） | 只在特定方向圆锥内照亮；可调光锥 |
| **Directional light**（平行光） | 位置无关，只看方向；场景中所有对象被相似照亮 |

灯光通过 [Add > Light] 添加，在 light 属性对话框中调整参数。

## 灯光属性对话框

通过 [Tools > Scene object properties] 打开，选中灯光后点 Light 按钮进入。多选时可把最后选中灯光的参数复制到其余选中灯光（Apply to selection 按钮）。

| 参数 | 说明 |
|------|------|
| Light is enabled | 启用/禁用此灯；场景同时最多 8 个启用灯 |
| Light is local | 设为局部灯，仅当相机/视觉传感器的 use local lights 项启用、且本灯是其直接/间接子对象时才生效 |
| Spot cutoff | 聚光灯截止角（仅 spotlight）；越小光锥越窄 |
| Spot exponent | 聚光灯光强分布（仅 spotlight）；0=宽束，128=窄束 |
| Constant attenuation factor | 常数衰减因子 |
| Linear attenuation factor | 线性衰减因子 |
| Quadratic attenuation factor | 二次衰减因子 |
| Object size | 灯光图标的视觉尺寸，无功能意义 |
| Light / casing color | 灯光色 / 灯壳色 |

## 环境属性（environment）

Environment 定义场景级、但非场景对象的属性，仅在保存场景时写入、保存模型时不写入。包括：

- 背景颜色
- 雾参数（只与启用了相应选项的相机/视觉传感器交互，不直接影响场景对象）
- 环境光（ambient light）
- 场景创建信息
- 其他附加设置

环境光是无灯光场景下的唯一照明来源；添加灯光后，对象呈现阴影与高光。

## 使用要点

- 8 灯上限包含所有启用灯（全向 / 聚光 / 平行），关闭的灯不计数。
- 局部灯用于相机/视觉传感器的"自带灯光"效果：把灯作为该相机子对象并启用相机的 use local lights。
- 聚光灯的 spot cutoff 与 spot exponent 共同决定光锥形状与强度分布。
- 衰减三因子用于点光源/聚光灯随距离的衰减模型；平行光无位置，衰减不生效。
