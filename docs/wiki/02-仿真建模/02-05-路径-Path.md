# 路径 Path

> Path 是一种**伪对象（pseudo object）**：它本身不是独立对象类型，而是由一组 dummy 加上一个描述其行为与功能的 customization script 构成，用以表示空间中一系列带姿态的点序列。

## 本质结构

一个 path 对象在场景层级中表现为单一节点，但底层数据由两部分支撑：

- **控制点序列**：一组 dummy（虚拟点），每个携带位置 `[x y z]` 与姿态四元数 `[qx qy qz qw]`，定义曲线在空间中的形状。
- **customization script**：描述 path 的功能（如沿路径生成挤出形状、用户参数回调等）。

path 的实际路径数据（插值后密集采样点）与控制点数据分别以 `customData.PATH` 和 `customData.PATHCTRLPTS` 两个 buffer 属性存储在 path 对象内部，可用 `sim.getBufferProperty` 读取。

## 添加与编辑

- **添加**：菜单 `Add > Path`。新 path 默认含若干控制点。
- **编辑模式（path edit mode）**：选中 path 后可进入编辑模式，对控制点进行移动、复制/粘贴、删除等操作以调整曲线形状。
- **用户参数**：path 的基本属性通过其用户参数（user config callback function 实现）访问与调整，入口在场景层级中的用户参数图标。

## 控制点与贝塞尔点

控制点（control points）定义 path 的曲线形状。path 在控制点之间通过插值生成密集路径点，插值方式由 `smoothness` 参数控制：

- `smoothness = 0.0`：线性插值，折线连接。
- `smoothness = 1.0`：100% 贝塞尔插值，曲线平滑。
- 中间值：线性与贝塞尔按比例混合。

**控制点 vs 贝塞尔点**：控制点是用户直接编辑的"骨架点"，贝塞尔点是平滑算法在控制点之间根据 smoothness 插值生成曲线所用的内部点。用户编辑控制点，系统据此与 smoothness 自动算出贝塞尔曲线并采样出实际 path 数据。

## 数据访问

path 内部数据以 `customData` buffer 属性存储，单位为米/弧度（Regular API 统一单位）。

```python
# 读取控制点（每个点：x, y, z, qx, qy, qz, qw）
ctrlPts = sim.unpackDoubleTable(sim.getBufferProperty(pathHandle, 'customData.PATHCTRLPTS'))

# 读取插值后的路径数据（每个点：x, y, z, qx, qy, qz, qw）
pathData = sim.unpackDoubleTable(sim.getBufferProperty(pathHandle, 'customData.PATH'))
```

## 沿路径运动

让对象沿 path 在位置与姿态上跟随运动，典型流程：解析 path 数据 → 计算各点累计长度 → 按速度推进沿路径距离 → 插值取当前位姿 → 写回对象。核心 API：

| API | 作用 |
|-----|------|
| `sim.getPathLengths(path, dof)` | 计算 path 每点累计长度与总长度（仅用前 dof 维欧氏距离） |
| `sim.getPathInterpolatedConfig(path, pathLengths, t, method, types)` | 按沿路径距离 t 插值取配置 |
| `sim.getClosestPosOnPath(path, pathLengths, absPt)` | 返回离空间点最近的沿路径距离 |
| `sim.resamplePath(path, pathLengths, finalConfigCnt, method, types)` | 重采样为指定点数的新 path |
| `sim.createPath(ctrlPts, options, ...)` | 从控制点序列创建 path 对象 |

`getPathInterpolatedConfig` / `resamplePath` 的 `method` 指定插值类型（`linear` 或 `quadraticBezier`）与贝塞尔强度（0.05–1.0）；`types` 标注每维类型：0=笛卡尔，1=2π 周期角，2=四元数。对 3D 位姿应使用 `[0 0 0 2 2 2 2]`。

### 沿路径运动示例（Python，stepping 模式）

```python
# 要求 CoppeliaSim 4.10+，ZMQ Remote API 客户端
import numpy as np
from coppeliasim_zmqremoteapi_client import RemoteAPIClient

client = RemoteAPIClient()
sim = client.require('sim')

# 启动仿真后执行（此处假设仿真已运行）
path = sim.getObject('/Path')
obj = sim.getObject('/跟随对象')  # 改为实际对象路径

pathData = sim.unpackDoubleTable(sim.getBufferProperty(path, 'customData.PATH'))
m = np.array(pathData).reshape(len(pathData) // 7, 7)
pathPositions = m[:, :3].flatten().tolist()
pathQuaternions = m[:, 3:].flatten().tolist()
pathLengths, totalLength = sim.getPathLengths(pathPositions, 3)

velocity = 0.04  # m/s
posAlongPath = 0.0
prevT = sim.getSimulationTime()
sim.setStepping(True)
while sim.getSimulationState() != sim.simulation_stopped:
    t = sim.getSimulationTime()
    posAlongPath = (posAlongPath + velocity * (t - prevT)) % totalLength
    pos = sim.getPathInterpolatedConfig(pathPositions, pathLengths, posAlongPath)
    quat = sim.getPathInterpolatedConfig(
        pathQuaternions, pathLengths, posAlongPath, None, [2, 2, 2, 2])
    sim.setObjectPosition(obj, pos, path)
    sim.setObjectQuaternion(obj, quat, path)
    prevT = t
    sim.step()
```

## Path Shaping（挤出形状）

path 可自动生成沿路径挤出的形状（extruded shape）。在 path 的用户参数中启用该功能后，由 customization script 中的 `path.shaping` 回调驱动，内部调用 `sim.generateShapeFromPath`：

```lua
-- path 的 customization script 中
function path.shaping(path, pathIsClosed, upVector)
    -- 方形截面：x/y 对序列，首尾重叠即闭合
    local section = {0.02,-0.02, 0.02,0.02, -0.02,0.02, -0.02,-0.02, 0.02,-0.02}
    local color = {0.7, 0.9, 0.9}
    local options = 0
    if pathIsClosed then options = options | 4 end  -- bit2=4 表示 path 闭合
    local shape = sim.generateShapeFromPath(path, section, options, upVector)
    sim.setShapeColor(shape, nil, sim.colorcomponent_ambient_diffuse, color)
    return shape
end
```

圆形截面可由极坐标生成：

```lua
local section, radius, sides = {}, 0.02, 32
local da = math.pi * 2 / sides
for i = 0, sides - 1 do
    section[2*i+1] = radius * math.cos(da*i)
    section[2*i+2] = radius * math.sin(da*i)
end
-- 闭合：首尾点重合
section[#section+1] = section[1]
section[#section+2] = section[2]
```

`sim.generateShapeFromPath(path, section, options, upVector)` 关键参数：

- `path`：行主序，每点 `[x y z qx qy qz qw]`；options 前两位为 0 时忽略姿态。
- `section`：截面 x/y 对序列，首尾重叠则截面闭合。
- `options`：bit0-1 决定 up 方向来源（0=upVector，1=x 轴，2=y 轴，3=z 轴）；bit2(4)=path 闭合。
- `upVector`：挤出面的 up 方向；options 前两位非 0 时可为 nullptr。

## 位置计算方法

path 沿曲线的位置以"距起点的弧长"度量。`sim.getPathLengths` 用前 `dof` 维欧氏距离累加得到每点累计长度与总长。插值时 `t` 即沿路径弧长距离，`getClosestPosOnPath` 据此返回离某空间点最近的弧长位置。对周期角与四元数需用 `types` 标注以正确处理绕圈（如关节角跨越 2π 边界、四元数球面插值）。

## 导入导出

path 的控制点数据以 `customData.PATHCTRLPTS` buffer 形式存储，可通过 `getBufferProperty` / `setBufferProperty` 配合 `unpackDoubleTable` / `packDoubleTable` 进行读写以实现导入导出。`sim.createPath` 接受控制点序列直接创建 path，可据此从外部数据源（CSV、矩阵等）重建 path。
