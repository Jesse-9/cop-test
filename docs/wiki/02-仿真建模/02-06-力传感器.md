# 力传感器 (Force Sensor)

> 力传感器是两个 shape 之间的**条件刚性链接**：既作为刚性约束把两端 shape 绑在一起，又能在仿真中测量沿/绕 x、y、z 三轴的力与力矩（共 6 个值），并在力/力矩超阈值时断裂。

## 本质

力传感器**初始**表现为连接两个 shape 的刚性链接。与普通 dummy-dummy 重叠约束（永久刚性）不同，力传感器的刚性是**条件的**：当力或力矩超出设定阈值，或满足用户自定义条件时，传感器会**断裂**，两端 shape 在动力学上解耦。典型应用如把一根梁（蓝）锚定在墙（红）上，由中间的力传感器（绿）测量梁对墙的拉力/力矩。

```
墙(红) ──[力传感器(绿)]── 梁(蓝)
```

> 注意：力传感器只是"测量 + 可断裂"的刚性约束，本身不提供驱动；如果两端 shape 需要主动相对运动，应改用动力学启用的关节。

## 测量值

一个力传感器测量一对 3 元素向量：

| 向量 | 分量 | 含义 |
|------|------|------|
| `forceVector` | `[fx, fy, fz]` | 沿传感器 x、y、z 轴的力 |
| `torqueVector` | `[tx, ty, tz]` | 绕传感器 x、y、z 轴的力矩 |

共 6 个标量，描述传感器所受的完整力旋量（wrench）。

## 动态启用前提

力传感器**仅在仿真中且被动态启用时**才工作。动力学启用的判定见 [[wiki/02-仿真建模/02-11-动力学仿真设计]]——场景层次树中，shape 之间通过"动力学启用的关节 / 力传感器 / dummy-dummy 重叠约束"连接，链条上任意一环失效（如断开的关节、纯静态 shape 夹在中间），力传感器就不再是动态约束，也就测不到力。仿真运行时，动态启用的对象在场景层次旁会显示动力学图标。

## 与关节测力的区别

| 维度 | 力传感器 | 关节（joint） |
|------|----------|---------------|
| 测量轴 | 沿/绕 x、y、z **三轴**的力与力矩（6 值） | 仅沿/绕其 **z 轴**的力或力矩（1 值，`sim.getJointForce`） |
| 角色 | 两 shape 间的可测刚性约束，可断裂 | 主动/被动驱动件，有目标力/位置 |
| 典型场景 | 末端力觉、装配接触、锚点断裂 | 关节电机出力、力控关节 |

简言之：关节测的是"电机轴上单维力/力矩"，力传感器测的是"刚性连接处的六维力旋量"。

## 属性对话框

`Tools > Scene object properties`，选中力传感器后点击 Force sensor 按钮。可设：

- **Filter（滤波）**：对采样的力/力矩做滤波以减少抖动。
  - `Sample size`：滤波窗大小，1 表示不滤波（原始值）。
  - `Average value`：输出窗内平均值。
  - `Median value`：输出窗内中值。
- **Trigger settings（触发阈值）**：
  - `Force threshold`：力向量幅值阈值。
  - `Torque threshold`：力矩向量幅值阈值。
  - `Consecutive threshold violations for breaking`：连续超阈值多少次后触发回调/断裂。
  - 触发会调用 trigger 回调函数（用户可在其中决定是否调用 break）。
- **Object size / Color**：仅影响 3D 可视化，无功能作用。

## 断裂行为

当满足触发条件（默认为力或力矩幅值连续超阈值 N 次）时，力传感器进入**broken 状态**：两端 shape 在动力学上解耦，原先的刚性约束消失。这一机制可用于模拟机械断裂、过载保护、装配失效等。

## 接触回调函数 (Contact Callback Function)

接触回调**不是**力传感器专属——它是物理引擎在两个可响应 (respondable) shape 发生碰撞时对每个接触对调用的系统回调 `sysCall_contact`，允许用户自定义接触处理。但力传感器常用于测量由此产生的接触力，二者配合使用很常见。

要点：
- 物理引擎检测到两个可响应 shape 碰撞时，对每个接触对调用 `sysCall_contact`。
- 回调可能**非常频繁**（单步仿真内有时上百次），实现务必保持简单，否则拖慢仿真。
- 回调可设置 `ignoreContact`（忽略此接触）、`collisionResponse`（是否产生碰撞响应），以及按引擎（Bullet/ODE/Newton/MuJoCo/Vortex）设置摩擦、恢复系数等参数。

### Python 示例（sysCall_contact）

```python
def sysCall_contact(inData):
    # inData["handle1"] 与 inData["handle2"] 是接触两端的 shape
    retData = {}
    retData["ignoreContact"] = False      # 在此处理该接触
    retData["collisionResponse"] = True   # shape 将碰撞
    if inData["engine"] == sim.physics_bullet:
        retData["bullet"] = {}
        retData["bullet"]["friction"] = 0
        retData["bullet"]["restitution"] = 0
    if inData["engine"] == sim.physics_newton:
        retData["newton"] = {}
        retData["newton"]["staticFriction"] = 0
        retData["newton"]["kineticFriction"] = 0
        retData["newton"]["restitution"] = 0
    return retData
```

> **旧式 contact callback script 已弃用**：现有脚本仍能运行，但编辑被禁用。如需临时启用编辑，在 `system/usrset.txt` 中将 `enableOldCustomContactHandlingEdition` 设为 `true`。新代码一律使用 `sysCall_contact` 回调函数。

## 读取力传感器 API

### 签名

```python
int result, list forceVector, list torqueVector = sim.readForceSensor(int objectHandle)
```

### 参数

- `objectHandle`：力传感器句柄。可与 `sim.handleflag_rawvalue` 相加，以读取每个动力学子步产生的**原始值**（默认每仿真步 10 个动力学子步）。原始值只能在物理引擎触发的回调函数内访问。

### 返回值

- `result`：位编码。bit 0（=1）表示力/力矩数据可用；为 0 表示尚不可用（例如滤波器还未积累足够样本）。
- `forceVector`：`[fx, fy, fz]`，沿传感器三轴的力。
- `torqueVector`：`[tx, ty, tz]`，绕传感器三轴的力矩。

> 读取的是**滤波后的值**（依属性对话框的 Filter 设置）。原始值需在回调内用 `sim.handleflag_rawvalue`。

### Python 示例（ZMQ Remote API）

```python
from coppeliasim_zmqremoteapi_client import RemoteAPIClient

client = RemoteAPIClient()
sim = client.require('sim')

sim.startSimulation()
sensor = sim.getObject('/sensor')          # 力传感器路径
try:
    while True:
        result, force, torque = sim.readForceSensor(sensor)
        if result & 1:                      # bit0=1 表示数据可用
            print(f'force={force}  torque={torque}')
        sim.step()                           # stepping 模式推进
except KeyboardInterrupt:
    pass
sim.stopSimulation()
```

## 创建力传感器 API

```python
int sensorHandle = sim.createForceSensor(int options, list intParams, list floatParams)
```

- `options` 位编码：bit0(1)=启用力阈值，bit1(2)=启用力矩阈值。
- `intParams`（5 个，Python 从 0 起）：`[filterType(0=avg,1=median), filterWindowSize, breakConsecutiveViolations, 0, 0]`。
- `floatParams`（5 个）：`[sensorSize, forceThreshold, torqueThreshold, 0.0, 0.0]`。

### Python 示例：编程创建带力阈值的力传感器

```python
from coppeliasim_zmqremoteapi_client import RemoteAPIClient

client = RemoteAPIClient()
sim = client.require('sim')

# options=3: 同时启用力阈值 + 力矩阈值
# intParams: 平均滤波, 窗口 5, 连续超阈值 3 次断裂
# floatParams: 尺寸 0.1, 力阈值 50N, 力矩阈值 5N·m
sensor = sim.createForceSensor(
    3,
    [0, 5, 3, 0, 0],
    [0.1, 50.0, 5.0, 0.0, 0.0],
)
print(f'created force sensor handle={sensor}')
```

## 建模实践要点（来自动力学仿真设计）

1. **力传感器是动态约束**：两端 shape 若都非静态且无其他约束，力传感器就是它们间的刚性链接；若链中出现静态 shape，会中断动态链，力传感器失效。
2. **作为模型装配点**：把力传感器作为模型"附着点"，组装时两端 shape 在仿真中保持刚性连接，是机器人-夹爪装配的常见做法。
3. **质量与惯量**：两端 shape 质量比应控制在 `m1 < 10*m2` 且 `m2 < 10*m1`，否则力传感器会变"软"、出现位姿误差；过低质量 shape 即使被大力驱动也难施加大力。
4. **避免静态 shape 夹在动态链中间**：会中断力传感器的逻辑行为。
5. **优先用原始 shape**：作为 respondable shape，用 primitive shape 比三角网格更稳定、更快。
