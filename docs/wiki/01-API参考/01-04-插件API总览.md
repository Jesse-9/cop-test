# 插件 API 体系总览

> CoppeliaSim 的功能由 regular API 之外的**插件**扩展：每个插件以独立命名空间（如 `simIK`、`simOMPL`、`simUI`）暴露函数，按需加载、各司其职。本条目按命名空间一览各插件职责，并标注与本仓库岛式车间仿真最相关者。

## 定位：regular API 与插件 API 的关系

依据 `apisOverview.htm`，CoppeliaSim 的 API 分为两组：

- **regular API**：CoppeliaSim 自身提供的主函数，统一归在 `sim` 命名空间下（如 `sim.getObject`）。详见 [[wiki/01-API参考/01-01-Regular-API-overview]]。
- **插件 API（other API functions）**：由特定插件提供，每个插件把函数归到一个**独立命名空间**，如 `simOMPL`、`simUI`、`simIK`。其描述与 API 参考见 functionality 各分节。

插件本质是按需加载的共享库（`loadPlugin`），可用任何能生成共享库并调用导出 C 函数的语言编写。典型用途：

1. 为仿真提供**自定义脚本命令**（与脚本配合使用）；
2. 提供**高性能计算**能力（编译语言比脚本快）；
3. 提供**硬件接口**（如真实机器人、ROS/ROS2 节点）。

## 插件加载方式

插件文件须命名为 `sim<name>-<version>`（版本可选），如 `simIK-2-1`，文件名在 Linux 为 `libsimIK-2-1.so`，置于 CoppeliaSim 可执行目录下。

加载方式一：直接 `loadPlugin`：

```lua
simIK = loadPlugin('simIK-2-1')
```

加载方式二（推荐，便于扩展）：用同名 Lua 模块封装后 `require`：

```python
# Python 脚本中
def sysCall_init():
    simIK = require('simIK-2-1')
```

```lua
-- Lua 脚本中
function sysCall_init()
    simIK = require('simIK-2-1')
end
```

插件入口点（C 侧）至少包含 `simInit`，其余可选；带 `_ui` 后缀的入口由 UI 线程调用，其余由仿真线程调用。详见 `plugins.htm`。

## 经 ZMQ 远程 API 访问插件函数

CoppeliaSim 的 external API 机制（含本仓库使用的 **ZeroMQ Remote API**）可访问脚本中可用的全部函数——**包括各插件命名空间的函数**，前提是：

1. 对应插件已在仿真端加载（如 `simIK`、`simOMPL` 经 add-on 或脚本 `require` 注册）；
2. ZMQ remote API 服务端激活（菜单 Add-ons > ZMQ remote API server，默认端口 23000）。

Python 客户端按命名空间 `require` 即可调用：

```python
from coppeliasim_zmqremoteapi_client import RemoteAPIClient

client = RemoteAPIClient()
sim = client.require('sim')
simIK = client.require('simIK')      # 逆运动学
simOMPL = client.require('simOMPL')  # 运动规划
simGeom = client.require('simGeom')  # 几何/碰撞/距离
simVision = client.require('simVision')  # 视觉处理
simROS2 = client.require('simROS2')  # ROS 2 接口（若启用）
```

这正是本仓库 `factory_*.py` 控制层经 ZMQ 远程 API 驱动仿真的基础——regular API 与插件 API 在客户端视角下统一通过 `require('<命名空间>')` 获取。

## 本仓库相关重点插件

### simIK — 逆运动学

创建 IK 任务、设定元素与基座、计算雅可比、求解关节构型。在岛式车间中用于机械臂末端位姿到关节角的解算，以及生成直线接近路径（`simIK.generatePath`）。详见 [[wiki/03-运动规划与控制/03-01-逆运动学-simIK]]。

### simOMPL — 运动规划

封装 OMPL 库，定义状态空间、任务、算法、碰撞对，计算避障路径。常与 simIK 联用：先用 `simIK.findConfigs` 由目标位姿求关节构型作为目标状态，再用 `simOMPL.compute` 规划路径。详见 [[wiki/03-运动规划与控制/03-02-OMPL运动规划]]。

### simGeom — 几何计算

mesh/点云/OC tree 的创建、复制、碰撞检测、距离查询。注意其句柄是**插件内部表示**，与 CoppeliaSim 场景中的 shape/point cloud/octree 句柄无直接关系，须用本插件 API 创建/操纵/销毁。详见 [[wiki/03-运动规划与控制/03-04-几何计算-simGeom]]。

### simVision — 视觉处理

配合 vision sensor 的 offscreen 渲染，提供 work image 操作、blob 检测、简单图像处理。常在 vision 回调 `sysCall_vision` 中与 `simIM` 配合处理采集图像。详见 [[wiki/04-感知与视觉/04-02-视觉传感器]]。

### simROS2 — ROS 2 协同

提供 ROS 2 的 topic/service/action 发布订阅与参数读写接口，实现 CoppeliaSim 与 ROS 2 生态的协同仿真。本仓库虽以 ZMQ Remote API 直连为主，但若需接入 ROS 2 节点图，可经此插件桥接。详见 [[wiki/05-数字孪生与协同仿真/05-01-ROS2集成]]。
