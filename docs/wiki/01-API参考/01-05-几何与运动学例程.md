# Coppelia 几何与运动学例程 (C++ Routines)

> CoppeliaSim 的几何与运动学计算能力源自两组 **C++ 例程集合**——Coppelia Geometric Routines 与 Coppelia Kinematics Routines。它们可被嵌入独立（非仿真）应用，也是仿真内 `simGeom` / `simIK` 插件的底层实现。

## 两组例程概览

| 例程集合 | 主要职责 | 典型函数前缀 | 仿真内封装 |
|---------|---------|-------------|-----------|
| Coppelia Geometric Routines | 碰撞检测、最小距离、最近点、接近传感器模拟（基于 mesh / octree / 点云） | `geom_*` | `simGeom` 插件 |
| Coppelia Kinematics Routines | 任意机构（含冗余、嵌套环路）的 FK / IK 雅可比求解 | `ik_*` | `simIK` 插件 |

两组例程的源码**不属于 CoppeliaSim 本体**，携带独立的许可条款。获取源码需联系官方。CoppeliaSim 通过把它们封装为插件（geometric plugin、kinematics plugin）在仿真内提供这些计算能力——也就是说**插件 API（`simGeom`/`simIK`）是例程在仿真上下文内的封装层**，二者解决同一类问题，只是入口与适用场景不同。

## Coppelia Geometric Routines

### 能力
根据官方手册，CoppeliaSim 的几何/网格（Geometry / Mesh）计算主要经由本组例程实现，被 geometric plugin 包装后负责：

- **碰撞检测**（mesh / octree / 点云之间）
- **最小距离计算**
- **接近传感器模拟**（基于上述几何体）

此外还有独立插件补充其它网格操作：
- `simConvex` — 凸包、凸分解
- `simOpenMesh` — 网格抽稀（decimation）
- `simIGL` — 布尔运算等

### 嵌入到独立应用
例程以纯 C++ 库形式提供，可在脱离 CoppeliaSim 的独立应用中使用。手册给出的最小示例——计算两个单三角形 mesh 之间的最小距离：

```cpp
#include "geom.h"

int main(int argc, char* argv[])
{
    // mesh1：单三角形
    std::vector<simReal> vertices1{0.0,0.0,0.0,
                                   0.5,0.5,0.0,
                                   0.5,0.0,0.5};
    std::vector<int> indices1{0,1,2};
    CObbStruct* mesh1 = geom_createMesh(&vertices1[0], vertices1.size(),
                                        &indices1[0], indices1.size());

    // mesh2：单三角形
    std::vector<simReal> vertices2{0.5,0.0,0.0,
                                   0.0,0.5,0.5,
                                   0.0,0.0,0.5};
    std::vector<int> indices2{0,1,2};
    CObbStruct* mesh2 = geom_createMesh(&vertices2[0], vertices2.size(),
                                        &indices2[0], indices2.size());

    // 移动/旋转两个 mesh 并实时计算最小距离
    simReal t = 0.0;
    while (true) {
        t += 0.001;

        C7Vector mesh1Transformation;
        mesh1Transformation.X = C3Vector(0.5*cos(0.1*t), 0.0, 0.0); // x 轴正弦运动
        mesh1Transformation.Q.setIdentity();

        C7Vector mesh2Transformation;
        mesh2Transformation.X = C3Vector(0.0, 0.4*cos(0.2*t), 0.3*cos(0.1*t)); // y/z 轴正弦
        C3Vector eulerAngles(0.0, 0.0, t*1.2); // 绕垂直轴旋转
        mesh2Transformation.Q.setEulerAngles(eulerAngles);

        simReal dist = REAL_MAX;
        geom_getMeshMeshDistanceIfSmaller(mesh1, mesh1Transformation,
                                          mesh2, mesh2Transformation, dist);
        printf("mesh-mesh minimum distance: %f\n", dist);
    }
    return 0;
}
```

关键点：
- 头文件 `geom.h`，类型 `CObbStruct`、`C7Vector`、`C3Vector`、`simReal`。
- 位姿用 `C7Vector`（平移 `X` + 旋转 `Q`），旋转可用 `setIdentity()` 或 `setEulerAngles()`。
- 计算函数形如 `geom_getMeshMeshDistanceIfSmaller(...)`，返回值经引用参数写出（`dist` 初值设为 `REAL_MAX` 以确保取到真实距离）。

## Coppelia Kinematics Routines

### 能力
基于**雅可比（Jacobian）**求解任意机构的 FK / IK，支持：

- 冗余 / 非冗余机构
- 含嵌套环路（nested loops）的机构
- 多种解析方法：雅可比伪逆、阻尼最小二乘伪逆（DLS）、零空间投影等

### 与 IK 组 / IK 元素的关系
手册指出，CoppeliaSim 内通过 **IK group** 与 **IK element** 表达 IK 任务：每个 IK element 将一个 tip dummy 约束跟随 target dummy，可设定位置 / 方向 / 二者约束；IK group 汇总若干 IK element 一次性求解。独立应用中用 `ikCreateGroup` / `ikAddElement` / `ikSetElementConstraints` 等函数构建同样的结构，再 `ikHandleGroup` 求解。

### 嵌入到独立应用
手册示例——构造 3 自由度转动副链并循环求解 IK：

```cpp
#include "ik.h"

int main(int argc, char* argv[])
{
    ikCreateEnvironment();                  // 创建 IK 环境

    int joint1Handle, joint2Handle, joint3Handle;
    ikCreateJoint(nullptr, ik_jointtype_revolute, &joint1Handle);
    ikCreateJoint(nullptr, ik_jointtype_revolute, &joint2Handle);
    C7Vector tr(C4Vector(1.57,0.0,0.0), C3Vector::zeroVector);
    ikSetObjectTransformation(joint2Handle, -1, &tr);
    ikSetObjectParent(joint2Handle, joint1Handle, true);      // 挂为 joint1 子节点
    ikCreateJoint(nullptr, ik_jointtype_revolute, &joint3Handle);
    tr.X = C3Vector(0.0,0.0,0.2);
    ikSetObjectTransformation(joint3Handle, -1, &tr);
    ikSetObjectParent(joint3Handle, joint2Handle, true);

    int tipHandle, targetHandle;
    ikCreateDummy(nullptr, &tipHandle);
    tr.Q.clear();
    tr.X = C3Vector(0.0,0.0,0.4);
    ikSetObjectTransformation(tipHandle, -1, &tr);
    ikSetObjectParent(tipHandle, joint3Handle, true);
    ikCreateDummy(nullptr, &targetHandle);
    ikSetObjectTransformation(targetHandle, -1, &tr);
    ikSetLinkedDummy(tipHandle, targetHandle);
    // 链: joint1 -> joint2 -> joint3 -> tipDummy <...> targetDummy

    // 创建 IK group，约束 tip 跟随 target（仅位置约束）
    int ikGroup, ikElementIndex;
    ikCreateGroup(nullptr, &ikGroup);
    ikAddElement(ikGroup, tipHandle, &ikElementIndex);
    ikSetElementConstraints(ikGroup, ikElementIndex, ik_constraint_position);

    ikGetObjectTransformation(targetHandle, -1, &tr);
    while (true) {
        // 微动 target
        tr.X = tr.X + C3Vector(0.001, 0.002, -0.0001);
        ikSetObjectTransformation(targetHandle, -1, &tr);

        // 求解 IK
        int result;
        ikHandleGroup(ikGroup, &result);
        if (result != ik_result_success)
            break;

        // 读取关节角
        simReal a1, a2, a3;
        ikGetJointPosition(joint1Handle, &a1);
        ikGetJointPosition(joint2Handle, &a2);
        ikGetJointPosition(joint3Handle, &a3);
    }
    return 0;
}
```

关键点：
- 头文件 `ik.h`；每个独立应用需先 `ikCreateEnvironment()` 建立独立 IK 环境（与仿真场景分离）。
- 关节用 `ikCreateJoint` + `ik_jointtype_revolute`，通过 `ikSetObjectParent` 组装父子关系。
- tip / target 为 dummy；用 `ikSetLinkedDummy` 建立配对约束。
- 约束类型枚举：`ik_constraint_position`、`ik_constraint_orientation`、`ik_constraint_full` 等。
- 求解状态枚举：`ik_result_success` 等，失败即应终止循环。

## 例程 vs. 插件 API

| 维度 | Coppelia C++ Routines | `simGeom` / `simIK` 插件 |
|------|----------------------|--------------------------|
| 适用上下文 | 独立 C++ 应用，脱离 CoppeliaSim | 仿真内（脚本 / Regular API / Remote API） |
| 入口方式 | 直接调用 `geom_*` / `ik_*` C++ 函数 | 经插件命名空间调用（Lua `simGeom.*` / `simIK.*`，Python ZMQ 端同理） |
| 计算对象 | 自建 mesh / IK 环境 | 场景中的现有对象（按句柄引用） |
| 许可 | 源码独立许可，需联系官方 | 随 CoppeliaSim 安装 |
| Python 侧访问 | 无直接 Python 绑定 | 通过 Remote API 调 `simIK` / `simGeom`（见 [[wiki/03-运动规划与控制/03-01-逆运动学-simIK]]、[[wiki/03-运动规划与控制/03-04-几何计算-simGeom]]） |

> 在本仓库（Python + ZMQ Remote API）的语境下，**不直接使用 C++ 例程**；而是经由插件命名空间 `simIK` / `simGeom` 间接调用同一套底层计算。C++ 例程是当应用需要脱离 CoppeliaSim 独立运行（如外部机器人控制器、离线批处理几何计算）时的入口。

## 何时使用例程

- **用例程**：需要在独立应用中嵌入几何/运动学计算，脱离 CoppeliaSim 运行（典型：真实机器人控制器的 IK 求解、离线 mesh 碰撞/距离批量分析）。
- **用插件 API**：计算对象已在 CoppeliaSim 场景中，或脚本/Remote API 流程需要调用——走 `simGeom` / `simIK`。本仓库走此路径。
