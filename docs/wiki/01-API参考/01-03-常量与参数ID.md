# API 常量总览与对象参数 / 属性参考

`sim.*` 命名空间下预定义了大量整型常量，用于句柄语义、对象分类、消息分发、位标志与各类配置。4.10 起，对象状态读写统一收敛到 **properties 体系**，旧的 **object parameter IDs** 仍可用但官方建议改用 properties。本条目按手册分类梳理常用常量，并给出 properties / parameter 两套读写的对照。

> 来源：`apiConstants.htm`、`objectParameterIDs.htm`、`properties.htm`、`propertiesReference.htm`。

## 一、特殊句柄值（handle）

许多 API 函数接受 `int handle` 参数，下列常量赋予该参数特殊语义：

| 常量 | 语义 |
|------|------|
| `sim.handle_world` | 世界坐标系 / 绝对参考系 |
| `sim.handle_parent` | 父对象作为参考系 |
| `sim.handle_self` | 自身 |
| `sim.handle_all` | 所有对象 |
| `sim.handle_all_except_explicit` | 除显式指定外的所有对象 |
| `sim.handle_all_except_self` | 除自身外的所有对象 |
| `sim.handle_tree` | 以指定对象为根的整棵子树 |
| `sim.handle_chain` | 从指定对象向上到根的链 |
| `sim.handle_single` | 仅单个对象 |
| `sim.handle_scene` | 当前场景 |
| `sim.handle_app` | 整个应用（app 级属性目标） |
| `sim.handle_default` | 默认行为 |
| `sim.handle_inverse` | 反向操作（如反向查询） |
| `sim.handle_absolute` | 绝对句柄（不带父子相对语义） |
| `sim.handle_main_script` | main script |

> `sim.handle_app`、`sim.handle_scene`、`sim.handle_world` 同时也是 properties API 的三类 target。

## 二、对象类型与子类型

### 通用对象类型（sim.objecttype_*）

`sim.isHandle` 等函数用此区分句柄所指对象的顶层类别：

- `sim.objecttype_sceneobject` — 场景对象
- `sim.objecttype_collection` — 集合
- `sim.objecttype_mesh` — 网格
- `sim.objecttype_texture` — 纹理

### 场景对象类型（sim.sceneobject_*）

`sim.getObjectType`、`sim.getObjectsInTree` 返回值用此区分：

| 常量 | 类型 |
|------|------|
| `sim.sceneobject_shape` | 形状 |
| `sim.sceneobject_joint` | 关节 |
| `sim.sceneobject_graph` | 图表 |
| `sim.sceneobject_camera` | 相机 |
| `sim.sceneobject_light` | 灯光 |
| `sim.sceneobject_dummy` | 虚拟点 |
| `sim.sceneobject_proximitysensor` | 近接传感器 |
| `sim.sceneobject_octree` | OC 树 |
| `sim.sceneobject_pointcloud` | 点云 |
| `sim.sceneobject_visionsensor` | 视觉传感器 |
| `sim.sceneobject_forcesensor` | 力传感器 |
| `sim.sceneobject_script` | 脚本 |

### 场景对象子类型（sim.{type}_{subtype}）

进一步刻画同一类型的不同形态：

- 灯光：`sim.light_omnidirectional` / `sim.light_spot` / `sim.light_directional`
- 关节：`sim.joint_revolute`（旋转）/ `sim.joint_prismatic`（移动）/ `sim.joint_spherical`（球）
- 形状：`sim.shape_simple` / `sim.shape_compound`
- 近接传感器体积：`sim.proximitysensor_ray` / `_pyramid` / `_cylinder` / `_disc` / `_cone`

## 三、仿真器消息与事件回调

### 脚本可查询消息（sim.message_*）

`sim.getSimulatorMessage` 在脚本中可查询到：

- `sim.message_model_loaded`
- `sim.message_scene_loaded`
- `sim.message_keypress`（`auxData[0]`=按键，`auxData[1]`=Ctrl/Shift 状态）

### 客户端应用消息（sim_message_*）

仅在 CoppeliaSim 客户端应用内可查询：

- `sim_message_simulation_start_resume_request`
- `sim_message_simulation_pause_request`
- `sim_message_simulation_stop_request`

### 事件回调消息（sim_message_eventcallback_*）

分发给插件 `simMsg` 入口点，也对应脚本回调。核心：

| 消息 | 触发时机 |
|------|---------|
| `sim_message_eventcallback_instancepass` | 每个主循环一次；`auxData[0]` 为事件位标志 |
| `sim_message_eventcallback_instanceswitch` | 场景切换 |
| `sim_message_eventcallback_instanceabouttoswitch` | 即将切换场景 |
| `sim_message_eventcallback_sceneloaded` / `_modelloaded` | 场景/模型加载后 |
| `sim_message_eventcallback_scenesave` / `_modelsave` | 即将保存场景/模型 |
| `sim_message_eventcallback_simulationabouttostart` | 仿真即将开始 |
| `sim_message_eventcallback_simulationabouttoend` / `_ended` | 仿真即将结束/已结束 |
| `sim_message_eventcallback_simulationinit` / `_actuation` / `_sensing` / `_cleanup` | 对应 main script 四阶段；`auxData[0]`=0 前/1 后 |
| `sim_message_eventcallback_keypress` | 按键（UI 线程） |
| `sim_message_eventcallback_refreshdialogs` | 对话框刷新前 |
| `sim_message_eventcallback_abouttoundo` / `_undoperformed` / `_abouttoredo` / `_redoperformed` | 撤销/重做 |
| `sim_message_eventcallback_menuitemselected` | 自定义菜单项被选 |
| `sim_message_eventcallback_events` | 事件分发；`auxPointer` 指向 CBOR 编码事件，`auxData[0]` 为事件数 |
| `sim_message_eventcallback_scriptabouttobedestroyed` / `_scriptstateabouttobedestroyed` | 脚本/脚本状态即将销毁 |

`instancepass` 的 `auxData[0]` 事件位标志（bit N set）：

| bit | 含义 |
|-----|------|
| 0 | 对象被删除 |
| 1 | 对象被创建 |
| 2 | 模型加载 |
| 3 | 场景加载 |
| 4 | 撤销 |
| 5 | 重做 |
| 6 | 场景切换 |
| 7 | 编辑模式（状态位，非事件） |
| 8 | 对象缩放 |
| 9 | 选择状态变化 |
| 10 | 按键 |
| 11 | 仿真开始 |
| 12 | 仿真结束 |

> 对某事件标志作出反应时，不要再同时处理其等价 event callback 消息（如 bit3 与 `sim_message_eventcallback_sceneloaded`）。

## 六、Object Parameter IDs（旧式，建议改用 properties）

4.10 手册明确：**object parameters have been replaced by properties**。下列 ID 仍被 `sim.getObjectInt32Param` / `sim.getObjectFloatParam` / `sim.getObjectStringParam` / `sim.getObjectFloatArrayParam` 及对应 set 系列使用，但官方建议迁移到 properties。

按对象类型分组（仅列高频项，完整清单见 `objectParameterIDs.htm`）：

### 场景对象通用

- `sim.objintparam_visibility_layer`（int32）— 可见性层
- `sim.objfloatparam_abs_x_velocity` / `_y` / `_z` / `_rot_velocity`（float，只读）— 绝对速度，计算值
- `sim.objfloatparam_objbbox_min_x` … `_max_z`（float，只读）— 对象包围盒
- `sim.objfloatparam_modelbbox_min_x` … `_max_z`（float，只读）— 模型包围盒（对象须为模型基）
- `sim.objintparam_collection_self_collision_indicator`（int32）
- `sim.objintparam_manipulation_permissions`（int32，位编码：bit0 非仿真平移 / bit1 仿真平移 / bit2 非仿真旋转 / bit3 仿真旋转 / bit4 平移锁定 / bit5 旋转锁定）
- `sim.objintparam_illumination_handle`（int32）— 照亮该对象的光源句柄，-1 为全部
- `sim.objfloatparam_transparency_offset`（float）
- `sim.objfloatparam_size_factor`（float）
- `sim.objstringparam_unique_id`（string，只读）— 持久唯一标识
- `sim.objintparam_visible`（int32，只读）

### 关节（Joints）

- `sim.jointfloatparam_intrinsic_x/y/z` / `_qx/qy/qz/qw`（float，只读）— 关节内禀变换
- `sim.jointfloatparam_velocity`（float，只读）— 关节速度
- `sim.jointfloatparam_upper_limit`（float）
- `sim.jointfloatparam_kc_k` / `_kc_c`（float）— 弹簧控制 K/C
- `sim.jointfloatparam_error_x/y/z` / `_a/b/g` / `_pos` / `_angle`（float，只读）— 内禀误差
- `sim.jointfloatparam_spherical_qx/qy/qz/qw`（float，只写）— 球关节四元数（qw 提交）
- `sim.jointfloatparam_screwlead`（float）— 螺距
- `sim.jointfloatparam_maxvel` / `_maxaccel` / `_maxjerk`（float）
- `sim.jointintparam_vortex_dep_handle` / `sim.jointfloatparam_vortex_dep_multiplication` / `_dep_offset` — Vortex 关节依赖
- `sim.jointintparam_dynctrlmode`（int32）— 动态控制模式
- `sim.jointintparam_dynvelctrltype` / `_dynposctrltype`（int32）— 速度/位置控制类型（0 默认 / 1 motion profile）

### 形状（Shapes）

- `sim.shapeintparam_static` / `_kinematic` / `_respondable` / `_respondablesuspendcnt`（int32）
- `sim.shapefloatparam_mass`（float）
- `sim.shapefloatparam_init_velocity_x/y/z` / `_a/b/g`（float）— 初始动态速度
- `sim.shapeintparam_culling` / `_wireframe` / `_compound` / `_convex` / `_convex_check` / `_respondable_mask` / `_edge_visibility` / `_edge_borders_hidden` / `_component_cnt` / `_sleepmodestart`（int32）
- `sim.shapefloatparam_texture_x/y/z/a/b/g` / `_texture_scaling_x/y`（float）
- `sim.shapefloatparam_shading_angle` / `_edge_angle`（float）
- `sim.shapestringparam_colorname`（string）— 颜色名

### 视觉传感器 / 相机

- `sim.visionfloatparam_near_clipping` / `_far_clipping` / `_perspective_angle` / `_ortho_size`（float）
- `sim.visionintparam_resolution_x` / `_resolution_y`（int32）
- `sim.visionintparam_disabled_light_components` / `_rendering_attributes` / `_entity_to_render` / `_render_mode` / `_perspective_operation` / `_windowed_size_x/y` / `_windowed_pos_x/y` / `_pov_focal_blur` / `_pov_blur_sampled` / `_rgbignoredint` / `_depthignoredint`（int32）
- `sim.visionfarrayparam_viewfrustum`（float array）— 近/远视锥角点

## 七、Properties 体系（4.10 推荐）

### 概念

4.10 起，**所有内部变量/状态都可作为 property** 读写，经统一 API：

```python
sim.getStringProperty(sim.handle_app, 'settingsPath')          # app 级
sim.setVector3Property(sim.handle_scene, 'gravity', [0,0,0])   # 场景级
sim.getFloatArrayProperty(jointHandle, 'interval')             # 对象级：关节上下限
sim.getIntArrayProperty(shapeHandle, 'meshes')                 # 对象级：形状所含网格句柄
sim.getFloatArrayProperty(meshHandle, 'vertices')              # 网格顶点
```

property 可读 / 可写 / 只读 / 只写 / 可移除：

```python
sim.setBoolProperty(shapeHandle, 'applyCulling', True)         # 只写
sim.removeProperty(objectHandle, 'customData.myFloatArray')    # 可移除
```

可用 [Modules > Developer tools > Property explorer] 附加组件交互查看。大部分 property 变更会触发事件，可经事件回调监听。

### 四类特殊前缀

| 前缀 | 性质 | target |
|------|------|--------|
| `customData.` | 持久化自定义数据（存盘），可创建/改/删 | app / scene / 对象 |
| `signal.` | 信号（易失），创建它的脚本状态销毁时自动清除 | app / scene / 对象 |
| `namedParam.` | 易失字符串，通常由 `-G` 命令行开关或用户设置注入 | app |
| `bullet.` / `ode.` / `newton.` / `vortex.` / `mujoco.` | 物理引擎相关参数 | scene / 对象 |

customData 示例（脚本 1 写、脚本 2 读）：

```python
# 写：将任意表打包为 buffer 存到对象上
myData = [1, 2, ["Hello", "world", True, {"value1": 63, "value2": "aString"}]]
sim.setBufferProperty(objectHandle, "customData.myTag", sim.packTable(myData))

# 读
buf = sim.getBufferProperty(objectHandle, "customData.myTag", {'noError': True})
if buf:
    myData = sim.unpackTable(buf)
```

signal 示例：

```python
sim.setIntProperty(sim.handle_scene, "signal.myIntSignal", 37)
v = sim.getIntProperty(sim.handle_scene, "signal.myIntSignal", {'noError': True})
```

namedParam 示例：

```python
arg = sim.getStringProperty(sim.handle_app, "namedParam.myCustomArgument")
```

### target 分类与高频 property（摘自 propertiesReference.htm）

**App（target = `sim.handle_app`）**：`appPath`、`productVersion`、`processId`、`platform`、`headlessMode`、`defaultPython`、`pythonPath`、`luaPath`、`mujocoPath`、`sessionRandomID`、`consoleVerbosity` / `dialogVerbosity` / `statusbarVerbosity`、`importExportPath` / `modelPath` / `scenePath`、`appArg1..9`、`randomFloat` / `randomQuaternion` / `randomString` 等。

**场景对象通用（target = 对象句柄）**：`alias`、`objectType`（只读）、`objectUid` / `persistentUid`（只读）、`parentHandle` / `parentUid`（只读）、`pose`、`bbPose` / `bbHSize`（只读）、`calcLinearVelocity` / `calcRotationVelocity` / `calcRotationAxis`（只读）、`layer`、`visible`（只读）、`selectable` / `selected`、`collidable` / `detectable` / `measurable` / `respondable`、`modelBase`、`model.*`（如 `model.notCollidable` / `_notDetectable` / `_notDynamic` / `_notMeasurable` / `_notRespondable` / `_notVisible` / `_scriptsNotActive` / `_propertyFlags`）、`mov.*`（移动权限：`mov.translInSim` / `_translNoSim` / `_rotInSim` / `_rotNoSim` / `_stepSize` / `_relativity` / `_prefTranslX..Z` / `_prefRotX..Z` 等）。

**形状属性**：`mass`、`centerOfMass`、`inertia`、`principalMomentOfInertia` / `pmiQuaternion`（只读）、`dynamic` / `kinematic` / `respondable` / `respondableMask`、`compound` / `convex` / `primitive`（只读）、`meshes`（只读）、`dynLinearVelocity` / `dynAngularVelocity`（只读）、`initLinearVelocity` / `initAngularVelocity`、`startInDynSleepMode`、`engineProperties`、`applyColor.*` / `applyCulling` / `applyShadingAngle` / `applyShowEdges` / `flipFaces`（只写），以及各引擎前缀参数（如 `bullet.friction` / `bullet.restitution` / `mujoco.friction` / `mujoco.margin` / `ode.maxContacts` / `vortex.restitution` 等）。

**关节属性**：`interval`（double[]，上下限）、`cyclic`、`calcVelocity`（只读）、`averageJointForce`（只读）、`dynCtrlMode` / `dynPosMode` / `dynVelMode`、`enforceLimits`、`intrinsicPose` / `intrinsicError`（只读）、`dependencyMasterHandle` / `dependencyParams`、`jointDiameter` / `jointLength`、`color.diffuse` / `_emission` / `_specular`、`engineProperties`、各引擎前缀参数（`bullet.posPid` / `bullet.stopErp` 等）。

其余对象类型（虚拟点、灯光、相机、视觉/近接/力传感器、图表、点云、OC 树、脚本、网格）的完整 property 列表见 `propertiesReference.htm`。

## 八、示例：用常量读对象参数与 property

下列 Python 代码经 ZMQ Remote API 在 4.10 上可直接运行，演示旧 parameter ID 与新 property 两套等价读法：

```python
# pip install coppeliasim-zmqremoteapi-client
from coppeliasim_zmqremoteapi_client import RemoteAPIClient

client = RemoteAPIClient()
sim = client.require('sim')

h = sim.getObject('/joint')                       # 取一个关节句柄

# --- 旧式：用常量 + getObjectXxxParam ---
vel = sim.getObjectFloatParam(h, sim.jointfloatparam_velocity)   # 关节速度（只读）
uid = sim.getObjectStringParam(h, sim.objstringparam_unique_id)   # 持久唯一 ID
layer = sim.getObjectInt32Param(h, sim.objintparam_visibility_layer)

# --- 新式：用 properties（推荐） ---
interval = sim.getFloatArrayProperty(h, 'interval')              # [下限, 上限]
cyclic = sim.getBoolProperty(h, 'cyclic')
calc_vel = sim.getFloatProperty(h, 'calcVelocity')               # 与上面 vel 等价
obj_type = sim.getStringProperty(h, 'objectType')                # 'joint' 等

# 场景级 property
gravity = sim.getVector3Property(sim.handle_scene, 'gravity')
sim_time = sim.getFloatProperty(sim.handle_scene, 'simulationTime')

# 自定义持久数据
sim.setBufferProperty(h, 'customData.note', sim.packTable({'tag': 'left_arm', 'idx': 3}))
note = sim.unpackTable(sim.getBufferProperty(h, 'customData.note', {'noError': True}))

print(vel, uid, layer, interval, cyclic, calc_vel, obj_type, gravity, sim_time, note)
```
