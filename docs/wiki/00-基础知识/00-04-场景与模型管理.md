# 场景与模型管理

> CoppeliaSim 的两个核心文件类型——场景（`.ttt`）与模型（`.ttm`）——构成仿真组织的基本单元。本条目以官方手册为准，梳理两者的区别、创建/加载/保存方法、场景对象类型清单、entity 概念及对象的层级与位姿。

## 场景与模型

场景（scene）与模型（model）是 CoppeliaSim 的两个主要仿真元素。模型是场景的一个子元素，不能独立存在，只能被场景包含后才可运行。两者都可包含：

- 场景对象（scene objects）
- 仿真脚本（simulation scripts）

场景额外包含以下专有元素：

- **环境（environment）**：环境光、雾、背景色等属性
- **主脚本（main script）**：默认主脚本允许在没有仿真脚本的情况下运行最小化仿真
- **页面与视图（pages and views）**：视图关联摄像机并显示其画面，视图被组织在页面中

文件格式：

| 类型 | 扩展名 | 内容 |
|------|--------|------|
| 场景 | `.ttt` | 完整场景（含环境/主脚本/页面视图/对象） |
| 模型 | `.ttm` | 模型基对象及其层级树的序列化数据 |

`.ttt` 与 `.ttm` 均支持在资源管理器与 CoppeliaSim 窗口之间拖放，也支持双击启动 CoppeliaSim 并打开。

## 模型理念：积木式可移植

模型由一组构建在同一层级树上的场景对象定义，树的根节点必须被标记为"Object is model base"。一个模型本身不能独立仿真，必须嵌入场景才能运行。

创建一个干净模型的步骤（见 `models.htm`）：

1. 将所有逻辑上属于该模型的对象直接或间接挂到模型树根节点下
2. 在对象属性对话框中勾选 **Object is model**
3. 点击 **Model properties** 设定整模型的覆盖属性（如整体不可见、整体不可碰撞），可快速禁用模型内全部对象的某些属性
4. 对模型内除根节点外的所有对象勾选 **select base of model instead**，防止误选个别子对象
5. 对通常不可见的对象勾选 **Ignored by model bounding box**，让模型包围盒尺寸正确
6. 考虑模型角色（可被挂到其他对象上？可接收其他模型？）并定义组装行为

模型根节点被选中时显示一个包围整个模型的虚线包围盒，并在层级视图左侧带有一个模型标签（model tag）。双击模型标签可打开模型对话框调整属性。复制/粘贴一个模型等价于先保存再加载（只是用内存缓冲区代替磁盘）。模型可在不同场景间复制，与普通对象无异。

这种"积木"式设计使得机械臂、夹爪、AGV 等都可以做成可重用模型，拖入场景即可使用——这正是 [[wiki/02-仿真建模/02-01-分层命名场景构建]] 所述分层命名场景构建的基础。

## 创建、加载与保存

### GUI 操作

- **新场景**：`File > New Scene`，创建默认场景（含若干摄像机/光源/视图/页面/环境/地板模型/默认主脚本）
- **加载场景**：`File > Open Scene...`，或拖放/双击 `.ttt` 文件
- **保存场景**：`File > Save Scene` / `File > Save Scene as...`
- **加载模型**：`File > Load model...`，或从模型浏览器拖放到场景视图
- **保存模型**：选中唯一一个被标记为 model base 的对象后 `File > Save model as...`

### ZMQ Remote API（Python）

```python
from coppeliasim_zmqremoteapi_client import RemoteAPIClient

client = RemoteAPIClient()
sim = client.require('sim')

# 保存当前场景到 .ttt 文件
sim.saveScene('myScene.ttt')

# 也可不写盘，返回序列化 buffer
buf = sim.saveScene()  # filename 省略时返回 buffer

# 加载场景（空字符串加载默认场景）
sim.loadScene('myScene.ttt')
# 保留当前场景：在文件名后追加 "@keepCurrent"
sim.loadScene('myScene.ttt@keepCurrent')

# 保存模型：base 句柄须为"Object is model base"标记对象
base = sim.getObject('/robot')
sim.saveModel(base, 'robot.ttm')

# 加载模型，返回模型根句柄
handle = sim.loadModel('robot.ttm')

# 仅取模型缩略图（128x128x4 rgba）
thumb = sim.loadModel('robot.ttm', True)
```

API 说明（见 `regularApi/simLoadScene.htm` 等）：

- `sim.loadScene(filenameOrBuffer)`：加载场景；空字符串加载默认场景；默认覆盖当前场景，追加 `@keepCurrent` 保留当前场景
- `sim.saveScene(filename=None)`：保存场景；`filename` 省略时返回序列化 buffer；同名文件会被覆盖
- `sim.loadModel(filename)`：加载模型并选中，返回模型根句柄；扩展名必须为 `.ttm` 或 `simmodel.xml`；第二参数 `onlyThumbnail=True` 仅取缩略图
- `sim.saveModel(baseHandle, filename=None)`：保存模型（根对象及其整棵层级树）；`filename` 省略时返回 buffer

## 场景对象类型总览

场景对象（scene objects）是构建仿真场景的主要元素，在层级视图与场景视图中可见。以下是完整类型清单（每类一句话，依 `objects.htm`）：

| 类型 | 说明 |
|------|------|
| **Shapes（形状）** | 由三角面组成的刚体网格 |
| **Joints（关节）** | 在相连对象间提供 1 或 3 自由度的对象，可为被动或主动（驱动） |
| **Graphs（图表）** | 用于记录并可视化仿真数据 |
| **Dummies（虚拟点）** | 带朝向的点，多用途对象，详见 [[wiki/02-仿真建模/02-04-虚拟点-Dummy]] |
| **Proximity sensors（接近传感器）** | 在其检测体积内以几何精确方式检测特定场景对象 |
| **Vision sensors（视觉传感器）** | 摄像机型传感器，对光、颜色和图像作出反应 |
| **Force sensors（力传感器）** | 测量施加其上的力与力矩 |
| **Cameras（摄像机）** | 允许从不同视点观察仿真场景 |
| **Lights（光源）** | 照明仿真场景 |
| **OC trees（八叉树）** | 由体素（voxel）组成的空间分区数据结构 |
| **Point clouds（点云）** | 包含点的 OC 树结构 |
| **Paths（路径）** | 空间中带朝向的一连串点；属于"伪场景对象"，由多个场景对象构成 |
| **Script objects（脚本对象）** | 包裹为场景对象的脚本，作为仿真脚本或定制脚本 |

形状与几何体的详细建模见 [[wiki/02-仿真建模/02-02-形状与几何体]]。

## 对象的四种特殊属性

部分场景对象具有特殊属性，决定其他对象或功能如何与其交互（见 `objects.htm`）：

- **Collidable（可碰撞）**：可与其他可碰撞对象进行碰撞检测
- **Measurable（可测量）**：可计算其与其他可测量对象间的最小距离
- **Detectable（可检测）**：可被接近传感器检测到
- **Viewable（可观察）**：可被透过、被看向，或其图像内容在视图中可视化

集合（collection）本身也是可碰撞、可测量、可检测的实体，并可覆盖其内对象的这些属性，详见 [[wiki/02-仿真建模/02-10-集合-Collections]]。

## entity：场景对象或集合

**entity（实体）** 是一个统称，指代 **场景对象** 或 **集合（collection）**。集合是用户定义的一组场景对象，常用于批量引用——例如检查两台机器人是否碰撞时，把每台机器人定义为一个集合，碰撞检测对就写作 `(collectionRobot1; collectionRobot2)`，算法会对两个集合中所有可碰撞对象两两检测。

集合的组成项可为：单个对象、对象树（含所有后代）、对象链（沿祖先向上）、全部场景对象；可加可减。集合不是静态的，会被持续评估/更新。集合定义与 `sim.createCollection` / `sim.addItemToCollection` 用法详见 [[wiki/02-仿真建模/02-10-集合-Collections]]。

## 父子层级与位姿

每个场景对象在场景中有一个位姿（pose）。对象可挂接到其他对象上构成父子层级：若对象 A 构建于对象 B 之上，则 B 为父，A 为子。

建立父子关系：

- 选中 A，再选 B（顺序重要），`Edit > Set parent, keep pose(s)`——A 的绝对位姿不变，但局部位姿被改写
- 或在层级视图中把 A 拖到 B 上
- 解除：选中 A 后 `Edit > Set parent-less`，或在层级视图中把 A 拖到 world 图标上

每个对象有：

- **绝对位姿（absolute/cumulative pose）**：相对于世界参考系
- **局部位姿（local/relative pose）**：相对于父对象参考系

当 A 成为 B 的子对象后，A 的绝对位姿不变，但局部位姿被重算；之后移动 B 时 A 会自动跟随。最近选中对象的绝对位姿显示在信息文本中，可通过 coordinates and transformations 对话框修改绝对/局部位姿。

## 导入与导出

CoppeliaSim 支持多种数据格式的导入/导出（见 `importExport.htm`）：

- **网格数据**：经 Assimp 插件，菜单 `File > Import > Meshes...` / `File > Export > Selected shapes...`；导入后若看不到形状多为尺寸过大/过小，需缩放；建议单机器人总三角面在 10,000–20,000 以内，过多可用 `Modules > Geometry / Mesh > Mesh decimation...` 简化
- **高度场**：`File > Import > Heightfield...`，支持图像/csv/txt
- **场景/模型 XML**：CoppeliaSim 原生 XML 格式
- **URDF**：`Modules > Importers > URDF importer...` / `Modules > Exporters > URDF exporter...`
- **SDF**：`Modules > Importers > SDF importer...`
- **GLTF**：`Modules > Exporters > GLTF exporter...`（静态场景）/ `GLTF animation exporter...`（动画）
- **图像**：`sim.loadImage` / `sim.saveImage`，另见 `sim.getScaledImage` / `sim.transformImage`
- **文本/二进制数据**：直接在脚本中用 Python `open` 或 Lua `io.open` 读写
- **户型图、LDR/MPD 模型**：经对应 add-on 导入

新的导入器/导出器可通过 add-on 或插件扩展。
