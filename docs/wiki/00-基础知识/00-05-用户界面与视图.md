# 用户界面与视图

> CoppeliaSim 应用窗口由应用栏、菜单栏、工具栏、模型浏览器、场景层级、状态栏、Commander、弹出菜单等元素组成。场景内容通过页面（page）与视图（view）呈现，视图关联可观察对象（camera 或 vision sensor）以显示其画面。本条目以官方手册为准，梳理界面布局、页面/视图机制、对象选择与鼠标操作、快捷键。

## 应用窗口的组成元素

CoppeliaSim 启动时会初始化一个默认场景，用户可并行打开多个场景，但同一时刻只有一个场景在应用窗口与对话框中可见。主要元素（依 `userInterface.htm`）：

| 元素 | 作用 |
|------|------|
| **控制台窗口（console）** | Windows 下默认隐藏（可在用户设置中改），Linux 下需从终端启动并保持可见。非交互式，仅输出插件加载/初始化信息；脚本可用 `print`、C 端可用 `printf`/`std::cout` 写入；也可用 API 编程创建辅助控制台 |
| **应用窗口（application window）** | 主窗口，用于显示、编辑、仿真并与场景交互。鼠标左/右键、滚轮、键盘的功能随上下文与激活位置变化 |
| **对话框（dialogs）** | 按相关功能或同一目标对象分组，内容随上下文（如选中状态）变化 |
| **应用栏（application bar）** | 显示许可证类型、当前场景文件名、一次渲染遍的耗时、仿真器当前状态（仿真状态或编辑模式）。应用栏及应用窗口任何表面都可拖放 `.ttt` 场景文件与 `.ttm` 模型文件 |
| **菜单栏（menu bar）** | 访问几乎所有功能，多数菜单项会激活一个对话框。内容上下文敏感。多数功能也可通过弹出菜单、层级视图图标双击或工具栏按钮访问 |
| **工具栏（toolbars）** | 工具栏 1 与工具栏 2，呈现高频功能（切换导航模式、选择页面等）。工具栏 1 部分功能、工具栏 2 全部功能也可经菜单栏/弹出菜单访问。两套工具栏可停靠/脱靠，但仅能停靠回各自初始位置 |
| **模型浏览器（model browser）** | 默认可见，可用对应工具栏按钮切换。上半部分显示 CoppeliaSim 模型文件夹结构，下半部分显示该文件夹下模型缩略图。缩略图可拖放到场景中自动加载该模型 |
| **场景层级（scene hierarchy）** | 默认可见，可切换。以树状显示场景中所有场景对象，可展开/折叠。双击图标打开/关闭相关属性对话框；双击别名可编辑别名。支持 Ctrl/Shift 多选。对象可拖放到另一对象上建立父子关系 |
| **状态栏（status bar）** | 显示与操作/命令相关的信息及脚本解释器的错误消息。脚本可用 `sim.addLog` 或 `print` 输出字符串到状态栏或控制台 |
| **Commander** | 状态栏上的 read-eval-print 循环文本输入，可即时输入并执行 Python 或 Lua 代码，可在 sandbox 或任何其他活动脚本中运行 |
| **弹出菜单（popup menu）** | 右键点击后出现。注意点击时鼠标不能移动，否则会激活相机旋转模式。应用窗口内的不同表面（场景层级、页面、视图等）触发不同弹出菜单，内容随仿真状态/编辑模式变化。多数弹出菜单功能也可经菜单栏访问，唯独 view-menu 项仅在视图/页面上激活弹出菜单时出现 |

## 页面与视图

页面（page）是场景的主要查看面，本身不是视图，而是可包含一个、两个或任意数量视图的容器。视图（view）用于显示某个可观察对象（viewable object）的图像内容；若视图关联了 camera，就显示该 camera 所见。每个场景有 **8 个可自由配置的页面**，通过页面选择工具栏按钮切换显示。

页面/视图的关键机制（依 `pagesAndViews.htm`）：

- 新场景创建时，8 个页面各自预配置为不同样式
- **移除页面**：弹出菜单 `Remove Page`；被移除的页面显示为深灰色面，移除页面会同时移除其所有视图，但不移除关联的对象
- **新建/配置页面**：弹出菜单 `Set-Up Page With...`，可从若干预设配置中选 1–8 个固定视图的布局（浅灰色面代表未关联的空视图）
- **浮动视图**：在现有页面布局之上，可用 `Add > Floating View` 添加不限数量的浮动视图。浮动视图可移动和调整大小，但不支持鼠标左/右键导航（如相机平移/旋转）。双击浮动视图可与视图索引 0 交换内容（该操作可被编程禁用）；点击其右上角按钮可移除

### 视图与可观察对象的关联

可观察对象（viewable objects）是能被"看穿""被看"或能显示图像内容的对象，包括 **Cameras** 与 **Vision sensors**（依 `viewableObjects.htm`）。一个可观察对象可同时关联任意数量的视图。

关联方式：

1. 选中对象，在目标视图上点击弹出菜单 `View > Associate view with selected camera` 或 `View > Associate view with selected vision sensor`（弹出菜单会根据最近选中的对象自动调整项）
2. 或在视图上激活 `View > View selector...` 打开视图选择器
3. 视图已创建但尚未关联时，`Add > Camera` 会直接添加一个 camera 并关联到该视图

Vision sensor 的特殊行为：它需要主动生成图像内容，且仅当合适的 API 命令被调用时才生成。默认主脚本包含 `sim.handleVisionSensor(sim.handle_all)` 处理场景中所有 vision sensor；除非某 vision sensor 被标记为 explicit handling 但未被显式处理，否则其图像内容会在仿真中生成。

## 对象选择

在场景层级或页面上，选择支持 Ctrl/Shift 多选。快捷键（依 `shortcuts.htm`，焦点须在场景层级或页面上）：

- `Ctrl+A`：全选
- `Esc`：清除选择
- `Ctrl+C` / `Ctrl+V` / `Ctrl+X`：复制 / 粘贴 / 剪切
- `Delete` / `Backspace`：删除选择

对象也可在层级视图中拖放以建立父子关系，详见 [[wiki/00-基础知识/00-04-场景与模型管理]]。

## 鼠标移动对象

除通过坐标与变换对话框修改位姿外，对象可被选中后用工具栏按钮直接用鼠标平移/旋转（依 `objectMovement.htm`）：

- **平移**：默认在世界 X-Y 平面。可在位置对话框中改为沿不同轴/平面、相对不同参考系。青色叠加图指示当前平移平面/轴
- **旋转**：默认绕对象自身 Z 轴。可在方向对话框中改为绕不同轴或相对不同参考系。叠加图指示当前旋转轴
- **吸附步长**：默认推荐 5 cm / 5°，可在用户设置对话框调整，也可按对象单独设置。**按下鼠标键后** 按住 Shift 可临时禁用吸附；按住 Ctrl 可临时切换到备选平移/旋转轴
- 对象/项平移工具栏按钮在顶点编辑模式下也可使用

## 常用快捷键

焦点在场景层级或页面时（依 `shortcuts.htm`）：

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+O` | 打开场景 |
| `Ctrl+N` | 新场景 |
| `Ctrl+S` | 保存场景 |
| `Ctrl+W` | 关闭场景 |
| `Ctrl+Q` | 退出应用 |
| `Ctrl+Space` | 启动/停止仿真 |
| `Ctrl+E` | 在 1) 普通、2) 对象平移、3) 对象旋转鼠标模式间切换 |
| `Ctrl+D` | 打开对象属性对话框 |
| `Ctrl+G` | 打开计算模块对话框 |
| `Ctrl+B` | 调整视图以适配选中对象（无选中则适配整个场景），焦点须在视图上 |
| `Ctrl+Alt+C` | 聚焦到 Commander |
| `Ctrl+L` | 清除状态栏（焦点在 Commander 时） |
