# CoppeliaSim 4.10 安装与设置

## 系统要求

| 平台 | 要求 |
|------|------|
| **操作系统** | Windows 10/11 (64-bit), Ubuntu 20.04/22.04/24.04, macOS 12+ |
| **CPU** | 支持 SSE4.2 的 x86-64 处理器 |
| **内存** | 最低 4GB，推荐 16GB+ |
| **GPU** | 支持 OpenGL 3.3+ 的显卡 |
| **磁盘空间** | 约 2.5GB（完整安装） |

## 下载

从 [Coppelia Robotics 官网](https://www.coppeliarobotics.com/downloads) 下载对应平台的 CoppeliaSim 4.10 版本。

版本选择：
- **EDU** — 教育版（免费，带水印，用于学习研究）
- **Player** — 播放器版（免费，只能运行已保存的场景）
- **Pro** — 专业版（付费，全功能）

## Windows 安装

1. 下载 `CoppeliaSim_Edu_V4_10_Setup.exe`（教育版）或对应版本
2. 运行安装程序，选择安装目录（推荐 `C:\Program Files\CoppeliaSim\`）
3. 安装完成后，运行 `coppeliaSim.exe`
4. （可选）将安装目录添加到系统 PATH 环境变量

## Ubuntu 安装

```bash
# 下载并解压
cd ~
wget https://www.coppeliarobotics.com/files/CoppeliaSim_Edu_V4_10_Ubuntu22_04.tar.xz
tar -xf CoppeliaSim_Edu_V4_10_Ubuntu22_04.tar.xz
cd CoppeliaSim_Edu_V4_10_Ubuntu22_04

# 运行
./coppeliaSim.sh
```

### 常见问题修复

```bash
# 如果缺少库文件
sudo apt update
sudo apt install libgl1-mesa-glx libglu1-mesa libxcb-icccm4 \
                 libxcb-image0 libxcb-keysyms1 libxcb-render-util0 \
                 libxcb-xinerama0 libxcb-xkb1 libxkbcommon-x11-0 \
                 libsm6 libpng16-16

# 如果使用 Wayland（推荐使用 Xorg）
export QT_QPA_PLATFORM=xcb
./coppeliaSim.sh
```

## 初始设置

### 1. 选择物理引擎
启动后，通过 `Tools → Calculation Modules → Dynamics` 选择物理引擎：
- 默认：Bullet（通用推荐）
- 可选：ODE, Newton, MuJoCo

### 2. 设置工作目录
`Tools → Options → General → Default directory for scenes`

### 3. 插件检查
启动时查看终端输出，确认必要插件已加载：
```
Plugin 'simIK': loading...
Plugin 'simIK': success.
Plugin 'simOMPL': loading...
Plugin 'simOMPL': success.
```

### 4. 验证安装
打开示例场景验证安装：
1. `File → Open scene` → `scenes/simulationExamples/bubbleRobExplicitHandling.ttt`
2. 点击"运行仿真"按钮（▶）
3. 观察 BubbleRob 机器人是否正常移动

## ROS2 集成设置

详见 [[wiki/05-数字孪生与协同仿真/05-01-ROS2集成]]

```bash
# 简要步骤
# 1. 确保 ROS2 已正确安装
source /opt/ros/humble/setup.bash  # 或 jazzy/rolling

# 2. 加载 ROS2 插件
cd CoppeliaSim_Edu_V4_10_Ubuntu22_04
cp compiledROSPlugins/libsimROS2.so .
```

## Python 绑定设置

### ZeroMQ Remote API
```bash
pip install coppeliasim-zmqremoteapi-client
```

### PyRep（适用于研究开发）
```bash
git clone https://github.com/stepjam/PyRep.git
cd PyRep
pip install -r requirements.txt
pip install .
export COPPELIASIM_ROOT=~/CoppeliaSim_Edu_V4_10_Ubuntu22_04
```

## 目录结构说明

安装后的关键目录：
```
CoppeliaSim_Edu_V4_10/
├── coppeliaSim.exe / .sh       # 主程序
├── scenes/                      # 示例场景
├── models/                      # 示例模型
├── plugins/                     # 插件目录
├── compiledROSPlugins/          # ROS 编译插件
├── lua/                         # Lua 标准库
├── textures/                    # 纹理资源
└── system/                      # 系统脚本
```

## 环境变量

| 变量 | 说明 | 推荐值 |
|------|------|--------|
| `COPPELIASIM_ROOT` | CoppeliaSim 根目录 | `/path/to/CoppeliaSim_Edu_V4_10` |
| `QT_AUTO_SCREEN_SCALE_FACTOR` | 高 DPI 缩放 | `1` |
| `QT_QPA_PLATFORM` | 显示平台 (Linux) | `xcb` (Wayland 问题修复) |
