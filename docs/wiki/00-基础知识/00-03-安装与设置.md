# CoppeliaSim 安装与设置

> 基于 CoppeliaSim 4.10 官方手册（`environment.htm`/`settings.htm`/`commandLine.htm`/`compilingCoppeliaSim.htm`/`addOns.htm`/`licensing.htm`）。手册 `welcome.htm` 首页标注 Version 4.10。

## 许可与版本（`licensing.htm`）

CoppeliaSim 提供三种授权，本仓库使用教育版：

| 版本 | 说明 |
|------|------|
| **CoppeliaSim Edu** | 教育版免费。仅限学校/大学的**学生、教师、教授**使用；不得用于公司、研究机构、非营利组织或商业用途。场景视图带 "EDU" 水印，不可去除。 |
| **CoppeliaSim Pro** | 商业付费，全功能。 |
| **CoppeliaSim Lite** | 嵌入式运行时版本，可随自有应用分发。 |

> 几何/运动学插件（`simGeom`/`simIK`）有独立教育许可，同样仅限教育实体非商业使用。

从 [Coppelia Robotics 官网](https://www.coppeliarobotics.com/downloads) 下载对应平台包，解压/安装后即可运行，无需额外安装步骤。手册（`welcome.htm`）指出用户手册已包含在下载包内。

## 跨平台与目录结构

CoppeliaSim 跨平台（Windows / Linux / macOS），支持创建便携、可扩展内容：单个便携文件可包含完整可用的模型或场景（含控制代码）。

安装后关键目录（本仓库实测）：

```
CoppeliaSim_Edu_V4_10_*/
├── coppeliaSim.exe / coppeliaSim.sh   # 主程序（客户端，加载 coppeliaSimLib 共享库）
├── scenes/                             # 示例场景 (.ttt)
├── models/                             # 示例模型库
├── addOns/                             # add-on 脚本目录 (.py / .lua)
├── plugins/                            # 插件目录
├── lua/                                # Lua 标准库 / base.lua / sim.lua
├── system/                             # 系统文件，含 usrset.txt 用户设置
├── textures/                           # 纹理资源
└── compiledROSPlugins/                 # ROS 编译插件（按需）
```

> `coppeliaSim`（或 `.exe`）只是加载共享库 `coppeliaSimLib` 的默认客户端；也可自行编译客户端替换（见编译小节）。

## 命令行参数（`commandLine.htm`）

从命令行启动 CoppeliaSim 时支持以下参数：

| 参数 | 作用 |
|------|------|
| `-v<verbosity>` | 控制台日志级别。默认 `loadinfos`；可选 `none`/`errors`/`warnings`/`loadinfos`/`scripterrors`/`scriptwarnings`/`scriptinfos`/`infos`/`debug`/`trace`/`tracelua`/`traceall`。运行时可经 `consoleVerbosity` property 修改。 |
| `-w<verbosity>` | 状态栏日志级别。默认 `scriptinfos`。 |
| `-x<verbosity>` | 简单对话框日志级别。默认 `infos`；可选 `none`/`errors`/`warnings`/`questions`。 |
| `-c<scriptString>` | sandbox 初始化后立即执行该脚本字符串。 |
| `-H` | 真·headless 模式（无 GUI 及 GUI 依赖），改用 `coppeliaSimHeadless` 库；仍需 display server。vision sensor 不工作（除非 Pov-Ray 渲染），渲染显著变慢。 |
| `-h` | 仿真 headless：仅隐藏 GUI 元素，其余正常运行。 |
| `-s<simulationTimeInMM>` | 自动启动仿真并运行指定毫秒；`0` 表示不自动停止。 |
| `-q` | 首次仿真结束后自动退出。 |
| `-a<addOn.lua>` / `-b<addOn.lua>` | 加载并运行额外 add-on。 |
| `-G<key>=<value>` | 命名参数，可在脚本中经 named parameter properties 查询。如 `-Glicense=licenseKey`、`-GpreferredSandboxLang=python`。 |
| `-g<string>` | 可选字符串参数，经 `appArg*` properties 查询。 |
| `-O<bitCoded>` | 禁用特定 GUI 项。 |
| `-f<scene.ttt>` 或 `-f<scene.simscene.xml>` | 加载场景。 |
| `-f<model.ttm>` 或 `-f<model.simmodel.xml>` | 加载模型。 |

手册给出的完整示例（headless 加载场景、运行 5 秒后退出）：

```bash
# Windows
coppeliaSim.exe -h -s5000 -q myScene.ttt

# Linux
./coppeliaSim.sh -h -s5000 -q myScene.ttt

# macOS
./coppeliaSim.app/Contents/MacOS/coppeliaSim -h -s5000 -q ../Resources/myScene.ttt
```

> ⚠ 手册特别说明：`-s` 不再允许单独使用，需写成 `-s0`（带值）。

## 用户设置文件 usrset.txt（`settings.htm` / `commandLine.htm`）

启动时读取 `system/usrset.txt`（位置可通过 `settingsPath` property 查询），设置涵盖调试、渲染/显示、目录、序列化、消息、兼容性、浮动许可等。可通过 `[Tools > Settings]` 打开用户设置对话框（部分反映 `usrset.txt` 内容）。

常用设置项：

- **Translation step size** / **Rotation step size**：对象平移/旋转步长（建议 5cm）。
- **Undo/redo enabled**：通过序列化整个场景到内存实现差量记忆，场景极大或机器老旧时可关闭。
- **Display world reference**：视图左下角世界坐标系显示。
- **Auto-save enabled**：定期自动保存已打开场景，崩溃后可恢复；延迟在 `usrset.txt` 中调整。
- **Hide console window**：默认隐藏控制台（macOS 在系统控制台查看 stdout）。
- **Hide hierarchy during simul.**：仿真运行时自动隐藏场景层级。
- **OpenGL settings**：offscreen context 类型、FBO 类型、VBO 操作、idle fps。
- 兼容性相关：`useBuffers`（关闭 V4.7 buffer）、`scriptConversion`（设 `-1` 转回旧 associated scripts）、`useSceneObjectScripts`（设 `false` 回退旧脚本）、`notifyDeprecated`（弃用告警冗长度 0/1/2）。

命令行 verbosity 也可在 `usrset.txt` 中覆盖：`verbosity`、`statusbarVerbosity`、`dialogVerbosity`、`consoleLogFilter`。

## 环境变量（`commandLine.htm`）

| 变量 | 作用 |
|------|------|
| `COPPELIASIMPLUGIN_IGNORE_MISSING_SYMBOLS` | 定义后插件忽略缺失符号 |
| `COPPELIASIM_USER_SETTINGS_FOLDER_SUFFIX` | 给用户设置目录追加后缀，可并行运行多个不同设置的实例 |
| `COPPELIASIM_CONSOLE_LOG_FORMAT` | 控制台日志格式，如 `[{origin}:{verbosity}]   {message}` |
| `COPPELIASIM_STATUSBAR_LOG_FORMAT` | 状态栏日志格式（支持 HTML 颜色） |
| `COPPELIASIM_STATUSBAR_LOG_FORMAT_UNDECORATED` | undecorated 模式下的状态栏日志格式 |

## Add-ons 激活（`addOns.htm`）— 本仓库必需

**Add-on** 是程序启动时自动加载的后台脚本，持久跨所有场景，可线程化或非线程化，按固定顺序与其它脚本类型协作执行。经 `[Menu bar > Modules]` 访问。

放置规则：

- 位于 `<CoppeliaSim folder>/addOns/` 目录，扩展名指示语言（`.py` 或 `.lua`）。
- 默认随 CoppeliaSim 启动自动加载；也可经命令行 `-a`/`-b` 加载额外 add-on。
- 通过 `sysCall_info` 返回 `{autoStart = false}` 可改为手动启停。
- 支持 `sysCall_init`/`sysCall_addOnScriptSuspend`/`sysCall_addOnScriptResume`/`sysCall_cleanup` 等回调。

### ZMQ remote API server add-on（本仓库运行前提）

本仓库依赖 ZeroMQ Remote API 外部控制仿真。激活方式：菜单 **`Add-ons > ZMQ remote API server`**（默认端口 23000）。

激活后即可从外部 Python（或 C++/Java/Matlab 等）通过 `coppeliasim-zmqremoteapi-client` 连接并调用全部 `sim.*` 及插件命名空间 API。详见 [[wiki/01-API参考/01-02-Remote-API-ZMQ]] 与 [[wiki/00-基础知识/00-02-CoppeliaSim-v410-新特性]]。

## 状态栏 Commander（`commandLine.htm`）

由 `simCmd` 插件实现的 REPL，在状态栏提供文本输入，可即时执行 Python 或 Lua 代码（在 sandbox 或任意活动脚本中运行）。经 `[Modules > commander]` 控制；`help()` 显示用法。headless 模式下也支持（基于 replxx，含行编辑/历史/TAB 补全）。

## 编译 CoppeliaSim（`compilingCoppeliaSim.htm`）

完整源码（含多数插件）在 GitHub。许可：`coppeliaSimLib` 为 GNU GPL；几何/运动学插件有特殊教育许可。

编译要求与建议：

- **CoppeliaSimLib 与几何插件为 Qt 项目**，需安装 Qt。尽量使用与官方 Edu 二进制相同的 Qt 版本与编译器（`[Help > About]` 查看）。
- 需下载编译 **QScintilla2**（C++ 编辑器控件）。
- 需安装 **Boost C++ 库**。
- 需 **Lua 5.3** 二进制与头文件。
- Ubuntu 为推荐 Linux 发行版。

步骤：下载 Edu 版安装 → 将 CoppeliaSimLib 源码（及可选插件源码）放入 Edu 安装目录 → 调整 `config.pri` 中各路径 → 编译。

`coppeliaSimLib` 编译为共享库；默认客户端 `coppeliaSim`/`.exe` 加载它。加载成功需满足：客户端能在共享库中找到全部所需函数；共享库能找到全部依赖（如 Lua 共享库）。最简做法：把编译产物复制进 CoppeliaSim 目录。

> ⚠ 关键约束：**不要混用不同 Qt 版本或不同编译器的二进制**。若主库用 Qt X + 编译器 Y 编译，所有插件也必须用 Qt X + 编译器 Y，否则可能出现库无法加载、莫名崩溃。插件不调用 Qt 函数时可放宽。

## 场景环境属性（`environment.htm`）

注意：手册中 "environment" 指场景级环境属性（非安装环境），包含背景色、雾参数、环境光、场景创建信息、附加设置等。这些属性随场景保存（不随模型保存）。

## 本仓库运行前提（关联 [CLAUDE.md](../../../CLAUDE.md)）

运行本仓库 v1 产品需满足 3 条前提：

1. **CoppeliaSim 4.10+ 已启动**（教育版即可）。
2. **ZMQ Remote API 服务端已激活**：菜单 `Add-ons > ZMQ remote API server`（默认端口 23000）。
3. **加载已校验的 v1 场景包**：`flexible-factory load` 根据
   `docs/scene_artifacts/v1/current.json` 加载包内的 `scene.ttt`，不隐式构建或清场。

Python 端始终为 clock master：`sim.setStepping(True)` 后每次 `sim.step()` 推进一个 `SIM_STEP`（默认 0.05s），控制逻辑与物理引擎严格同步。v1 的命令、场景包与运行方式见 [[wiki/98-ProjectUsage/USAGE]]；MCP 不在 v1 范围。
