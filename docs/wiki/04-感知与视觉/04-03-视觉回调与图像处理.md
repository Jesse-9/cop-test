# 视觉回调与图像处理

## 概念

当脚本对象的**父对象是视觉传感器**时，该脚本对象可包含一个 **vision callback 函数** `sysCall_vision`。系统在每次获取新图像或应用图像时调用该回调，允许用户在回调内执行图像处理。

触发 `sysCall_vision` 的 API 包括：

- `sim.handleVisionSensor`
- `sim.checkVisionSensor`
- `sim.checkVisionSensorEx`
- `sim.setVisionSensorImg`

## sysCall_vision 签名

```python
# python
def sysCall_vision(inData):
    # inData['handle']: 视觉传感器句柄
    # inData['resolution']: [x, y] 分辨率
    # inData['clippingPlanes']: 近/远裁剪面
    # inData['viewAngle']: 透视模式下的视角
    # inData['orthoSize']: 正交模式下的视口尺寸
    # inData['perspectiveOperation']: 是否透视模式
    outData = {}
    outData['trigger'] = False        # True 表示让传感器触发
    outData['packedPackets'] = []     # 打包的附加数据包，可经 sim.readVisionSensor 读取
    return outData
```

```lua
-- lua
function sysCall_vision(inData)
    -- inData.handle / inData.resolution / inData.clippingPlanes
    -- inData.viewAngle / inData.orthoSize / inData.perspectiveOperation
    local outData = {}
    outData.trigger = false
    outData.packedPackets = {}
    return outData
end
```

`outData.packedPackets` 中的附加数据包需为打包形式（Python 用 `struct.pack`，Lua 用 `sim.packFloatTable`），可经 `sim.readVisionSensor` 的 `packet2...` 读取。

## 三种图像处理路径

手册在 `syntheticVision.htm` 给出三种修改图像的方式，可在同一回调中混用：

### 1. simVision（vision plugin，简单处理）

`simVision` 命名空间提供基础图像处理函数。典型工作流：把传感器图像复制到工作图（work img），在工作图上处理，再写回传感器图。

```python
import struct

def sysCall_vision(inData):
    simVision.sensorImgToWorkImg(inData['handle'])
    simVision.edgeDetectionOnWorkImg(inData['handle'], 0.1)
    simVision.workImgToSensorImg(inData['handle'])
    outData = {}
    outData['trigger'] = True
    outData['packedPackets'] = [struct.pack('fff', * [1.0, 42.123, 129.3])]
    return outData
```

simVision 还维护两个内部缓冲（buffer1/buffer2），支持 `swapWorkImgWithBuffer1`、`addBuffer1ToWorkImg`、`subtractBuffer1FromWorkImg` 等双图运算。

### 2. simIM（image plugin，OpenCV 封装）

`simIM` 提供 OpenCV 封装的更强大图像处理。返回图像句柄，操作后写回传感器：

```python
def sysCall_vision(inData):
    imgHandle = simIM.readFromVisionSensor(inData['handle'])
    center = [inData['resolution'][0] / 2, inData['resolution'][1] / 2]
    radius = (inData['resolution'][0] + inData['resolution'][1]) / 8
    simIM.circle(imgHandle, center, radius, [255, 0, 255], 4)
    simIM.writeToVisionSensor(imgHandle, inData['handle'])
    simIM.destroy(imgHandle)
```

> `simIM` 是 image plugin 命名空间，需单独加载（`simIM = require('simIM')`）。

### 3. 直接操作图像缓冲

不依赖插件，用 Regular API 的 `sim.transformImage` / `sim.transformBuffer` 直接变换字节缓冲：

```python
def sysCall_vision(inData):
    image = sim.getVisionSensorImg(inData['handle'])
    sim.transformImage(image, inData['resolution'], 4)  # bit2=4: 翻转 y 轴
    image = sim.transformBuffer(image, sim.buffer_uint8rgb, 1, 0, sim.buffer_uint8bgr)
    sim.setVisionSensorImg(inData['handle'], image)
    outData = {}
    outData['trigger'] = True
    outData['packedPackets'] = [sim.packFloatTable([1, 42, 57])]
    return outData
```

## sim.transformImage

```python
bytes newImage = sim.transformImage(bytes image, list resolution, int options)
```

- `image`：rgb/rgba 值缓冲（Lua 中会被原地修改）。
- `resolution`：图像分辨率。
- `options`（位编码）：
  - `bit0`（1）：输入为 rgba（或深度缓冲，每像素一个 double），否则为 rgb；
  - `bit1`（2）：沿 x 轴翻转；
  - `bit2`（4）：沿 y 轴翻转。

## sim.transformBuffer

```python
# 形式 a：缓冲类型转换/线性变换
bytes outBuff = sim.transformBuffer(bytes inBuff, int inFormat, float mult, float off, int outFormat)
# 形式 b：按 splitSize 切分
list outBuff = sim.transformBuffer(bytes inBuff, sim.buffer_uint8, 0, int splitSize, sim.buffer_split)
```

线性变换关系：`out = off + mult * in`。常用场景：rgb→bgr 转换（`sim.buffer_uint8rgb` → `sim.buffer_uint8bgr`），或把 uint8 缓冲转 float 缓冲。

## simVision 命名空间函数清单

`simVision` 命名空间（vision plugin）的函数按用途分两类：

**图像处理（操作 work img / buffer）**：

| 函数 | 说明 |
|------|------|
| `sensorImgToWorkImg` | 传感器图 → 工作图 |
| `workImgToSensorImg` | 工作图 → 传感器图 |
| `sensorDepthMapToWorkImg` | 传感器深度图 → 工作图 |
| `workImgToSensorDepthMap` | 工作图 → 传感器深度图 |
| `swapWorkImgWithBuffer1` / `swapBuffers` | 工作图与缓冲互换 |
| `workImgToBuffer1` / `buffer1ToWorkImg` / `buffer2ToWorkImg` | 工作图与 buffer1/buffer2 互拷 |
| `addBuffer1ToWorkImg` / `addWorkImgToBuffer1` | 缓冲与工作图相加 |
| `subtractBuffer1FromWorkImg` / `subtractWorkImgFromBuffer1` | 相减 |
| `multiplyWorkImgWithBuffer1` | 相乘 |
| `uniformImgToWorkImg` | 用统一颜色填充工作图 |

**像素级运算**：`edgeDetectionOnWorkImg`、`blobDetectionOnWorkImg`、`colorSegmentationOnWorkImg`、`changedPixelsOnWorkImg`、`coordinatesFromWorkImg`、`binaryWorkImg`、`intensityScaleOnWorkImg`、`normalizeWorkImg`、`sharpenWorkImg`、`selectiveColorOnWorkImg`、`matrix3x3OnWorkImg`、`matrix5x5OnWorkImg`、`scaleAndOffsetWorkImg`、`shiftWorkImg`、`rotateWorkImg`、`resizeWorkImg`、`horizontalFlipWorkImg`、`verticalFlipWorkImg`、`circularCutWorkImg`、`rectangularCutWorkImg`。

**特殊传感器**：`createVelodyneHDL64E` / `destroyVelodyneHDL64E` / `handleVelodyneHDL64E`、`createVelodyneVPL16` / `destroyVelodyneVPL16` / `handleVelodyneVPL16`、`handleSpherical`、`handleAnaglyphStereo`、`distort`。

> `simVision` 不是 Regular API，而是 vision plugin 导出的命名空间，使用前需 `simVision = require('simVision')`。

## 工作图与缓冲模型

simVision 的处理模型围绕三个图像：

- **sensor img**：传感器当前持有的图像；
- **work img**：工作图，处理在此进行；
- **buffer1 / buffer2**：两个内部缓冲，用于双图运算（加减乘、差分等）。

典型模式：`sensorImgToWorkImg` → 在 work img 上做处理 → `workImgToSensorImg` 写回。需要前后帧对比时用 buffer 暂存上一帧。
