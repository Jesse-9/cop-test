# 视觉传感器 Vision sensor

## 概念

视觉传感器是一种**可视对象**，工作方式类似相机：渲染视场内的对象，并在指定阈值被越过/低于时触发检测。当颜色、光照或结构在检测过程中起作用时（红外传感器、对光敏感的相机类传感器等），应优先使用视觉传感器而非 proximity sensor。

> 切勿与相机混淆。主要区别见 [[wiki/04-感知与视觉/04-01-相机-Cameras]]：视觉传感器固定分辨率、图像可经 API 读取、较慢、主要渲染 shape。

## 投影类型

| 类型 | 视场形状 | 适用 |
|------|----------|------|
| 正交投影（Orthographic） | 矩形 | 近距离红外、激光测距 |
| 透视投影（Perspective） | 梯形 | 相机型传感器 |

视觉传感器作为可视对象，也可像相机一样"看穿"（`Popup menu > View > Associate view with selected vision sensor`）。

## 渲染与检测机制

视觉传感器通过**离屏渲染（offscreen rendering）**生成场景图像，随后可经视觉回调函数处理（见 [[wiki/04-感知与视觉/04-03-视觉回调与图像处理]]）。处理流程：

1. 清除上次图像处理数据；
2. 读取（渲染）一帧图像；
3. 经视觉回调函数执行图像处理；
4. 根据回调返回的 `trigger` 与阈值判定是否触发检测。

## 图像与深度获取

手册给出的相关 Regular API（均要求先调用 `sim.handleVisionSensor`，否则返回值无意义）：

```python
# 读取图像（RGB bytes，可用 sim.unpackUInt8Table 转 int 数组）
img, res = sim.getVisionSensorImg(vs, options=0, rgbaCutOff=0.0, pos=[0,0], size=[0,0])

# 读取深度缓冲（options bit0=1 返回米制距离，否则 0.0-1.0 归一化）
depth, res = sim.getVisionSensorDepth(vs, options=0, pos=[0,0], size=[0,0])

# 仅读取分辨率
res = sim.getVisionSensorRes(vs)  # [resX, resY]

# 写入图像（要求传感器勾选 External input）
sim.setVisionSensorImg(vs, img, options=0, pos=[0,0], size=[0,0])
```

`options` 位编码：`bit0`（1）返回灰度图，`bit1`（2）附加 alpha 通道（RGBA/灰度+A）。

## handleVisionSensor 与 readVisionSensor

```python
# 执行感知（清除旧数据 + 渲染 + 图像处理）
detectionCount, packet1, packet2, ... = sim.handleVisionSensor(vs)
# 或批量处理：sim.handle_all / sim.handle_all_except_explicit
```

`sim.handleVisionSensor` 返回：
- `detectionCount`：本次触发检测的视觉传感器数量；
- `packet1`：默认 15 个辅助值（intensity/red/green/blue/depth 的 min、max、avg）；
- `packet2...`：图像处理组件追加的辅助值包。

```python
# 仅读取上次 handle 的结果，不重新感知
result, packet1, packet2, ... = sim.readVisionSensor(vs)
```

`sim.readVisionSensor` 的 `result`：`0/1` 表示未触发/触发；`-1` 表示从未 handle 或已 reset。

## 渲染时机与 stepping 模式

视觉传感器的处理分两种触发路径：

1. **主脚本中批量处理**：主脚本调用 `sim.handleVisionSensor(sim.handle_all_except_explicit)` 处理所有"非显式"传感器。
2. **仿真脚本显式处理**：将传感器标记为 **Explicit handling**（在属性对话框勾选），则不会被 `handle_all_except_explicit` 触及，仅在脚本显式调用 `sim.handleVisionSensor(vsHandle)` 或 `sim.handleVisionSensor(sim.handle_all)` 时处理。

> 若不勾选 Explicit handling 而又在脚本里再调一次 `sim.handleVisionSensor(vsHandle)`，传感器会被处理两次。

**stepping 模式下的帧**：视觉传感器产生新帧的条件是 `sim.handleVisionSensor` 被调用。在 Python 端作为 clock master 的 stepping 模式下（`sim.setStepping(True)`），每次 `sim.step()` 推进一个 `SIM_STEP`；若该步内主脚本执行了 `handleVisionSensor`，则产生新帧。Python 端可在 `sim.step()` 前后调 `sim.getVisionSensorImg` 读取最新帧。

## 属性对话框关键参数

| 参数 | 说明 |
|------|------|
| Explicit handling | 显式处理（见上） |
| External input | 启用后处理外部图像（如视频帧） |
| Ignore RGB info (faster) | 忽略颜色，仅用深度 |
| Ignore depth info (faster) | 忽略深度 |
| Packet1 is blank (faster) | 不自动提取 packet1，更快 |
| Render mode | Legacy OpenGL / Legacy OpenGL color-coded handles / POV-Ray / OpenGL3 |
| Near / far clipping plane | 检测近/远距离 |
| Perspective angle / Orthographic size | 透视张角 / 正交视口尺寸 |
| Resolution X / Y | 图像分辨率；高分辨率更慢 |
| Default image color | 无渲染区域的默认色 |
| Show view frustum | 显示视锥体 |

Render mode 中 **Legacy OpenGL, color coded handles** 会把对象句柄编码进颜色，`packet1` 返回的即是检测到的对象句柄（向下取整）。

## 特殊传感器（special sensors）

vision plugin（`simVision` 命名空间）提供若干非通用相机的特殊传感器算法：

- **Velodyne HDL64E / VPL16**：`simVision.createVelodyneHDL64E` / `createVelodyneVPL16` 创建激光雷达数据生成句柄，`handleVelodyneHDL64E` / `handleVelodyneVPL16` 每帧推进，`destroyVelodyne*` 销毁。
- **球形视野（spherical）**：`simVision.handleSpherical` 处理球形全景。
- **立体视觉（anaglyph stereo）**：`simVision.handleAnaglyphStereo` 处理红蓝立体。
- **镜头畸变**：`simVision.distort` 对图像做畸变。

> 特殊传感器底层仍依赖普通 vision sensor 作为图像源，`simVision.*` 是在其基础上的后处理。

## 与本仓库的关系

`cop-test` 当前未启用视觉感知。若后续要加：

1. 在 `build_scene` 中为目标岛挂 vision sensor，启动时经别名扫描采集句柄（同 `RobotArmAnimator` 的句柄采集方式，不依赖斜杠路径 `getObject`）；
2. 控制层在 stepping 每步 `sim.step()` 后调 `sim.getVisionSensorImg` / `getVisionSensorDepth` 做识别/定位闭环；
3. 需要图像处理时在 sensor 的父脚本里实现 `sysCall_vision` 回调（见 [[wiki/04-感知与视觉/04-03-视觉回调与图像处理]]）。
