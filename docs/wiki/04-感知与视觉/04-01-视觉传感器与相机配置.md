# 视觉传感器与相机配置

## 概念区分

CoppeliaSim 中"看到场景"有两套不同对象，常被混淆：

| 对象类型 | 用途 | 是否参与渲染 |
|---------|------|-------------|
| `object_camera_type`（相机） | 视口观察视角，人看场景用 | 是 |
| `object_visionsensor_type`（视觉传感器） | 程序读取图像做感知，机器人"看"用 | 是 |

> ⚠ 清场脚本若把 `object_camera_type` 一并删除，视口会丢失默认观察视角。
> 视觉传感器则可按需重建——但默认相机丢失后需要手动重新添加相机才能正常观察。

## 创建视觉传感器

```python
vs = sim.createVisionSensor()
sim.setObjectAlias(vs, "Island/A_Assembly/Camera_A")
sim.setObjectPosition(vs, [x, y, z], sim.handle_world)
sim.setObjectOrientation(vs, [alpha, beta, gamma], sim.handle_world)
# 分辨率
sim.setObjectInt32Param(vs, sim.visionintparam_resolution_x, 640)
sim.setObjectInt32Param(vs, sim.visionintparam_resolution_y, 480)
```

## 通过 ZMQ Remote API 读图

```python
img, res_x, res_y = sim.getVisionSensorImg(vs)
# img 为 bytes / numpy 可解析的 RGB 缓冲
```

## 与本仓库的关系

`cop-test` 当前是**纯控制 + 视觉动画**层，未启用感知：`build_scene` 的 `clear_scene`
类型清单包含 `object_visionsensor_type` 和 `object_camera_type`，构建前会清掉这两类对象。
若后续要加视觉感知，应：

1. `clear_scene` 时保留相机（从类型清单移除 `object_camera_type`），或构建后重新挂一个默认相机
2. 在 `build_scene` 中为目标岛挂视觉传感器，并在启动时经别名扫描采集句柄（同 `FactoryController`/`RobotArmAnimator` 的句柄采集方式，不依赖斜杠路径 `getObject`）
3. 控制层按步进读取 `getVisionSensorImg`，做识别/定位闭环
