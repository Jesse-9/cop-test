# Lua 基本脚本模式与模板

## 脚本类型速查

| 脚本类型 | 运行方式 | 用途 | 挂载位置 |
|----------|----------|------|----------|
| 非线程子脚本 | 每仿真步执行一次 | 通用控制逻辑 | 场景对象 |
| 线程子脚本 | 独立循环 | 持续运行的任务 | 场景对象 |
| 定制化脚本 | 用户交互时触发 | UI 交互 | 模型/对象 |
| 主脚本 | 每仿真步执行一次 | 场景全局控制 | 场景根 |

## 1. 非线程子脚本 (Non-threaded Child Script)

最常用的脚本类型。每个仿真步依次调用各回调函数。

### 完整模板
```lua
-- 非线程子脚本模板
function sysCall_init()
    -- 初始化：获取对象句柄、加载模块、设置变量
    motor = sim.getObject('/joint_motor')
    sensor = sim.getObject('/proximity_sensor')
    targetPos = 0.0
    print("初始化完成")
end

function sysCall_actuation()
    -- 执行阶段：控制计算、运动指令
    local detected, dist, point = sim.readProximitySensor(sensor)
    if detected > 0 then
        targetPos = math.pi  -- 遇到障碍物旋转
    else
        targetPos = 0.0
    end
    sim.setJointTargetPosition(motor, targetPos)
end

function sysCall_sensing()
    -- 感知阶段：传感器读取、数据记录
    local time = sim.getSimulationTime()
    sim.setFloatSignal('current_time', time)
end

function sysCall_cleanup()
    -- 清理：关闭资源、保存数据
    print("脚本清理完成")
end

function sysCall_suspend()
    -- 暂停时调用（可选）
end

function sysCall_resume()
    -- 恢复时调用（可选）
end
```

### 调用顺序
```
⋮
├─ sysCall_actuation()    ← 先执行
├─ [物理引擎步进]
├─ sysCall_sensing()      ← 后执行
⋮
```

## 2. 线程子脚本 (Threaded Child Script)

独立运行的循环，适合连续控制任务。

### 完整模板
```lua
-- 线程子脚本模板
function sysCall_init()
    -- 初始化
    motor = sim.getObject('/joint_motor')
    targetPos = 0.0
end

function sysCall_thread()
    -- 主循环
    while sim.getSimulationState() ~= sim.simulation_advancing_abouttostop do
        
        -- 执行控制逻辑
        sim.setJointTargetPosition(motor, targetPos)
        
        -- 让出控制权（必须！）
        sim.switchThread()
        
        -- 可选：检查外部信号
        local cmd = sim.getFloatSignal('external_cmd')
        if cmd then
            targetPos = cmd
        end
    end
end

function sysCall_cleanup()
    -- 清理
    print("线程脚本结束")
end
```

### 线程挂起与恢复
```lua
function sysCall_thread()
    while true do
        -- 挂起等待条件
        sim.waitUntil(sim.getSimulationTime() > 10.0)
        
        -- 或挂起指定时间
        sim.wait(1.0)
        
        -- 或等待特定信号
        local sig = sim.waitForSignal('start_move', 5.0)  -- 超时5秒
        if sig then
            -- 执行动作
        end
    end
end
```

## 3. 定制化脚本 (Customization Script)

处理用户交互事件，不影响仿真核心逻辑。

### 模板
```lua
-- 定制化脚本模板
function sysCall_init()
    -- 初始化 UI 参数
    params = {
        speed = 1.0,
        amplitude = 0.5
    }
    
    -- 创建 UI（可选）
    createUI()
end

function sysCall_beforeDraw()
    -- 每帧绘制前调用
end

function sysCall_msg(msg)
    -- 处理消息
    if msg == 'speed_changed' then
        sim.setFloatSignal('speed', params.speed)
    end
end

-- 其他可能用到的回调
-- function sysCall_keyPress(keys) end
-- function sysCall_mouseDown(x, y, sel) end
-- function sysCall_mouseUp(x, y, sel) end

function sysCall_cleanup()
    -- 清理 UI
    destroyUI()
end
```

## 4. 常用工具函数

```lua
-- 延时（仿真时间）
sim.wait(duration)       -- 等待 duration 秒（仿真时间）
sim.waitUntil(timePoint) -- 等待直到指定时间

-- 线程控制
sim.switchThread()       -- 让出线程控制权
sim.setThreadIsFree(free) -- 设置线程是否空闲

-- 信号等待
sim.waitForSignal(name, timeout)  -- 等待信号，超时返回 nil

-- 类型转换
sim.packFloatTable({1.0, 2.0})   -- 打包浮点数组
sim.unpackFloatTable(data)       -- 解包
sim.packIntTable({1, 2, 3})      -- 打包整数数组
sim.unpackIntTable(data)         -- 解包

-- 数学工具
sim.getSimulationTime()     -- 当前仿真时间
sim.getSystemTime()         -- 系统时间（毫秒）
math.random()               -- Lua 原生随机数
sim.getRandom()             -- CoppeliaSim 随机数
```

## 6. Python 子脚本

CoppeliaSim 4.6+ 支持 Python 子脚本：

```python
# Python 子脚本模板
def sysCall_init():
    global motor, sensor
    motor = sim.getObject('/joint_motor')
    sensor = sim.getObject('/proximity_sensor')
    print("Python 脚本初始化完成")

def sysCall_actuation():
    global target_pos
    detected, dist, point = sim.readProximitySensor(sensor)
    if detected > 0:
        target_pos = 3.14159
    else:
        target_pos = 0.0
    sim.setJointTargetPosition(motor, target_pos)

def sysCall_sensing():
    pass

def sysCall_cleanup():
    print("Python 脚本清理完成")
```

## 7. 脚本间通信

### 父子脚本通信
```lua
-- 父脚本调用子脚本
local result = sim.callScriptFunction(
    "childFunction",       -- 函数名
    childScriptHandle,     -- 子脚本句柄
    arg1, arg2            -- 参数
)

-- 广播到所有脚本
sim.callScriptFunction("globalEvent", sim.handle_scene, eventData)
```

### 信号通信
```lua
-- 脚本 A 发送
sim.setFloatSignal('joint_target', 1.57)

-- 脚本 B 接收
local val = sim.getFloatSignal('joint_target')
```
