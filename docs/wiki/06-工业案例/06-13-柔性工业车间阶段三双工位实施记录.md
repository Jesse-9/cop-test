# 柔性工业车间阶段三：双工位实施记录

> 本文记录阶段三的实现边界、布局、任务链、资源锁和实测结果；详细
> 步骤见 [[wiki/06-工业案例/06-12-柔性工业车间阶段三双工位详细实施步骤]]，
> 完整证据与限制见 [[implementation/PHASE3_REPORT]]。

## 1. 实现范围

阶段三在已验收阶段二工件上派生双工位场景，不重建 A 单元、不复制第二套
生命周期：

```text
输入传送带共享取料区
  → UR5_A 取料并装载 AGV（dock A）
  → AGV 沿 x=0.40 直线带载到 dock B
  → UR5_B 从 AGV 载台取料并放置到 Station B
```

每台 UR5 拥有独立 simIK environment、影子臂、碰撞集合、
`ConfigurationChecker`、`LocalPlanner` 和 `Stage2Safety`。阶段三不包含
阶段 2.1 的统一故障恢复；锁存后只停止、保留现场、任务 FAILED。

## 2. 场景与工件

- 生产布局 `L2_MIRROR`：A/B 工位关于 Y=0 镜像；A 单元沿用 L1_S1。
- 父工件 `stage2/L1_S1/v013_20261024_232558`；
  阶段三工件 `stage3/L2_MIRROR/v004_20261025_131837`。
- 新增对象：`Island_B`、`Island_B_Station`、`Robot_UR5_02`、
  `SuctionPad_02`、`SuctionPad_02_TCP`、`Sensor_SuctionPad_02`、
  `IK_Target_02`、`Sensor_AGV_Dock_B`、`PlaceTarget_Station_A/B`、
  `Stage3_PickZone`。
- AGV 初始位姿改为 dock A `(0.40, 0.70)` 朝 −Y；dock A 传感器同步移动。
  这是构建期一次布局设置，运行期仍只通过左右轮 `setJointTargetVelocity`
  驱动。
- 工件含 109 项构建契约、229 项只读校验；`extra.stage3` 记录布局、
  资源表、AGV 路线、任务流、验收场景和父 stage2 契约/配置摘要。

## 3. 资源锁与任务流

固定申请顺序：

```text
pick_zone → agv_lane → dock_A → dock_B → arm_A → arm_B
```

- `pick_zone` 从 A 装载计划开始持有，TCP 退出 conveyor envelope 后释放；
- AGV 运输任务持有 `agv_lane`/`dock_B`，到站停稳并确认后释放；
- B 工位在 AGV 运输途中记录 `dock_B` WAIT，但不提前获取，避免死锁；
- 失败/停止释放普通调度锁；`Stage2Safety` 锁存独立保存，不因资源释放
  而清除；
- 同一 UID 的活动 `load_A`/`transport`/`unload_B` 重复提交被拒绝。

任务状态为 PENDING / WAITING / RUNNING / BLOCKED / DONE / FAILED /
REJECTED；`FAILED`/`BLOCKED` 不会改写成 `DONE`。

## 4. AGV 路线

- x=0.40 直线穿梭：A→B 前进带载，B→A 倒车空载；不在 dock 处原地旋转，
  避免车体扫过 Island/Station。
- 停止判据：位置误差 ≤ 0.02 m、航向误差 ≤ 0.08 rad、连续 5 步低速稳定；
  带载时载荷相对载台滑移 ≤ 0.02 m。
- 阻塞判据：轮速已下发但 3 s 窗口位移 < 0.01 m → BLOCKED、立即停车；
  清障后只有无安全锁存、障碍移除、位置/航向和资源所有权重新确认才
  允许 0.08 m/s 续行。
- 正常实测停靠误差 0.0195–0.0199 m，航向误差 < 0.0011 rad，滑移 0.0。

## 5. 验收结果

| 场景 | 结果 |
|---|---|
| A→B 闭环 | 3 任务 DONE；停靠 0.019733 m；滑移 0.0；物料 RELEASED 于 Station B |
| 竞争/重复请求 | 3 个重复请求被拒绝；1 次 dock_B WAIT；资源最终全部释放 |
| 受控阻塞 | t=44.90 BLOCKED；t=54.95 清障续行；停靠 0.019773 m |
| 不稳定卸载 | `LOAD_DRIFT(0.0400>0.02)` 锁存；unload FAILED；载荷仍吸附；未释放 |
| 双向路线基线 | A→B 带载 0.019742 m；B→A 空载 0.019522 m；滑移 0.0 |
| MCP 路由 | 自动 backend=stage3；三任务 DONE；生命周期/运行锁复用 |

证据文件见 `docs/implementation/evidence/phase3_*` 与
`stage3_layout_20261025.json`；原始 trace 在 `docs/implementation/runs/`
（不提交）。

## 6. 动作质量与限制

- A 装载总 TV 18.731 rad，`TV(q[3])=8.133`，`pre_place` 单段
  `TV(q[3])=4.931`；B 卸载总 TV 11.649 rad。
- 实测 jerk 峰值 113.9–120.7 rad/s³ > 目标 100；速度/加速度在限值内。
  MQ-01/MQ-02/MQ-03 未关闭，阶段三不宣称动作已优化。
- 阶段 2.1 故障恢复、OMPL、多物料/多 AGV、两臂并发未实现；碰撞检查
  仍为离散采样，不是连续碰撞证明。
- 改变布局、载荷、摩擦、轮速或动作参数后，必须重新派生工件并重跑
  阶段三五个场景及动作质量门槛。
