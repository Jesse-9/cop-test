# 柔性工业车间阶段 2.01：动作与轨迹优化

> 本阶段承接已完成的阶段二，在不改变工位布局、工具安装、接触语义和安全检查的前提下，减少不必要的腕部转动、分支跳变和冗余路径点。本文是设计与验收计划，不表示优化已经实施。

## 1. 问题与证据

阶段二已实现多解 simIK、连续 seed、关节流式执行、笛卡尔法向接近和逐段碰撞复核。实现对候选解使用关节距离排序，并对 q6 施加较小偏好；阶段二报告同时记录工具竖直时模型关节坐标 q5 接近 ±90°，q4/q6 耦合，近似直线上升可能出现绕工具 Z 轴的旋转。[阶段二规划器](../../../src/stage2/path_planning.py) [阶段二报告](../../implementation/PHASE2_REPORT.md)

本文 q1…q6 按 UR5 轴号从底座向末端编号；因此 q5 是第五轴 Wrist 2，在 Python 六元素数组中对应 `q[4]`。不同模型的零位/坐标约定可能不同，阶段二报告中的 ±90° 是当前模型实测值，不应直接当成通用 UR5 奇异角度。

当前问题不是任务失败：station、agv 和 both 的阶段二正常验收均通过。问题在于动作是否包含不影响抓放结果的关节行程，且既有报告未统计各动作段的关节总变差、最大单步变化和腕部翻转次数。当前运行报告主要保存最终计划，未完整提供 transfer 每个子段的最终关节统计，因此具体能否锁定某轴仍需按本方案实测。本阶段先建立可比较指标，再优化选解和段落目标；不以动画观感或单次成功作为效果证明。

现有阶段二的 `transit` 是高位且带基座方向偏移的中转位姿，`pre_place` 是目标放置位姿上方 `PRE_APPROACH_CLEARANCE` 的预接近位姿；因此当前 `transit → pre_place` 同时包含 XY 和 Z 的变化。2.01 将其拆成两个逻辑段：先在保持 `z_transit` 的高度上水平移动到目标正上方，再沿 Z 轴下降到 `pre_place`。这里的“目标正上方”采用新的逻辑 waypoint `high-above-place` 表示，不能把它与较低的 `pre-place` 名称混用。

`rise` 与 `pre-place` 高度并非理论上不能相等；准确的判断是，当前配置下它们承担不同的安全职责。`rise` 在取料点上方建立跨区域转运净空，宜与 `transit`/`high-above-place` 采用同一高位；`pre-place` 则是目标上方 0.15 m 的最终下降起点。当前取料 TCP 约为 z=0.55 m，lift 约为 z=0.70 m，`rise` 约为 z=0.82 m；station 的 `pre-place` 约为 z=0.55 m，AGV 约为 z=0.507 m。若把 rise 直接降到这些 pre-place 高度，带载物料在传送带上方几乎没有净空（AGV 目标甚至低于传送带面），不能作为当前布局的安全转运高度。只有重新定义高位/预接近语义，或完成整段碰撞与载荷净空验证后，才可合并高度。

## 2. 目标与边界

目标是在完成相同 TCP 任务和安全约束的候选路径中，选择关节变化较小、连续且没有突发腕部回绕的路径；运行轨迹不得切换腕部分支或穿越经当前模型标定的腕部奇异边界。合并确属冗余且语义、约束一致的路径点。

保持以下阶段二保证：完整路径仍经过限位、碰撞/距离、接触、载荷和 FK 检查；取放与放置的姿态要求不被降级；输出轨迹实际下发的每个新构型及其段仍被复核；规划失败时停止并报告失败原因。

本阶段不调整场景几何、UR5/TCP 模型、物理参数、布局、目标放置位姿和控制模式；不引入通用全局规划器、动力学伺服或故障恢复（后者仍属阶段 2.1）。按动作段评估关节保持不变的可行性；只有目标几何允许且全段安全、执行复核通过后才采纳段内锁轴。锁轴属于轨迹/IK 约束，不是关闭场景关节或跳过碰撞检查。

## 3. 优化策略

### 3.1 先量测，再对照

为每条规划路径按动作段记录六关节起止值、展开后的关节总变差 `sum(abs(delta_q))`、最大单步变化、路径点数、执行时间、IK 回退/失败、最小碰撞距离、TCP 误差、工具轴误差及路径检查结果。对有有限位的关节，统计和插值必须按真实限位内连续角处理，不允许 wrap 产生跨限位短路。

通过基线 stage2 工件对 station 和 agv 各执行一次可复现任务；保存起始构型、输入目标、候选路径摘要和运行证据。只在隔离派生工件中试验，避免更改已保护的 v008 和阶段一父工件。

### 3.2 冗余自由度按动作段处理

| 动作段                          | 几何事实与约束                                                                                                                | 方案判断                                                                     | 实验候选                                                                                     |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------- |
| pick → lift → rise           | 同一取料点竖直法向移动；rise 在 lift 上方再抬升 0.12 m，并作为跨区域高位净空；起点物料仍可能接触带面                                                                       | 可先试底座方位轴 `q[0]` 不变；其余关节连续求解，腕部分支保持不变                                     | 自由基线对比固定 q[0]；检查 TCP 直线偏差、带载扫掠、起点承载接触                                                    |

| pre-place → place            | 同 XY、同完整姿态，TCP 仅垂直下降 0.15 m。已有 station 安全端点候选中，joint1 (`q[0]`) 分别约 -0.170 和 -0.173 rad；但这不是同一条连续路径的配对解，只能说明值得测试，不能证明可锁 | **优先测试固定 q[0]（UR5 joint1/base axis）**；不是只动一个关节，q[1:4] 仍可能协同运动            | station、AGV 分别对比自由笛卡尔下降与固定 q[0]；复核姿态、TCP 直线误差、附着物、碰撞、接触                                  |

腕部分支连续性是硬约束：每段候选必须与当前已验证构型属于同一腕部分支；规划不得跨过当前 UR5 模型实测标定的腕部奇异边界来切换分支。若同分支内没有满足姿态、限位和碰撞条件的解，应返回规划失败，不回退到另一腕部分支，也不放宽安全约束。分支判别需以本模型的 IK 候选和关节轴/奇异边界测量为依据，不仅凭 q6 正负或某个关节单独阈值判断。

关节限制属于规划级约束，不修改模型自由度或关闭关节驱动。每次只改变一个因素：同腕部分支下增强连续性代价、工艺允许的有限工具 yaw 候选、段内固定单轴。固定轴无解时记录该目标不可用并退回同分支自由 IK；不得以切换腕部分支作为 fallback。

当前模型实测 q5 接近 ±90° 时 q4/q6 耦合。保持 q5 数值或最小化 q6 单变量都不能单独证明没有翻腕，也可能将转动转移到另一腕轴。因此方案须跟踪 IK 腕部分支并保持 q1…q6 的连续解；通过实测标定奇异边界及安全裕量，在边界前拒绝会跨支的候选。不得根据 q6 符号直接判定分支，也不得把 q6 小权重当作禁止翻腕的实现。

### 3.3 轨迹点精简

先区分语义 waypoint（接触、抬升、高位转运、预放置、放置、撤离）与数值离散点。语义 waypoint 不因关节代价而删除。仅当相邻段具有相同载荷、接触和姿态策略，且合并后实际生成的 TCP 路径仍满足原几何意图、碰撞采样和执行预算时，才可精简重复/共线点。对轨迹平滑或时间参数化后的实际输出重新执行路径复核；不因点数减少而降低原有检查分辨率保证。

## 4. 实施步骤

1. **冻结对照条件。** 从只读 stage2 v008 派生隔离工件；固定起始 q、取料位姿、station/agv 目标、seed 集合、预算和仿真步长。先复现基线，各运行一次 station/agv，运行 both 一次确认任务链。
2. **补齐逐段测量。** 每个计划段保存名称、载荷状态、姿态约束类型、q 起止值与路径序列、TCP FK 误差、腕部分支标签/最小奇异边界距离、碰撞采样/最小距离、规划耗时、执行耗时。计算各关节总变差 `TV_i=Σ|q_i[k+1]-q_i[k]|`、最大相邻增量、总行程和路径点数。使用执行器实际下发/实测 q 统计，不只看 IK 端点。
3. **标定腕部分支拒绝规则。** 对当前 UR5 模型的有效关节区间采集 simIK 候选，结合 FK/关节轴方向标注分支与奇异边界；用接近边界的两侧样本测试分类。边界与安全裕量未验证前不启用自动锁轴优化；最终任何生成路径不得跨支，不能只按 q6 正负分类。
4. **拆分并验证转运末段。** 在 `transit` 与 `pre-place` 之间增加逻辑 waypoint `high_above_place=[place.x, place.y, z_transit, place.orientation]`，其中 `z_transit` 与 transit 相同（当前为 0.80 m）。先验证 `transit → high_above_place` 的水平段，再验证 `high_above_place → pre-place` 的竖直段；两段均以上一构型为 seed，保持同一腕部分支。水平段比较自由解与固定 q[0]，竖直段优先测试固定 q[0]。复核末端姿态、TCP 直线误差、负载 attach 变换、全段碰撞及净空。
5. **验证 `pre-place → place` 固定 q[0]。** 先 station，再 AGV。对目标直线按当前 `CARTESIAN_IK_STEP` 分段，每点令 q[0] 等于段起始值、以其余关节求解；所有点以上一点为 seed。复核末端完整姿态、TCP 直线误差、负载 attach 变换、全段碰撞及最终接触。然后独立验证 `place → retreat`。分别记录可行性，不因同一 XY 而假定通过。
6. **验证 `pick → lift → rise` 固定 q[0]。** 以真实 conveyor 取料位进行同样的分段求解；包含 pick 接触点、抬升起点允许承载接触和脱离后的负载扫掠检查。成功后仍需核对其后转运的起始构型和连续性。
7. **优化 `rise → transit` 与两段末端转运。** 先按同一腕部分支求可行路径，按全关节总行程、峰值关节变化和最小净空排序；再分别做水平段/竖直段固定 q[0] 实验。如 q[0] 固定无解或碰撞，允许 q[0] 参与，但加入连续性代价来压低无收益旋转。不得删去已证明必要的高位中转。
8. **收敛轨迹点和代价。** 只有在关节路径与 TCP 路径误差均不增加、碰撞采样覆盖不降低时才移除数值冗余点；接触、rise、transit、high-above-place、pre-place、place、retreat 等语义点保留。一次只改变一个代价/限制，保留失败案例与策略名称。
9. **回归与决策。** 用候选配置重跑 station/agv/both 及一次阶段二运行期障碍停止检查。按第 5 节准则决定固定 q[0] 的适用段和目标；不具备可重复收益的限制不进入默认策略。

## 5. 验收标准

- station 和 agv 正常搬运仍完成；both 连续任务无串任务；所有动作段保持同一腕部分支，不发生腕部分支翻转。
- 每个活动段有输入目标、候选/最终关节路径摘要、逐段安全检查结果和执行统计；失败原因可区分 IK 无解、限位、碰撞、姿态误差与预算耗尽。
- 抓取/抬升/放置/撤离的 TCP 误差不超过现行 `EXEC_TCP_POS_TOL`、`EXEC_TCP_ANG_TOL` 对应姿态策略；原接触判据及 release 稳定性不回退。
- 轨迹全程维持既有碰撞、载荷接触和运行期停止联锁；对规划路径及实际下发步进段都保留检查。
- 与基线相比，至少一个目标动作段的腕部无效行程指标有可重复下降；固定 q[0] 的目标段其 q[0] 变化应在执行容差内；任务总关节行程或仿真执行时间不得显著恶化。若候选方案没有稳定收益，保留同腕部分支安全基线并记录结论，不合并优化。
- 同分支内不可达或安全检查失败时明确失败；不自动切换腕部分支，也不放宽姿态、碰撞或接触条件。

不设置脱离测量依据的固定“翻腕次数”门槛。第 1–2 步先给出基线分布与测量噪声，再冻结具有意义的相对改善阈值；A/B 对照使用相同起始 q、目标 pose、seed 集合、预算和场景快照。

### 各段锁轴判定

| 候选规则 | 初始判断 | 采纳条件 |
|---|---|---|
| pre-place → place 固定 q[0] | 优先候选，几何上有依据 | station 与 AGV 各自的整段笛卡尔下降通过；若只对一个目标通过，就按目标配置，不泛化 |
| place → retreat 固定 q[0] | 候选 | 空载撤离独立通过吸盘/物料、台面净空和碰撞复核 |
| pick → lift → rise 固定 q[0] | 候选 | 传送带上方带载扫掠及 lift 起点承载接触规则均通过 |
| rise → transit 固定 q[0] | 探索项 | 同腕部分支下完整路径安全，且行程或耗时有实测收益 |
| transit → high-above-place 固定 q[0] | 候选 | 只在水平段的完整 FK、载荷扫掠、净空和执行检查均通过时采纳 |
| transit → high-above-place 只动 q[0] | **不作为预设方案** | 水平位移通常需要多关节协调；只有新实测证明 TCP 水平轨迹、姿态和碰撞均满足时才可考虑 |
| high-above-place → pre-place 固定 q[0] | 优先候选 | station 与 AGV 的竖直下降分别通过；其余关节仍由连续 IK 求解 |
| high-above-place → pre-place 只动 q[0] | **不合适** | joint1 单轴不能完成保持工具姿态的垂直下降 |
| place 阶段只动 q[0] | **不合适** | joint1 单轴也无法完成保持工具姿态的垂直下降；优先测试固定 q[0]、其余关节由连续 IK 求解 |

这里的 `q[0]` 是本项目六关节数组的 joint1/base axis，`q[1]` 是 joint2/shoulder axis。表中的“固定/锁定 q[0]”指 q[0] 保持常值、其余关节仍可运动；“只动 q[0]”则是 q[1:6] 全部保持不变，两者不可混为一谈，也不能与报告文字中的 q1/q2 轴号混用。
