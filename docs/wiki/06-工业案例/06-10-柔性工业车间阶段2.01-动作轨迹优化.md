> rise/transit 路径点、`TRANSFER_PATH_POLICY`/偏移/绕行等 2.02 实验开关与

## 1. 问题与证据

本文分开记录阶段 2.01 的基础动作优化和阶段 2.02 的 AGV 转运专项。阶段编号表示实施工作包；
`MOTION_OPT_VERSION` / `AGV_TRANSFER_OPT_VERSION` 是配置功能标识，
`stage2_contract_...` 是工件序列化契约版本，`v012` / `v013` 是场景工件修订，彼此独立。
阶段 2.01 已完成基础验收；阶段 2.02 的实验能力已实现，但候选策略默认关闭，未达采纳条件的事项仍待解决。

阶段二已实现多解 simIK、连续 seed、关节流式执行、笛卡尔法向接近和逐段碰撞复核。实现对候选解使用关节距离排序，并对 q6 施加较小偏好；阶段二报告同时记录工具竖直时模型关节坐标 q5 接近 ±90°，q4/q6 耦合，近似直线上升可能出现绕工具 Z 轴的旋转。[阶段二规划器](../../../src/stage2/path_planning.py) [阶段二报告](../../implementation/PHASE2_REPORT.md)

本文 q1…q6 按 UR5 轴号从底座向末端编号；因此 q5 是第五轴 Wrist 2，在 Python 六元素数组中对应 `q[4]`。不同模型的零位/坐标约定可能不同，阶段二报告中的 ±90° 是当前模型实测值，不应直接当成通用 UR5 奇异角度。

当前问题不是任务失败：station、agv 和 both 的阶段二正常验收均通过。问题在于动作是否包含不影响抓放结果的关节行程，且既有报告未统计各动作段的关节总变差、最大单步变化和腕部翻转次数。当前运行报告主要保存最终计划，未完整提供 transfer 每个子段的最终关节统计，因此具体能否锁定某轴仍需按本方案实测。本阶段先建立可比较指标，再优化选解和段落目标；不以动画观感或单次成功作为效果证明。

现有阶段二的 `transit` 是高位且带基座方向偏移的中转位姿，`pre_place` 是目标放置位姿上方 `PRE_APPROACH_CLEARANCE` 的预接近位姿；因此当前 `transit → pre_place` 同时包含 XY 和 Z 的变化。2.01 将其拆成两个逻辑段：先在保持 `z_transit` 的高度上水平移动到目标正上方，再沿 Z 轴下降到 `pre_place`。这里的“目标正上方”采用新的逻辑 waypoint `high-above-place` 表示，不能把它与较低的 `pre-place` 名称混用。

> **实施结果（2026-10-21）**：拆分能力已实现并由 `TRANSFER_SPLIT_HIGH_ABOVE_PLACE` 控制，但 A/B 实测把 station 计划 TV 从 12.395 提高到 16.013 rad、AGV 从 11.968 提高到 13.354 rad，因此**默认关闭**。结论见 [PHASE2_01_REPORT §3.3](../../implementation/PHASE2_01_REPORT.md)。

`rise` 与 `pre-place` 高度并非理论上不能相等；准确的判断是，当前配置下它们承担不同的安全职责。`rise` 在取料点上方建立跨区域转运净空，宜与 `transit`/`high-above-place` 采用同一高位；`pre-place` 则是目标上方 0.15 m 的最终下降起点。当前取料 TCP 约为 z=0.55 m，lift 约为 z=0.70 m，`rise` 约为 z=0.82 m；station 的 `pre-place` 约为 z=0.55 m，AGV 约为 z=0.507 m。若把 rise 直接降到这些 pre-place 高度，带载物料在传送带上方几乎没有净空（AGV 目标甚至低于传送带面），不能作为当前布局的安全转运高度。只有重新定义高位/预接近语义，或完成整段碰撞与载荷净空验证后，才可合并高度。

## 2. 目标与边界

目标是在完成相同 TCP 任务和安全约束的候选路径中，选择关节变化较小、连续且没有突发腕部回绕的路径；运行轨迹不得切换腕部分支或穿越经当前模型标定的腕部奇异边界。合并确属冗余且语义、约束一致的路径点。

保持以下阶段二保证：完整路径仍经过限位、碰撞/距离、接触、载荷和 FK 检查；取放与放置的姿态要求不被降级；输出轨迹实际下发的每个新构型及其段仍被复核；规划失败时停止并报告失败原因。

本阶段不调整场景几何、UR5/TCP 模型、物理参数、布局、目标放置位姿和控制模式；不引入通用全局规划器、动力学伺服或故障恢复（后者归项目最终阶段，见 06-05 §6）。按动作段评估关节保持不变的可行性；只有目标几何允许且全段安全、执行复核通过后才采纳段内锁轴。锁轴属于轨迹/IK 约束，不是关闭场景关节或跳过碰撞检查。

## 3. 优化策略

### 3.1 先量测，再对照

为每条规划路径按动作段记录六关节起止值、展开后的关节总变差 `sum(abs(delta_q))`、最大单步变化、路径点数、执行时间、IK 回退/失败、最小碰撞距离、TCP 误差、工具轴误差及路径检查结果。对有有限位的关节，统计和插值必须按真实限位内连续角处理，不允许 wrap 产生跨限位短路。

通过基线 stage2 工件对 station 和 agv 各执行一次可复现任务；保存起始构型、输入目标、候选路径摘要和运行证据。只在隔离派生工件中试验，避免更改已保护的 v008 和阶段一父工件。

### 3.2 冗余自由度按动作段处理

| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------- |

腕部分支连续性是硬约束：每段候选必须与当前已验证构型属于同一腕部分支；规划不得跨过当前 UR5 模型实测标定的腕部奇异边界来切换分支。若同分支内没有满足姿态、限位和碰撞条件的解，应返回规划失败，不回退到另一腕部分支，也不放宽安全约束。分支判别需以本模型的 IK 候选和关节轴/奇异边界测量为依据，不仅凭 q6 正负或某个关节单独阈值判断。

关节限制属于规划级约束，不修改模型自由度或关闭关节驱动。每次只改变一个因素：同腕部分支下增强连续性代价、工艺允许的有限工具 yaw 候选、段内固定单轴。固定轴无解时记录该目标不可用并退回同分支自由 IK；不得以切换腕部分支作为 fallback。

当前模型实测 q5 接近 ±90° 时 q4/q6 耦合。保持 q5 数值或最小化 q6 单变量都不能单独证明没有翻腕，也可能将转动转移到另一腕轴。因此方案须跟踪 IK 腕部分支并保持 q1…q6 的连续解；通过实测标定奇异边界及安全裕量，在边界前拒绝会跨支的候选。不得根据 q6 符号直接判定分支，也不得把 q6 小权重当作禁止翻腕的实现。

### 3.3 轨迹点精简

先区分语义 waypoint（接触、抬升、高位转运、预放置、放置、撤离）与数值离散点。语义 waypoint 不因关节代价而删除。仅当相邻段具有相同载荷、接触和姿态策略，且合并后实际生成的 TCP 路径仍满足原几何意图、碰撞采样和执行预算时，才可精简重复/共线点。对轨迹平滑或时间参数化后的实际输出重新执行路径复核；不因点数减少而降低原有检查分辨率保证。

## 4. 实施步骤

1. **冻结对照条件。** 从只读 stage2 v008 派生隔离工件；固定起始 q、取料位姿、station/agv 目标、seed 集合、预算和仿真步长。先复现基线，各运行一次 station/agv，运行 both 一次确认任务链。
2. **补齐逐段测量。** 每个计划段保存名称、载荷状态、姿态约束类型、q 起止值与路径序列、TCP FK 误差、腕部分支标签/最小奇异边界距离、碰撞采样/最小距离、规划耗时、执行耗时。计算各关节总变差 `TV_i=Σ|q_i[k+1]-q_i[k]|`、最大相邻增量、总行程和路径点数。使用执行器实际下发/实测 q 统计，不只看 IK 端点。
3. **标定腕部分支拒绝规则。** 对当前 UR5 模型的有效关节区间采集 simIK 候选，结合 FK/关节轴方向标注分支与奇异边界；用接近边界的两侧样本测试分类。边界与安全裕量未验证前不启用自动锁轴优化；最终任何生成路径不得跨支，不能只按 q6 正负分类。
4. **拆分并验证转运末段。** 在 `transit` 与 `pre-place` 之间增加逻辑 waypoint `high_above_place=[place.x, place.y, z_transit, place.orientation]`，其中 `z_transit` 与 transit 相同（当前为 0.80 m）。先验证 `transit → high_above_place` 的水平段，再验证 `high_above_place → pre-place` 的竖直段；两段均以上一构型为 seed，保持同一腕部分支。水平段比较自由解与固定 q[0]，竖直段优先测试固定 q[0]。复核末端姿态、TCP 直线误差、负载 attach 变换、全段碰撞及净空。
5. **验证 `pre-place → place` 固定 q[0]。** 先 station，再 AGV。对目标直线按当前 `CARTESIAN_IK_STEP` 分段，每点令 q[0] 等于段起始值、以其余关节求解；所有点以上一点为 seed。复核末端完整姿态、TCP 直线误差、负载 attach 变换、全段碰撞及最终接触。然后独立验证 `place → retreat`。分别记录可行性，不因同一 XY 而假定通过。
6. **验证 `pick → lift → rise` 固定 q[0]。** 以真实 conveyor 取料位进行同样的分段求解；包含 pick 接触点、抬升起点允许承载接触和脱离后的负载扫掠检查。成功后仍需核对其后转运的起始构型和连续性。
7. **优化 `rise → transit` 与两段末端转运。** 先按同一腕部分支求可行路径，按全关节总行程、峰值关节变化和最小净空排序；再分别做水平段/竖直段固定 q[0] 实验。如 q[0] 固定无解或碰撞，允许 q[0] 参与，但加入连续性代价来压低无收益旋转。不得删去已证明必要的高位中转。
8. **收敛轨迹点和代价。** 只有在关节路径与 TCP 路径误差均不增加、碰撞采样覆盖不降低时才移除数值冗余点；接触、rise、transit、high-above-place、pre-place、place、retreat 等语义点保留。一次只改变一个代价/限制，保留失败案例与策略名称。
9. **回归与决策。** 用候选配置重跑 station/agv/both 及一次阶段二运行期障碍停止检查。按第 5 节准则决定固定 q[0] 的适用段和目标；不具备可重复收益的限制不进入默认策略。

## 5. 验收标准

- station 和 agv 正常搬运仍完成；both 连续任务无串任务；所有动作段保持同一腕部分支，不发生腕部分支翻转。
- 每个活动段有输入目标、候选/最终关节路径摘要、逐段安全检查结果和执行统计；失败原因可区分 IK 无解、限位、碰撞、姿态误差与预算耗尽。
- 抓取/抬升/放置/撤离的 TCP 误差不超过现行 `EXEC_TCP_POS_TOL`、`EXEC_TCP_ANG_TOL` 对应姿态策略；原接触判据及 release 稳定性不回退。
- 轨迹全程维持既有碰撞、载荷接触和运行期停止联锁；对规划路径及实际下发步进段都保留检查。
- 与基线相比，至少一个目标动作段的腕部无效行程指标有可重复下降；固定 q[0] 的目标段其 q[0] 变化应在执行容差内；任务总关节行程或仿真执行时间不得显著恶化。若候选方案没有稳定收益，保留同腕部分支安全基线并记录结论，不合并优化。
- 同分支内不可达或安全检查失败时明确失败；不自动切换腕部分支，也不放宽姿态、碰撞或接触条件。

不设置脱离测量依据的固定“翻腕次数”门槛。第 1–2 步先给出基线分布与测量噪声，再冻结具有意义的相对改善阈值；A/B 对照使用相同起始 q、目标 pose、seed 集合、预算和场景快照。

### 各段锁轴判定

| 候选规则 | 初始判断 | 采纳条件 |
|---|---|---|
| pre-place → place 固定 q[0] | 优先候选，几何上有依据 | station 与 AGV 各自的整段笛卡尔下降通过；若只对一个目标通过，就按目标配置，不泛化 |
| place → retreat 固定 q[0] | 候选 | 空载撤离独立通过吸盘/物料、台面净空和碰撞复核 |
| pick → lift → rise 固定 q[0] | 候选 | 传送带上方带载扫掠及 lift 起点承载接触规则均通过 |
| rise → transit 固定 q[0] | 探索项 | 同腕部分支下完整路径安全，且行程或耗时有实测收益 |
| transit → high-above-place 固定 q[0] | 候选 | 只在水平段的完整 FK、载荷扫掠、净空和执行检查均通过时采纳 |
| transit → high-above-place 只动 q[0] | **不作为预设方案** | 水平位移通常需要多关节协调；只有新实测证明 TCP 水平轨迹、姿态和碰撞均满足时才可考虑 |
| high-above-place → pre-place 固定 q[0] | 优先候选 | station 与 AGV 的竖直下降分别通过；其余关节仍由连续 IK 求解 |
| high-above-place → pre-place 只动 q[0] | **不合适** | joint1 单轴不能完成保持工具姿态的垂直下降 |
| place 阶段只动 q[0] | **不合适** | joint1 单轴也无法完成保持工具姿态的垂直下降；优先测试固定 q[0]、其余关节由连续 IK 求解 |

这里的 `q[0]` 是本项目六关节数组的 joint1/base axis，`q[1]` 是 joint2/shoulder axis。表中的“固定/锁定 q[0]”指 q[0] 保持常值、其余关节仍可运动；“只动 q[0]”则是 q[1:6] 全部保持不变，两者不可混为一谈，也不能与报告文字中的 q1/q2 轴号混用。

**实施后的默认锁轴集合（2026-10-21）**：`lift`、`rise`、`place`、`retreat`。
`pre_place`（未拆分时的 transit→pre_place 对角段）实测不可锁：station 会迫使腕部
跨支，AGV 会让载荷扫过 conveyor pad；因此该段保留自由 IK，但仍受腕部分支和
逐段碰撞检查约束。锁轴通过临时收窄 simIK 关节区间实现，不是关闭场景关节。

### 8.1 现象判读与优化目标

阶段 2.01 的 AGV 真实执行记录 `phase2_01_run_agv_none_20261021_210713.json` 显示：`rise → transit` 的 `q[0]` 净变化约 −1.511 rad（−86.6°）；合并的 `transit → pre_place` 段 `q[3]` 净变化约 +5.019 rad（+287.6°），执行耗时约 11.15 s。这里的 q 是 Python 0-based 数组，`q[0]` 为 joint1/base，`q[3]` 为 joint4/Wrist 1，`q[4]` 才是 joint5/Wrist 2。q[3] 的大转动不是已测得的腕部分支翻转：该运行 q[4] 分支保持 positive。

执行器实际逐步下发的最大相邻关节变化约 0.0448 rad，说明轨迹被细分执行；这不能证明速度、加速度或 jerk 已平顺，也不能抵消 q[3] 总行程约 5 rad 与该段较长耗时。应把问题分别记录为“端点间关节路径过长”和“动态平顺性待测”，不要把角度大直接等同于运行不稳定。

当前具体规划缺口是：`transit`、`pre_place` 为严格姿态端点，但二者间由端点 IK 与关节路径连接，没有指定 TCP 必须按水平、再垂直的工艺路径通过；候选评分也没有对整段 `q[0]`/`q[3]` 行程作全局比较。阶段 2.01 的 `high_above_place` 拆分 A/B 已使 AGV 计划 TV 增加 11.6%，故不能简单把拆分开关打开，也不把增加中间点本身当成解决方法。

### 8.2 目标路径与约束

AGV 专项比较以下 TCP 路径，均从同一个实际 `rise` 构型和载荷状态开始，保持目标抓放姿态、当前腕部分支和现有安全契约：

1. **基线**：当前 `rise → transit → pre_place → place`。保留逐点 q、TCP、载荷位姿和检查结果作为对照。
2. **高位平移后垂直接近**：先从 rise 沿经验证的安全高度到达 AGV 目标 XY 正上方，再保持 XY 垂直降至 pre-place，最后沿原垂线放置。比较是否可省略朝基座方向 0.20 m 的 transit 偏移；只有在整段载荷净空通过时才省略或缩短偏移。
3. **连续避障路径**：若直接水平/垂直路径被碰撞或净空拒绝，只加入能解释该碰撞的最少中间点，优先维持高位，在水平偏移上绕开具体障碍后再对位；每个点均记录引入原因和绕行距离。不得为降低关节 TV 删除碰撞检查或降低载荷净空。

`rise`/transit 高度由跨 conveyor、station 与 AGV 的带载净空决定，不能为了压低关节行程直接降到 AGV pre-place 高度。水平段测试固定 q[0] 仅作为候选；若不可行则允许其协调运动。垂直段测试固定 q[0]，但 AGV 现有 pre-place 下降段的负载和姿态约束仍须独立重验。q[3] 不先做硬锁或限幅，避免把转动转移到其他关节；先用候选路径代价抑制无收益绕转。

### 8.3 选解与轨迹生成改造

1. **建立可诊断基线。** 固定 stage2 v012 工件、AGV 目标、起始 q、实际 attach 变换和规划预算；复跑并导出 transfer 每个离散 waypoint 的六轴 q、FK TCP、载荷位姿、碰撞净空与执行采样。重点确认 `q[3]` 的 +5.019 rad 是端点间单调转动还是中途来回，并确认所有 simIK 候选中是否存在同分支、低 q[3] 行程的安全端点组合。
2. **先改路径目标，不先调速度。** 对比第 8.2 节三类 TCP 路径。沿直线以现有 `CARTESIAN_IK_STEP` 采样，完整约束姿态；水平和垂直分段的 A/B 结果用端到端关节代价评估，不能只按 TCP 长度判胜。
3. **将贪心逐点选解改为有界整段候选选择。** 在每个笛卡尔采样位姿保留有限个同腕部分支 IK 解；相邻层只连接通过限位、FK、带载碰撞及净空检查的候选。用有界 beam/dynamic-programming 在整段上选链，而不是每一点取第一个安全解。沿用现有候选数、预算和检查器，不引入新规划器依赖；候选不足或预算耗尽要明确报告，不能静默退化为未经比较的路径。
4. **采用分层代价。** 安全与完整 TCP 任务是硬约束；可行候选之间先比较六轴加权总变差 `Σ_i w_i TV_i`，单独报告 `TV(q[0])`、`TV(q[3])`、最大相邻变化和总路径时间。其次惩罚相邻步方向反复、二阶差分（关节加速度代理）和无任务收益的 q[0]/q[3] 长行程。权重按现有 AGV 基线量纲归一化并通过 A/B 冻结；不得只压 q[3] 而造成 q[0]、q[5] 或最小碰撞距离恶化。不要对有限位 joint4 使用 wrap 短路。
5. **平滑与时间参数化放在选链之后。** 对已选连续 q 路径采用现有轨迹生成能力限制速度、加速度和 jerk；计算实际下发/观测 q 的速度、加速度、jerk 峰值及跟踪误差。平滑可能改变 TCP 与碰撞路径，输出轨迹必须重新做全段 FK、腕部分支、载荷扫掠和碰撞复核；不以增加插值点替代平滑。

### 8.4 实施顺序与决策门

| 顺序 | 修改/实验 | 通过后进入下一步的条件 |

验收不预设 q[0]/q[3] 必须达到某个任意角度阈值。先用重复基线估计运行差异，再要求各次结果都保持同分支、通过相同安全检查，并使 `TV(q[0])`、`TV(q[3])` 至少一项有超过基线波动的稳定改善，另一项、总 TV、执行时间和最小净空无显著退化。报告须同时给计划 TV 与实测执行 TV，避免只凭动画或 IK 端点下结论。

本节能力已实现为阶段 2.02 的**实验开关**；默认仍是 `TRANSFER_PATH_POLICY="baseline"`、`CARTESIAN_CHAIN_SEARCH="greedy"`、`TRAJECTORY_SMOOTHING_ENABLED=False`，因此阶段 2.01 的生产路径与默认结论不变。2026-10-25 的规划 A/B 显示 0.10/0.00 m 偏移可大幅降低 AGV transfer TV，但 `rise → transit` 的 q[0] TV 未下降，按 §8.4 B 的判定规则不切换默认值；实机重复运行与完整回归（§8.4 G）仍是采纳前的必要条件。测量与代码边界见 §8.7。

### 8.5 可直接执行的实验卡与记录格式

以下按阶段推进；阶段未过门槛时停止该分支实验，不叠加下一项变量。所有影子探针都从冻结工件和只读场景开始，不驱动真实臂。执行候选前必须确认计划起始 q 与当前实测 q 满足现有计划起点容差；否则重置到同一已验证起始状态后再比较。

**实验卡 A：复现并拆解转动来源**

1. 固定 `stage2/L1_S1/v013_20261024_232558`（2.02 工件；2.01 对照为
   `v012_20261021_210539`）、AGV 目标、传送带停止后的 pick pose、计划/实测
   起始 q、吸附相对变换、IK seed、仿真步长和规划预算。先运行已有 AGV 基线
   一次用于路径细节，再按同一输入重复规划两次验证选解是否确定。
2. 每个目标段输出所有尝试策略及失败原因；对每个 waypoint 记录 `q[0:6]`、TCP XYZ/四元数、负载中心/包围盒、腕部分支/裕量、相邻段检查净空、IK seed 和候选序号。不得只输出段首/段尾。
3. 对 `transit → pre_place` 的 `q[3]` 序列计算净变化 `Δq3`、总变差 `TV3=Σ|Δq3|`、正负方向变化次数、峰到峰值及有限关节限位余量。判别：净变化接近总变差表示主要是单向大转；总变差显著大于净变化表示存在来回摆动。对所有安全端点候选按同一指标排序，保存被碰撞/限位/腕部分支拒绝的原因。
4. 对 `rise → transit` 输出 `q[0]` 的起止值、TV、转角方向和 transit TCP 的实际 XY 偏置向量；将当前 `−1.511 rad` 归因到“目标方位需求”或“transit 偏移/IK 分支选择”，必须通过端点候选和路径检查证据区分，不凭动画猜测。

**实验卡 B：压低 q[0] 长转动**

1. 保持 `rise` 与高位 z、工具姿态、其他评分项和安全检查不变，只改变 transit 沿“目标指向基座”方向的偏移距离：0.20 m（现状）、0.10 m、0 m。每个配置求出 transit 候选后，继续规划到 AGV 上方、pre-place、place；不得只比较 transit 端点。
2. 每个偏移值保留至少 3 个安全候选端点（若可获得），通过后续完整转运链排序。记录 `TV(q[0])`、全关节 TV、最小载荷净空、最小连杆净空、路径成功率和执行时间。
3. 选择规则：先剔除路径失败或净空低于现行安全要求的配置；再在可行者中选偏移最短且完整路径 `TV(q[0])` 确实下降者。若零偏移使肩/肘或 Wrist 1 行程明显上升，或避障失败，则选 0.10 m 或保留 0.20 m，不强求 q[0] 角度最小。

**实验卡 C：控制物品的水平/垂直路径**

1. 固定选定的安全 transit 高度与偏移，分别规划三种末段：当前端点关节连接；高位同姿态水平到 `[agv.x, agv.y, z_high]` 后垂直到 pre-place；若直线路径碰撞，在报告了具体碰撞物对后，仅加一个最短绕行 waypoint。所有候选保持完整工具姿态，不允许把物料/工具只约束成位置点。
2. 逐段测量 TCP 水平长度、垂直长度、绕行额外长度、实际 TCP 对指定线段的最大横向误差；同时计算每关节 TV、总 TV、TCP 路径长度和载荷扫掠最小距离。直线任务的 waypoint 高度取当前已验证的高位，不把 AGV 的低位 pre-place 高度用作跨工作区高度。
3. 高位拆分 A/B 曾使 AGV 计划 TV 增加 11.6%；因此只有全段评分选出了不同且改善的 IK 链，或安全证据表明拆分减少绕行后，才保留新路径。若 TCP 路径更直但关节 TV 更高且无安全收益，记录结果并拒绝默认采用。

**实验卡 D/E：整段候选选择与 q[3] 优化**

1. 对高位末段的每个 TCP 插值样点调用现有多解 simIK，seed 由上一候选层的有限候选和当前生产 seed 组成；所有候选先执行限位、同腕部分支、FK 误差筛选。相邻层候选边只有在整段 `check_segment` 对载荷、连杆和碰撞通过时才加入图。
2. 在候选图上使用有上限的动态规划/beam 搜索，保留当前实现的计算预算。初始 beam 宽度建议 8，候选每层上限沿用 6；若预算不足则报告覆盖不足，不降低安全检查，也不静默换用未经打分的 greedy 路径。输出最终链及被剪枝原因摘要。
3. 评分分两层：第一层为硬约束，要求 TCP 误差、完整姿态、关节限位、同腕部分支、碰撞/载荷净空全部通过；第二层对可行链计算归一化总代价：`J = 1.0·TV_all + 0.5·TV(q[0]) + 0.5·TV(q[3]) + 0.2·B_all + 0.2·A_all`。其中 `B_all=Σ|q[k+1]-2q[k]+q[k-1]|` 为关节折返/曲率代理，`A_all` 为按采样时间归一化的二阶差分平方和。系数是首轮实验初值，不直接作为最终常数；先做消融（只 TV、TV+q0/q3、再加平滑项），检查是否存在关节代偿，再以 A/B 结果冻结。有限位关节 q[3] 差值不 wrap。
4. 额外输出独立 Pareto 表：`TV(q[0])`、`TV(q[3])`、其余四轴 TV、`TV_all`、`B_all`、`A_all`、最小净空、TCP 误差和预计时间。若候选在 q[0]/q[3] 上变好但其余关节代价、净空或任务时间退化超出基线波动，不采纳。

**实验卡 F：稳定运动验证**

选链后才处理时间参数化。按执行采样时间对实测 q 计算每轴速度、加速度、jerk 峰值与 RMS，并对照当前控制器速度/加速度/jerk 限制；同步记录指令—实测关节误差峰值、TCP 跟踪误差、段耗时和停止联锁响应。时间参数化或平滑一旦改变 q 路径，必须将实际输出路径送回同一个 FK、分支、载荷碰撞检查器。若目前轨迹步进的最大相邻角小，但加速度/jerk 或跟踪误差没有证据，则只报告“未证实稳定”，不靠增加 waypoint 宣称平滑。

### 8.6 结果表与停止条件

每个候选配置提交一行可比记录：`artifact/config digest`、固定起始 q、AGV load pose/attach、transit 偏移、高度、末段路径类型、seed/候选预算、成功/失败状态、六轴 `TV_i`、`Δq_i`、方向反转次数、TCP 直线误差、TCP 路径长度、带载/连杆最小净空、腕部分支裕量、速度/加速度/jerk 峰值与 RMS、跟踪误差、仿真耗时、墙钟规划耗时。规划 TV 与执行 TV 分列。

达到任一情形即停止该候选：同腕部分支无解；目标完整姿态不满足；任何中间构型碰撞/净空失败；实际路径偏离指定水平/垂直线超出现行 FK/执行容差；候选搜索预算耗尽且没有已验证整段链；或改善只来自把行程转移到其他轴。保留失败原因和基线，不放宽约束去“做出”成功结果。
