# 柔性车间资料导航

本目录包含柔性车间案例、混线生产业务说明、阶段规划与待评估优化项。本文提供
业务资料导航；当前实现与验收状态以 [实施资料索引](../../../implementation/README.md)
及其中的产品/阶段报告为准。

## 为什么归入“工业案例”

“柔性车间”描述的是一个业务域和仿真场景：产品路线、工序、设备能力、物料
流转、车间资源和阶段目标都属于案例语义。它们需要能脱离某一轮代码实现继续
复用，因此放在 `wiki/06-工业案例/`，作为业务规划和领域参考的入口。

`implementation/` 的职责不同：它只记录 v1 本轮的代码落点、工作包、测试门槛、
实施报告和正式证据。两处通过阶段号、`related` 和
[项目文档登记表](../../../implementation/governance/project-document-register.md) 对应，
不把同一篇规划复制两份。
