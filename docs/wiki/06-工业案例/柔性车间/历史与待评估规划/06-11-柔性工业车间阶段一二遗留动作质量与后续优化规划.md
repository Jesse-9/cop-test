> **归档说明：**遗留质量问题和候选优化清单；执行前需按当前代码、场景工件和运动基线重新复核，不属于当前混线生产阶段计划。当前计划见 [[wiki/06-工业案例/柔性车间/当前规划/06-18-柔性车间混线生产工序与设备调度演进规划]]。

## 1. 范围与状态定义

本文关注关节运动是否必要、连续、稳定，TCP 路径是否符合工艺意图，以及载荷运输时是否稳定。阶段一的单次异常、阶段二的边界条件和后续阶段功能扩展分开记录，避免把“任务 DONE”误当成动作质量验收。

状态含义：

- **已证实未解决**：已有运行数据证明超出目标或表现不佳，尚无经重复运行验证的修复。
- **候选待验证**：已有诊断/策略或影子规划结果，但没有满足实机重复和回归门槛。
- **风险监视**：曾出现且被安全联锁正确拦截，复测通过但样本不足以关闭。
- **已关闭**：同一冻结输入下有可重复的真实执行证据，路径、安全和任务回归均达标。

阶段 2.01 的基础验收、阶段 2.02 实验能力实现，与本文问题关闭是不同状态。OMPL 未纳入阶段二且属于可选全局规划增强；它不是以下已测动作质量问题的默认修复手段。

## 3. 建议后续工作包：动作质量收敛（候选阶段 2.03）

此工作包承接阶段 2.01/2.02 的现有指标与实验钩子，**不预先认定需要新增算法或改变默认路径**。动作质量收敛可与阶段三的软件结构和布局筛选并行；但阶段三 AGV 带载路线验收必须遵守本规划的实测 jerk、载荷稳定及 q[0]/q[3] 记录门槛。执行顺序如下：

1. **冻结并复现基线**：固定 stage2 工件、AGV 停止后的 pick pose、载荷、目标、seed、仿真步长、规划预算和配置；记录软件/工件契约版本。基线 station、AGV、both 各运行一次用于确认入口和数据完整。
2. **补齐分段运动剖面**：对每个 waypoint 和实际执行采样点记录六关节 `q[0:6]`、TCP 位姿、载荷位姿、各轴净变化、`TV(q_i)`、方向反转、速度/加速度/jerk 峰值及 RMS、跟踪误差、碰撞最小净空、腕部分支与限位裕量。区分计划值与实测值。
3. **定位关节行程来源**：优先拆解 `rise → transit` 和 `transit → pre_place`，比较基线、0.10 m/0.00 m 偏移和现有路径变体；保存所有安全/不安全 IK 候选及被拒原因。不得用缩短总 TV 掩盖其他轴行程上升。
4. **针对 jerk 做单变量修正**：先确定峰值来自离散目标跳变、时间参数化、执行器目标保持/切换还是测量采样噪声；再选用已有平滑钩子或最小时间参数化改动。一次只改一个变量，平滑后的离散路径仍要经过完整路径与实际执行复核。
5. **联合筛选路径**：候选排序同时纳入关节总变差/峰值速度加速度 jerk、关节限位余量、路径净空、TCP 误差、任务时间和载荷稳定；碰撞、同腕部分支、工具姿态、工艺路径和物料安全是硬约束，不可由权重抵消。q[0]/q[3] 同时改善优先；若存在不可避免取舍，报告 Pareto 方案及原因。
6. **实机重复与回归**：固定同一起始状态，胜出候选和 baseline 分别实机重复 3 次；随后 station、both 和运行期障碍锁存各回归一次。若 pick pose、载荷或场景几何变化，原 A/B 结论不直接外推，按影响范围复测。
7. **决策与归档**：只有所有门槛通过才将候选写为默认配置；否则保留基线，记录失败原因、证据和下一项可判定实验。候选实现能力存在、单次运行成功或动画看起来更顺，都不构成关闭证据。

## 4. 验收门槛

- 所有测试输入、起始构型、目标、工件及配置可复现；同一输入重复规划结果确定，或可解释并界定随机差异。
- q[0]/q[3] 问题按逐段净变化与 TV 分析；没有把行程转移到其他轴后仍宣称优化。
- 实测关节速度、加速度和 jerk 不超过冻结限值；实际跟踪误差在现有控制容差内。
- 整条 TCP 路径、工具姿态、腕部分支、载荷扫掠、碰撞净空和最终放置结果均通过现有阶段二联锁/复核。
- 载台与载荷稳定性覆盖声明的运行条件；风险工况被正确拒绝或停止，不允许靠放宽安全判据换取通过。
- 候选相对 baseline 的改善超过基线重复波动，且任务时间无不可接受退化。未达成任一条件，保持原默认策略并继续列为开放问题。
