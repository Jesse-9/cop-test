# 快捷键速查

> 当焦点位于场景层级（Scene hierarchy）或某个页面（page）时，CoppeliaSim 支持以下快捷键。摘自官方手册 `shortcuts.htm`。

## 文件与场景

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+O` | 打开场景 |
| `Ctrl+N` | 新建场景 |
| `Ctrl+S` | 保存场景 |
| `Ctrl+W` | 关闭场景 |
| `Ctrl+Q` | 退出应用 |

## 选择与编辑

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+A` | 全选 |
| `Esc` | 清除选择 |
| `Ctrl+C` | 复制选择 |
| `Ctrl+V` | 粘贴复制缓冲 |
| `Ctrl+X` | 剪切选择 |
| `Delete` | 删除选择 |
| `Backspace` | 删除选择 |

## 仿真与视图

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Space` | 启动 / 停止仿真 |
| `Ctrl+E` | 在三种鼠标模式间切换：①普通 ②对象平移 ③对象旋转 |
| `Ctrl+B` | 视图自适应：使选中对象充满视图；无选择时使整个场景充满视图（焦点需在视图上） |

## 对话框与工具

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+D` | 打开对象属性对话框（Scene object properties） |
| `Ctrl+G` | 打开计算模块对话框（Calculation modules） |
| `Ctrl+Alt+C` | 将焦点切到命令行栏（Commander） |
| `Ctrl+L` | 清空状态栏（焦点在 Commander 时） |

## 使用提示

- 鼠标模式切换（`Ctrl+E`）是最常用的操作之一：进入平移或旋转模式后，可配合 [[wiki/99-附录/99-03-对话框与属性参考|Position/Orientation 对话框]] 精确调整对象位姿。
- 仿真启停（`Ctrl+Space`）与 Python 端 `sim.setStepping(True)` 的步进模式配合使用时，可由外部脚本充当 clock master 逐帧推进。详见 [[wiki/00-基础知识/00-05-用户界面与视图|用户界面与视图]]。
