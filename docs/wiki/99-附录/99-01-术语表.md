# 术语表

## A

| 术语 | 说明 |
|------|------|
| **API** | Application Programming Interface，应用程序编程接口 |
| **Actuation Phase** | 仿真步进的执行阶段，先于 Sensing Phase |

## B

| 术语 | 说明 |
|------|------|
| **BlueZero** | CoppeliaSim 的高性能通信框架，基于 ZeroMQ |
| **Bullet** | 默认的物理引擎，稳定高效 |
| **Base** | IK 运动链中的基座参考系 |

## C

| 术语 | 说明 |
|------|------|
| **Child Script** | 子脚本，挂载在场景对象上的 Lua/Python 脚本 |
| **Collision Detection** | 碰撞检测，检测物体间是否发生碰撞 |
| **Customization Script** | 定制化脚本，处理用户交互事件 |
| **CoppeliaSim** | 原名 V-REP 的机器人仿真平台 |
| **CBOR** | Concise Binary Object Representation，ZMQ API 使用的数据序列化格式 |

## D

| 术语 | 说明 |
|------|------|
| **Digital Twin** | 数字孪生，物理系统的虚拟镜像 |
| **Dynamics Engine** | 物理引擎，实现刚体力学仿真 |
| **Dummy** | 场景中的虚拟对象，常用作参考点或 IK 目标 |

## E

| 术语 | 说明 |
|------|------|
| **Element (IK)** | IK 元素，定义一条运动链（基座→关节→末端） |
| **Environment (IK)** | IK 环境，独立的求解空间 |
| **Euler Angles** | 欧拉角，描述旋转的三种角度（α, β, γ） |

## F

| 术语 | 说明 |
|------|------|
| **FK** | Forward Kinematics，正向运动学 |
| **FSM** | Finite State Machine，有限状态机 |
| **Frame** | 坐标系/参考系 |

## G

| 术语 | 说明 |
|------|------|
| **Group (IK)** | IK 组，包含一个或多个 IK 元素 |
| **Graph** | CoppeliaSim 中的图表工具，用于实时数据可视化 |

## H

| 术语 | 说明 |
|------|------|
| **Handle** | 对象句柄，CoppeliaSim 中引用对象的标识符 |
| **Hierarchy** | 场景对象的层级结构（父子关系） |

## I

| 术语 | 说明 |
|------|------|
| **IK** | Inverse Kinematics，逆运动学 |
| **IMU** | Inertial Measurement Unit，惯性测量单元 |
| **IP** | Internet Protocol，互联网协议 |

## J

| 术语 | 说明 |
|------|------|
| **Jacobian** | 雅可比矩阵，关节速度到末端速度的映射 |
| **Joint** | 关节，连接刚体的运动副 |

## L

| 术语 | 说明 |
|------|------|
| **Lua** | CoppeliaSim 主要脚本语言（版本 5.3） |
| **Legacy Remote API** | 旧版远程 API（基于 XML-RPC），不推荐新项目使用 |

## M

| 术语 | 说明 |
|------|------|
| **Main Script** | 主脚本，每个场景只有一个 |
| **Model** | 模型文件（.ttm），可复用的组件 |
| **MuJoCo** | 物理引擎，擅长接触和生物力学仿真 |

## N

| 术语 | 说明 |
|------|------|
| **Newton** | 物理引擎，稳定的物理模拟 |
| **Non-threaded Script** | 非线程脚本，每仿真步执行一次 |

## O

| 术语 | 说明 |
|------|------|
| **ODE** | Open Dynamics Engine，开源物理引擎 |
| **OMPL** | Open Motion Planning Library，开源运动规划库 |
| **Object** | 场景对象，CoppeliaSim 中最基本的实体 |

## P

| 术语 | 说明 |
|------|------|
| **Plugin** | 插件，扩展 CoppeliaSim 功能的动态库 |
| **Proximity Sensor** | 接近传感器 |
| **Pose** | 位姿（位置 + 姿态） |
| **PRM** | Probabilistic Roadmap，概率路标图（OMPL 规划器） |
| **Python** | CoppeliaSim 4.6+ 支持的脚本语言 |

## R

| 术语 | 说明 |
|------|------|
| **ROS** | Robot Operating System，机器人操作系统 |
| **ROS2** | ROS 第二代（Humble, Jazzy, Rolling 等发行版） |
| **RRT** | Rapidly-exploring Random Tree，快速随机扩展树（OMPL 规划器） |
| **RRTConnect** | 双向 RRT 规划器（OMPL 通用推荐） |
| **Regular API** | CoppeliaSim 核心 API（`sim.*` 命名空间） |

## S

| 术语 | 说明 |
|------|------|
| **Scene** | 场景文件（.ttt），包含所有仿真内容 |
| **Sensing Phase** | 仿真步进的感知阶段，在 Actuation 之后 |
| **Signal** | 信号，脚本间轻量级数据交换机制 |
| **simIK** | 运动学插件 API |
| **simOMPL** | 运动规划插件 API |
| **simROS** | ROS1 接口插件 |
| **simROS2** | ROS2 接口插件 |
| **simZMQ** | ZeroMQ 通信插件 |

## T

| 术语 | 说明 |
|------|------|
| **TF** | Transform，ROS 中的坐标变换库 |
| **Threaded Script** | 线程脚本，独立循环运行 |
| **Tip** | IK 运动链中的末端 |

## U

| 术语 | 说明 |
|------|------|
| **UR5** | Universal Robots 5 系列 6 轴协作机器人 |

## V

| 术语 | 说明 |
|------|------|
| **V-REP** | CoppeliaSim 的原名（Virtual Robot Experimentation Platform） |
| **Vision Sensor** | 视觉传感器（RGB 相机、深度相机） |

## Z

| 术语 | 说明 |
|------|------|
| **ZeroMQ (ZMQ)** | 高性能消息队列库，CoppeliaSim 外部通信的基础 |
| **ZeroMQ Remote API** | 推荐的 CoppeliaSim 外部控制接口 |

## 数字 & 符号

| 术语 | 说明 |
|------|------|
| **6-DOF** | 6 Degrees of Freedom，六自由度 |
| **.ttt** | CoppeliaSim 场景文件扩展名 |
| **.ttm** | CoppeliaSim 模型文件扩展名 |
