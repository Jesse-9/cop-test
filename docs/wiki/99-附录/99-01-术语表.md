# 术语表

> CoppeliaSim 4.10 核心术语中文释义速查。每条尽量给出关联 wiki 条目，便于跳转深入。

## A

| 术语 | 说明 |
|------|------|
| **Actuation Phase** | 仿真步进的执行阶段，先于 Sensing Phase |
| **Add-on** | 附加组件。4.10 中是一类随仿真自动加载的脚本/插件，如 ZMQ remote API server add-on、Property Explorer add-on。不同于 sandbox 与 customization script。 |
| **Alias** | 别名。`sim.setObjectAlias` 为对象设置；**别名本身不应含斜杠**（手册建议，否则会被转成下划线）。查询时构造路径（如 `/Mobile/AGV_Shared`）用斜杠前缀。见 [[wiki/02-仿真建模/02-01-分层命名场景构建]] |
| **API** | Application Programming Interface，应用程序编程接口 |

## B

| 术语 | 说明 |
|------|------|
| **Base (IK)** | IK 运动链中的基座参考系 |
| **BlueZero** | CoppeliaSim 的高性能通信框架，基于 ZeroMQ |
| **Bullet** | 默认的物理引擎，稳定高效 |

## C

| 术语 | 说明 |
|------|------|
| **CBOR** | Concise Binary Object Representation，ZMQ Remote API 使用的数据序列化格式 |
| **Child Script** | 子脚本（旧版术语）。4.10 已改用 **script object** 体系（simulation script / customization script）。见 `scriptObjects.htm` |
| **Clock Master** | 时钟主导者。当 `sim.setStepping(True)` 后，每次 `sim.step()` 推进一个 `SIM_STEP`，由外部（如 Python 端）充当 clock master 逐帧推进控制逻辑与物理引擎。本仓库 Python 端始终为 clock master。 |
| **Collection** | 集合。可在场景对象上分组，用于碰撞/距离/检测等批量计算。集合自碰撞指示器可避免运动链连续杆件误判。见 [[wiki/99-附录/99-03-对话框与属性参考]] |
| **Collision Detection** | 碰撞检测，检测物体间是否发生碰撞 |
| **CoppeliaSim** | 原名 V-REP 的机器人仿真平台 |
| **Custom Data** | 持久化自定义数据（属性前缀 `customData.`），作用域可全局/场景/对象级，脚本销毁后仍保留 |
| **Customization Script** | 定制化脚本（script object 的一种）。挂载在场景对象上，处理用户交互事件、UI 事件，不随仿真启停而启停。对应旧版 customization script 的演进。见 [[wiki/01-API参考/01-01-Regular-API-overview]] |

## D

| 术语 | 说明 |
|------|------|
| **Digital Twin** | 数字孪生，物理系统的虚拟镜像 |
| **Dummy** | 场景中的虚拟对象，常用作参考点、IK 目标、装配链接点 |
| **Dynamic (vs Kinematic)** | 动态对象参与物理求解（有质量/惯性/受力），kinematic 对象由代码/关节直接驱动位姿不响应力。Shape 有 `dynamic` 与 `kinematic` 两个属性标志。见 [[wiki/99-附录/99-03-对话框与属性参考]] |
| **Dynamics Engine** | 物理引擎，实现刚体力学仿真 |

## E

| 术语 | 说明 |
|------|------|
| **Element (IK)** | IK 元素，定义一条运动链（基座→关节→末端） |
| **Entity** | 4.10 中泛指场景中可被引用的实体（scene object、collection 等） |
| **Environment (IK)** | IK 环境，独立的求解空间 |
| **Euler Angles** | 欧拉角，描述旋转的三种角度（α, β, γ） |

## F

| 术语 | 说明 |
|------|------|
| **FK** | Forward Kinematics，正向运动学 |
| **Frame** | 坐标系/参考系 |
| **FSM** | Finite State Machine，有限状态机 |

## G

| 术语 | 说明 |
|------|------|
| **Graph** | CoppeliaSim 中的图表工具，用于实时数据可视化 |
| **Group (IK)** | IK 组，包含一个或多个 IK 元素 |

## H

| 术语 | 说明 |
|------|------|
| **Handle** | 对象句柄。`sim.getObject` 等返回的 int 标识，引用场景对象；`sim.handle_world`/`sim.handle_parent`/`sim.handle_self`/`sim.handle_app`/`sim.handle_scene` 等是特殊伪句柄 |
| **Hierarchy** | 场景对象的层级结构（父子关系） |

## I

| 术语 | 说明 |
|------|------|
| **IK** | Inverse Kinematics，逆运动学 |
| **IK Group** | IK 组，包含一个或多个 IK 元素，由 IK 求解器求解 |
| **IMU** | Inertial Measurement Unit，惯性测量单元 |
| **IP** | Internet Protocol，互联网协议 |

## J

| 术语 | 说明 |
|------|------|
| **Jacobian** | 雅可比矩阵，关节速度到末端速度的映射 |
| **Joint** | 关节，连接刚体的运动副 |

## L

| 术语 | 说明 |
|------|------|
| **Legacy Remote API** | 旧版远程 API（基于 XML-RPC），不推荐新项目使用 |
| **Lua** | CoppeliaSim 主要脚本语言（版本 5.3） |

## M

| 术语 | 说明 |
|------|------|
| **Main Script** | 主脚本（4.10 保留概念）。每个场景的仿真入口脚本，4.10 实践中更多用 script objects + sandbox 替代旧版 child/main 二分 |
| **Model** | 模型文件（.ttm），可复用的组件 |
| **MuJoCo** | 物理引擎，擅长接触和生物力学仿真 |

## N

| 术语 | 说明 |
|------|------|
| **Named Parameter** | 命名参数（属性前缀 `namedParam.`），易失字符串，target 为 `sim.handle_app`，来自用户设置或 `-G` 命令行开关 |
| **Newton** | 物理引擎，稳定的物理模拟 |
| **Non-threaded Script** | 非线程脚本，每仿真步执行一次 |

## O

| 术语 | 说明 |
|------|------|
| **ODE** | Open Dynamics Engine，开源物理引擎 |
| **Object** | 场景对象，CoppeliaSim 中最基本的实体 |
| **OMPL** | Open Motion Planning Library，开源运动规划库 |

## P

| 术语 | 说明 |
|------|------|
| **Path** | 路径。`sim.getObject(path)` 用斜杠路径查询；绝对路径 `/Robot`，相对路径 `./`、`../`、`:`、`::`；支持通配符 `*`、同层索引 `[n]`、全局索引 `{n}`。路径与别名不同：别名不含斜杠，路径是查询时构造的。见 [[wiki/02-仿真建模/02-01-分层命名场景构建]] |
| **Plugin** | 插件，扩展 CoppeliaSim 功能的动态库（如 simIK、simOMPL、simROS2） |
| **Pose** | 位姿（位置 + 姿态）。Regular API 中常用 7 元素 `[x y z qx qy qz qw]`（位置 + 四元数）。见 [[wiki/01-API参考/api/api-simGetObjectPose]] |
| **PRM** | Probabilistic Roadmap，概率路标图（OMPL 规划器） |
| **Primitive Shape** | 基本体形状。CoppeliaSim 的纯几何基元（cuboid/sphere/cylinder 等），不能翻转、对非等比缩放有限制 |
| **Proximity Sensor** | 接近传感器 |
| **Property** | 4.10 将所有内部变量/状态统一为属性，可用 `sim.getXxxProperty`/`sim.setXxxProperty` 查询修改。target 可为 app/scene/对象。见 [[wiki/99-附录/99-03-对话框与属性参考]] |
| **Python** | CoppeliaSim 4.6+ 支持的脚本语言 |

## R

| 术语 | 说明 |
|------|------|
| **RRT** | Rapidly-exploring Random Tree，快速随机扩展树（OMPL 规划器） |
| **RRTConnect** | 双向 RRT 规划器（OMPL 通用推荐） |
| **Regular API** | CoppeliaSim 核心 API（`sim.*` 命名空间）。支持 **Python、Lua、C/C++** 三种语言。见 [[wiki/01-API参考/01-01-Regular-API-overview]] |
| **Remote API** | 远程 API。当前推荐使用 **ZeroMQ Remote API**（见 `zmqRemoteApi.htm`）。Legacy Remote API（XML-RPC）已不推荐。见 [[wiki/01-API参考/01-02-Remote-API-ZMQ]] |
| **ROS** | Robot Operating System，机器人操作系统 |
| **ROS2** | ROS 第二代（Humble, Jazzy, Rolling 等发行版） |

## S

| 术语 | 说明 |
|------|------|
| **Sandbox** | 沙箱脚本。4.10 提供的独立脚本环境，用于无场景上下文测试/辅助代码执行，不挂载于具体对象。见 `scriptObjects.htm` |
| **Scene** | 场景文件（.ttt），包含所有仿真内容 |
| **Script Object** | 4.10 脚本对象体系。包含 **simulation script**（仿真运行时执行）与 **customization script**（处理交互/UI 事件）两类，取代旧版 child script 二分法。见 [[wiki/01-API参考/01-06-脚本回调函数清单]] |
| **Sensing Phase** | 仿真步进的感知阶段，在 Actuation 之后 |
| **Signal** | 信号。4.10 中作为属性的一种（前缀 `signal.`），易失变量，脚本状态销毁时自动删除。兼容旧版 `setIntegerSignal`/`getIntegerSignal` 等 API |
| **Simulation Script** | 仿真脚本（script object 的一种）。随仿真启停而启停，在 actuation/sensing 阶段执行回调 |
| **simIK** | 运动学插件 API |
| **simOMPL** | 运动规划插件 API |
| **simROS** | ROS1 接口插件 |
| **simROS2** | ROS2 接口插件 |
| **simZMQ** | ZeroMQ 通信插件 |
| **Stepping Mode** | 步进模式。`sim.setStepping(True)` 后仿真不自动推进，每次 `sim.step()` 推进一个 `SIM_STEP`。外部控制器（如 Python）成为 clock master，精确同步控制逻辑与物理引擎 |

## T

| 术语 | 说明 |
|------|------|
| **TF** | Transform，ROS 中的坐标变换库 |
| **Threaded Script** | 线程脚本，独立循环运行 |
| **Tip** | IK 运动链中的末端 |

## U

| 术语 | 说明 |
|------|------|
| **UR5** | Universal Robots 5 系列 6 轴协作机器人 |

## V

| 术语 | 说明 |
|------|------|
| **V-REP** | CoppeliaSim 的原名（Virtual Robot Experimentation Platform） |
| **Vision Sensor** | 视觉传感器（RGB 相机、深度相机） |

## Z

| 术语 | 说明 |
|------|------|
| **ZeroMQ (ZMQ)** | 高性能消息队列库，CoppeliaSim 外部通信的基础 |
| **ZeroMQ Remote API** | 推荐的 CoppeliaSim 外部控制接口。见 [[wiki/01-API参考/01-02-Remote-API-ZMQ]] |

## 数字 & 符号

| 术语 | 说明 |
|------|------|
| **6-DOF** | 6 Degrees of Freedom，六自由度 |
| **.ttt** | CoppeliaSim 场景文件扩展名 |
| **.ttm** | CoppeliaSim 模型文件扩展名 |
