# 对话框与属性参考

> 汇总 CoppeliaSim 4.10 中与场景对象属性、几何、位姿及坐标变换相关的常用对话框及其关键字段。来源：`commonPropertiesDialog.htm`、`sceneObjectPropertiesDialog.htm`、`properties.htm`、`propertiesReference.htm`、`geometryDialog.htm`、`positionDialog.htm`、`orientationDialog.htm`、`coordinateDialog.htm`。

## 1. Scene object 对话框（Scene object properties）

- **入口**：菜单 `Tools > Scene object properties`；或在场景层级中双击对象图标；或点击工具栏按钮。
- **行为**：上下文敏感，仅显示**最后选中**对象的属性。无选择时对话框失效；多选时部分参数可经 "Apply to selection" 按钮从最后选中对象复制到其他选中对象。
- **两段式结构**：
  1. **Object-type specific properties**（对象类型专属属性）
  2. **General scene object properties**（所有对象通用的通用属性，见下节）

## 2. 通用场景对象属性（General properties）

关键字段速查（来源 `commonPropertiesDialog.htm`，对应 `propertiesReference.htm` 中 "Scene object common properties"）：

| 字段 | 说明 |
|------|------|
| **Selectable** | 是否可在视图中被点选（场景层级中始终可选）。对应属性 `selectable`。 |
| **Invisible during selection** | 选择操作时对象对拾取射线不可见（可穿过点选）。`selectInvisible` |
| **Ignored by depth pass** | 深度渲染阶段忽略该对象（影响相机移动时红球定位）。`depthInvisible` |
| **Select base of model instead** | 视图中点选时改为选中其最近的"model base"父对象。`selectModel` |
| **Ignored by model bounding box** | 不计入父模型的包围盒（适用于使模型包围盒过大的不可见对象）。`hideFromModelBB` |
| **Ignored for view-fitting** | 视图自适应时忽略该对象（通常地板等打此标记）。`ignoreViewFitting` |
| **Cannot be deleted during simul.** | 仿真运行中禁止删除（代码触发仍可删）。`cannotDeleteInSim` |
| **Cannot be deleted** | 始终禁止删除（代码触发仍可删）。`cannotDelete` |
| **Hidden during simulation** | 仿真运行时隐藏。— |
| **Not moveable** | 不能用鼠标移动。— |
| **Extension string** | 附加属性字符串，主要供扩展插件使用。对应 `sim.getExtensionString`。 |
| **Camera visibility layers** | 可见性层。对象可属于一个或多个层；至少一层与层选择对话框的激活层匹配时，对象对相机可见。默认 shape→第 1 层、joint→第 2 层、dummy→第 3 层……对应 `layer`。 |
| **Object is model base** | 标记对象为模型基座（model base）。复制时会连同整棵层级树复制；选中时包围盒用粗虚线显示，包围整个模型。`modelBase` |
| **Model properties** | 打开模型对话框（Model dialog）。— |
| **Collidable** | 启用/禁用碰撞检测能力。`collidable` |
| **Measurable** | 启用/禁用最小距离计算能力。`measurable` |
| **Detectable** | 启用/禁用接近传感器检测能力。`detectable` |
| **Collection self-collision indicator** | 集合自碰撞指示器：同一集合内两项的指示器差值若恰为 1/10/100/1000/10000/100000，则不互相检测，用于运动链中避免连续杆件误判碰撞。`collectionSelfCollisionIndicator` |

## 3. Shape geometry 对话框

- **入口**：形状（shape）属性对话框的一部分。
- **功能**：查看与修改 shape 的几何，显示顶点数、三角面数和包围盒尺寸。
- **要点**：
  - 顶点 / 三角面数越多，渲染与计算（碰撞、距离）越慢——应尽量精简。
  - 通用属性对话框只能等比缩放；**几何对话框允许非等比缩放**，甚至可用负缩放因子翻转网格沿某一轴。
  - **primitive shape 不能被翻转**，且对非等比缩放有限制。

## 4. Position 对话框（对象平移）

- **入口**：点击 "Object translation" 工具栏按钮。
- **四个标签页**：
  - **Mouse Translation**：鼠标拖拽参数。`Relative to world/own frame` 选择对齐参考系；`Translation step size` 步长（按住 Shift 可用更小步长）；`Preferred axes` 沿 X/Y/Z 优先轴（按住 Ctrl 可临时切换其他轴）。
  - **Position**：精确定位。`Relative to world/parent frame` 选择参考系；直接输入 X/Y/Z 坐标。
  - **Translation**：精确平移。`Relative to world/parent/own frame`；输入沿三轴的平移量。
  - **Position scaling**：位置缩放。`Relative to world/parent frame`；输入 X/Y/Z 缩放系数（可非等比）。

## 5. Orientation 对话框（对象旋转）

- **入口**：点击 "Object rotation" 工具栏按钮。
- **三个标签页**：
  - **Mouse Rotation**：鼠标拖拽旋转参数。`Relative to world/own frame`；`Rotation step size`；`Preferred axis`（X/Y/Z，按 Ctrl 临时切换）。
  - **Orientation**：精确设置朝向。`Relative to world/parent frame`；输入 Alpha/Beta/Gamma 欧拉角。
  - **Rotation**：精确旋转。`Relative to world/parent/own frame`；输入绕 X/Y/Z 的旋转量。

> Position 与 Orientation 对话框是 `Ctrl+E` 切换鼠标模式后的配套面板，见 [[wiki/99-附录/99-02-快捷键速查|快捷键速查]]。

## 6. Properties（属性）统一模型

CoppeliaSim 4.10 将**所有内部变量 / 状态**统一为"属性（property）"，可通过 `sim.getXxxProperty` / `sim.setXxxProperty` 系列函数查询与修改。属性的 target 有三类：

| Target | 含义 | 示例 |
|--------|------|------|
| `sim.handle_app` | 应用级（全局） | `settingsPath`、`appPath`、`pythonPath`、`namedParam.*` |
| `sim.handle_scene` | 场景级 | `gravity`、`dynamicsEngine`、`dynamicsStepSize`、`simulationTime`、`signal.*` |
| 对象句柄 | 场景对象级 | `pose`、`alias`、`jointPosition`、`mass`、`customData.*` |

### 6.1 特殊属性类别

- **custom data**：以 `customData.` 为前缀的**持久化**数据（写入磁盘），可创建/修改/删除。脚本销毁后仍保留。用 `sim.packTable` / `sim.unpackTable` 配合 `setBufferProperty` / `getBufferProperty` 存取任意 Lua/Python 表。
- **signals**：以 `signal.` 为前缀的**易失**变量（类似旧版 signal 系统）。作用域同上。创建它的脚本状态被销毁时自动删除。
- **named parameters**：以 `namedParam.` 为前缀的易失字符串属性，target 为 `sim.handle_app`。通常来自用户设置或 `-G` 命令行开关。
- **engine-related properties**：以 `bullet.` / `ode.` / `newton.` / `vortex.` / `mujoco.` 为前缀的物理引擎相关属性。

### 6.2 读写权限

属性可具有以下权限组合：可读可写、只读（`not writable`）、只写（`not readable`）、可移除（`removeProperty`）。

```python
# 只读示例
meshes = sim.getIntArrayProperty(shapeHandle, 'meshes')

# 只写示例
sim.setBoolProperty(shapeHandle, 'applyCulling', True)

# 可移除示例
sim.removeProperty(objectHandle, 'customData.myFloatArray')
```

### 6.3 属性浏览

可通过附加组件 `Modules > Developer tools > Property explorer`（Property Explorer add-on）方便地浏览所有属性。大多数属性变更（显式或内部触发）会产生事件，可通过事件回调函数监听。

## 7. 常用对象属性速查（节选自 propertiesReference.htm）

完整列表见 `propertiesReference.htm`，以下为高频字段。

### Scene 对象通用

| 属性 | 类型 | 说明 |
|------|------|------|
| `alias` | string | 对象别名 |
| `pose` | pose | 本地位姿 |
| `objectType` | string, 只读 | 对象类型 |
| `objectUid` | long long, 只读 | 对象唯一 ID |
| `parentHandle` | int, 只读 | 父对象句柄 |
| `bbHSize` / `bbPose` | vector[3] / pose, 只读 | 包围盒半尺寸 / 局部位姿 |
| `layer` | int | 可见性层 |
| `modelBase` | bool | 是否为模型基座 |
| `collidable` / `measurable` / `detectable` / `selectable` / `visible` | bool | 各能力位 |

### Shape 专属

| 属性 | 说明 |
|------|------|
| `mass` | 质量 |
| `centerOfMass` | 质心（相对 shape 参考系） |
| `inertia` | 惯性张量 |
| `dynamic` | 是否动态（非静态） |
| `kinematic` | 特殊标志（主要用于 MuJoCo 中移动的静态 shape） |
| `respondable` / `respondableMask` | 是否传递碰撞力 / 掩码 |
| `meshes` | 组成该 shape 的网格句柄（只读） |
| `convex` / `compound` / `primitive` | 几何特征只读标志 |

### Joint 专属

| 属性 | 说明 |
|------|------|
| `jointType` | 关节类型（只读） |
| `jointMode` | 关节模式 |
| `jointPosition` | 关节线/角位移 |
| `interval` | 关节限位（下界、上界） |
| `cyclic` | 是否为循环旋转关节（无限位） |
| `dynCtrlMode` | 动态控制模式 |
| `targetPos` / `targetVel` / `targetForce` | 控制器目标位置/速度/最大力 |
| `maxVelAccelJerk` | 最大速度/加速度/jerk |
| `springDamperParams` | 弹簧阻尼参数 |
| `dependencyMasterHandle` / `dependencyParams` | 依从关系主关节及参数 |

### Dummy 专属

| 属性 | 说明 |
|------|------|
| `dummyType` / `dummySize` | dummy 类型 / 尺寸 |
| `linkedDummyHandle` | 关联 dummy 句柄 |
| `assemblyTag` | 装配标签 |

### Scene 级

| 属性 | 说明 |
|------|------|
| `gravity` | 重力（vector[3]） |
| `dynamicsEngine` | 选定物理引擎索引与版本 |
| `dynamicsStepSize` | 动力学步长 |
| `timeStep` | 仿真步长 |
| `simulationState` / `simulationTime` / `stepCount` | 仿真状态/时间/步数（只读） |
| `selectionHandles` | 选中对象句柄列表 |
| `objectHandles` | 全部场景对象句柄（只读） |
| `realtimeSimulation` / `realtimeModifier` | 是否实时仿真 / 倍率 |

### App 级

| 属性 | 说明 |
|------|------|
| `appPath` / `resourcePath` / `systemPath` | 应用/资源/系统路径 |
| `settingsPath` | 用户设置文件 `usrset.txt` 路径 |
| `pythonPath` / `luaPath` / `defaultPython` | Python/Lua 解释器 |
| `productVersion` / `productVersionNb` | 产品版本（字符串/数字） |
| `platform` | 操作系统（只读） |
| `headlessMode` | 无头模式（0=否，1=GUI 抑制，2=无头库） |
