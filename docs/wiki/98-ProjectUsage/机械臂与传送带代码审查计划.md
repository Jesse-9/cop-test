# 机械臂与传送带代码审查及修复计划

> [!info] 当前状态
> 本文记录 `src/` 下机械臂和传送带相关代码的审查结果、候选修复、验证计划及当前进度。当前状态为 **review**，已通过单元测试覆盖全部 4 项缺测，文档已与代码同步；尚未完成 60 秒全流程仿真验收。

## 1. 范围与术语

本轮审查覆盖：

- `src/factory_robot.py`：UR5 关节采集、关键帧动画和动作触发。
- `src/factory_physics.py`：物料与传送带 pad 的物理属性。
- `src/factory_controller.py`：物料生成、传送带推进、工位出料和机械臂触发。
- `src/build_scene.py`：UR5、夹爪、传送带和 AGV 场景构建。
- `src/factory_config.py`：机械臂关键帧、传送带速度和物理参数。
- `src/factory_types.py`：物料的传送带、冻结和物理状态。

本文中的“履带”指 CoppeliaSim 内置 `generic conveyor (belt).ttm` 的闭环 pad 传送带。当前 AGV 使用 Pioneer P3DX 轮式模型，不是履带式移动底盘。

## 2. 审查基线

- CoppeliaSim 场景中存在 6 台 UR5，每台本体有 6 个关节。
- UR5 本体关节实际为 `jointmode_dynamic=5`。
- UR5 动态控制模式实际为 `jointdynctrl_position=8`。
- 每条内置传送带包含约 50 个名为 `pad` 的 shape。
- pad 沿上表面、右端滚轮、底部、左端滚轮构成闭环。
- Python 仿真步长与 CoppeliaSim 步长均为 `0.05 s`。
- 工作区在审查开始前已有未提交修改，后续必须保留并与之兼容。

## 3. 已确认问题

| 严重度 | 问题 | 影响 | 状态 |
|---|---|---|---|
| P1 | 动态 UR5 使用 `setJointPosition` | 写入会被下一次物理解算覆盖，关节接近零位，动画不可用 | 已形成候选修复 |
| P1 | pad 仅增加局部 X 并按带长回卷 | 滚轮和底部 pad 被破坏，无法保持闭环履带形状 | 已形成候选修复 |
| P1 | 物理模式物料生成在仓库中心而非传送带入口 | 物料可能落到带外或地板，无法依靠摩擦输送 | 已形成候选修复 |
| P2 | C 岛出料后只设置 `on_conveyor` | 物理模式跳过 Python 位姿同步，物料不会自动移动到 C→E 入口 | 已形成候选修复 |
| P2 | 非循环动画结束前先清除 `anim` | 动作最后一帧没有被精确写入，可能停在接近 HOME 的姿态 | 已形成候选修复 |
| P2 | UR5 关节顺序依赖对象树返回顺序 | 模型或版本变化时关键帧可能映射到错误关节 | 已形成候选修复 |
| P2 | `factory_physics`、`factory_scene` 未列入打包模块 | 开发目录可运行，安装后的 CLI 可能导入失败 | 已形成候选修复 |
| P3 | `factory_robot.update()` 文档与实际触发逻辑不一致 | 文档声称 COMPLETE 自动触发，实际由控制器事件更可靠 | 已同步文档 (factory_robot.update() 注释已更新) |

## 5. 验收标准

### 机械臂

- 每台 UR5 恰好采集 6 个本体关节，不包含夹爪关节。
- 关节目标值与关键帧顺序一致。
- 实际关节位置随目标变化，不被物理解算重置到零位。
- 抓取、放置和装配动作结束后回到 HOME。
- 单台机械臂不可用时不阻断生产逻辑。

### 传送带

- pad 始终沿闭环移动，滚轮和底部段不被拉到上表面。
- pad 间距无明显累计误差或跳变。
- 物料生成在正确传送带入口并沿 start→end 方向移动。
- 目标工位拒收时传送带可冻结，恢复后继续输送。
- 内置模型不可用时，几何回退模型仍可完成逻辑输送。

### 全流程

- 仿真时间持续推进，不停在启动后的少数帧。
- 20 秒测试中三条上料线至少完成首次到岛。
- 60 秒测试中 B→A、D→E、C→E 和 E 岛装配链路均有可追踪记录。
- 不出现重复任务、重复入岛、物料丢失或未捕获异常。

- 关键帧动画只控制关节角，不做 IK、碰撞规避或真实抓取。
- 夹爪脚本被剥离后不会自动开合，当前仍主要是视觉模型。
- MuJoCo 对 kinematic/static 接触面的行为与 Bullet/ODE 可能不同。
- 动态物料离开带面后仍受物理引擎作用，可能需要按状态切换动力学属性。
