# OMPL 运动规划 (simOMPL)

## 概述

**OMPL**（Open Motion Planning Library）是 CoppeliaSim 集成的开源运动规划库。`simOMPL` 插件为工业机器人提供**碰撞规避路径规划**功能，是复杂环境中机器人运动规划的核心工具。

> 详细文档见 [[raw/src-doc-CoppeliaSim-OMPL-plugin.html]] 和 [[raw/src-doc-CoppeliaSim-path-motion-planning.html]]

## 适用场景

- **避障路径规划** — 在存在障碍物的环境中规划无碰撞路径
- **高自由度规划** — 支持 6+ 自由度的工业机器人
- **复杂环境** — 静态和动态障碍物场景
- **多机器人协调** — 协作避障

## 初始化

```lua
simOMPL = require('simOMPL')
```

## 基本工作流程

```
1. 创建状态空间 ──→ 2. 设置规划问题 ──→ 3. 配置规划器 ──→ 4. 求解 ──→ 5. 执行路径
```

## 完整示例 (Lua)

```lua
function sysCall_init()
    simOMPL = require('simOMPL')
    
    -- 获取场景对象
    robotJoints = {}
    for i = 1, 6 do
        robotJoints[i] = sim.getObject('/UR5/joint' .. i)
    end
    
    -- 障碍物集合
    obstacles = {
        sim.getObject('/obstacle1'),
        sim.getObject('/obstacle2')
    }
    
    -- 定义关节范围
    jointRanges = {
        {-3.14, 3.14},  -- J1
        {-2.0, 2.0},    -- J2
        {-2.0, 2.0},    -- J3
        {-3.14, 3.14},  -- J4
        {-2.0, 2.0},    -- J5
        {-3.14, 3.14}   -- J6
    }
end

function sysCall_actuation()
    -- 第 1 步：创建状态空间
    local ss = simOMPL.createStateSpace('joint_space', simOMPL.StateSpaceType.joint_position, robotJoints, jointRanges)
    
    -- 第 2 步：设置碰撞检测回调
    simOMPL.setStateSpace(ss)
    simOMPL.setCollisionPair(ss, simOMPL.CollisionPair.self_collision, true)
    for _, obs in ipairs(obstacles) do
        simOMPL.setCollisionPair(ss, simOMPL.CollisionPair.start_obstacle, robotJoints[1], obs, true)
    end
    
    -- 第 3 步：设置规划器（RRT Connect 是通用的好选择）
    local planner = simOMPL.createPlanner(ss, simOMPL.PlannerType.RRTConnect)
    
    -- 第 4 步：设置起止状态
    local startState = {}
    local goalState = {0.5, -0.8, 1.2, 0.0, 0.5, 0.0}
    for i = 1, 6 do
        startState[i] = sim.getJointPosition(robotJoints[i])
    end
    
    simOMPL.setStartState(ss, startState)
    simOMPL.setGoalState(ss, goalState)
    
    -- 第 5 步：求解
    local result, path = simOMPL.compute(ss, 5.0, 1000)  -- 5秒超时, 1000最大迭代
    
    if result == simOMPL.Result.success then
        print("路径规划成功！路径点数量: " .. #path)
        
        -- 第 6 步：执行路径
        for _, config in ipairs(path) do
            for j = 1, 6 do
                sim.setJointTargetPosition(robotJoints[j], config[j])
            end
            -- 等待到达位置
            sim.waitUntil(sim.getSimulationTime() + 0.01)
        end
    else
        print("路径规划失败")
    end
end
```

## 规划器类型

| 规划器 | 特点 | 适用场景 |
|--------|------|----------|
| `PlannerType.RRT` | 基本 RRT，渐近最优 | 简单环境快速规划 |
| `PlannerType.RRTConnect` | 双向 RRT，效率高 | 通用推荐 |
| `PlannerType.RRTstar` | RRT*，渐近最优路径 | 需要最优路径 |
| `PlannerType.BITstar` | 批量信息树，高质量 | 复杂环境 |
| `PlannerType.PRM` | 概率路标图 | 多查询场景 |
| `PlannerType.PRMstar` | PRM* 改进版 | 高质量多查询 |
| `PlannerType.LazyPRMstar` | 惰性碰撞检测 | 碰撞检测昂贵场景 |
| `PlannerType.SBL` | 单查询双向规划 | 窄通道环境 |

## 状态空间类型

```lua
simOMPL.StateSpaceType.joint_position      -- 关节空间（最常用）
simOMPL.StateSpaceType.position2d          -- 2D 位置空间
simOMPL.StateSpaceType.position3d          -- 3D 位置空间
simOMPL.StateSpaceType.se2                -- SE(2) 位姿空间
simOMPL.StateSpaceType.se3                -- SE(3) 位姿空间
```

## 固定场景路径规划（无需 OMPL）

对于固定工作环境中重复执行的路径，可以对路径进行**预计算**和**序列化存储**：

```lua
-- 保存规划好的路径到文件
local pathStr = sim.packFloatTable(path)
sim.writeCustomDataFile("path_data.bin", pathStr)

-- 加载路径
local loadedData = sim.readCustomDataFile("path_data.bin")
local loadedPath = sim.unpackFloatTable(loadedData)
```

## Python + ZMQ 调用 OMPL

```python
from coppeliasim_zmqremoteapi_client import RemoteAPIClient
import math

client = RemoteAPIClient()
sim = client.getObject('sim')
simOMPL = client.getObject('simOMPL')

# 创建状态空间
joints = [sim.getObject(f'/UR5/joint{i}') for i in range(1, 7)]
ranges = [[-3.14, 3.14] for _ in range(6)]

ss = simOMPL.createStateSpace(
    'joint_space',
    simOMPL.StateSpaceType.joint_position,
    joints, ranges
)

simOMPL.setStateSpace(ss)

# 设置规划器
planner = simOMPL.createPlanner(ss, simOMPL.PlannerType.RRTConnect)

# 起止状态
start_state = [sim.getJointPosition(j) for j in joints]
goal_state = [0.5, -0.8, 1.2, 0.0, 0.5, 0.0]

simOMPL.setStartState(ss, start_state)
simOMPL.setGoalState(ss, goal_state)

# 求解
result, path = simOMPL.compute(ss, 5.0, 1000)

if result == simOMPL.Result.success:
    print(f"路径规划成功！{len(path)} 个路径点")
    for config in path:
        for j, joint in enumerate(joints):
            sim.setJointTargetPosition(joint, config[j])
```

## 与 IK 配合使用

工业场景中常见的工作流：

```
IK 求解 → 目标位姿 → OMPL 规划 → 无碰撞路径 → 执行
```

示例：IK 先计算末端可达位姿，OMPL 再规划从当前位置到目标的无碰撞路径。

## 性能优化建议

1. **简化碰撞模型** — 使用基本几何体（盒子、球体、圆柱体）代替复杂网格进行碰撞检测
2. **合理设置迭代上限** — 过高导致耗时，过低可能找不到解
3. **适当选择规划器** — RRTConnect 通常是最佳通用选择
4. **分段规划** — 长距离路径分多段规划，提高成功率

## 常见问题

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 规划失败 | 障碍物阻塞所有路径 | 放松碰撞检测或增加迭代次数 |
| 规划时间过长 | 碰撞模型复杂 | 简化碰撞几何体或增加超时时间 |
| 路径抖动 | 规划器随机性 | 使用 RRT* 或对路径做平滑后处理 |
